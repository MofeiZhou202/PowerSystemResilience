# 高性能线性代数求解器研究进展综述——兼论其在电力系统分析中的应用

## 摘要

线性方程组求解是几乎所有电力系统计算内核（潮流、状态估计、暂态稳定、电磁暂态、最优潮流）中耗时占比最高的环节，其性能直接决定电网分析的规模上限与时效性。本综述系统梳理了高性能线性代数求解器在过去十余年间的三条主线进展：**直接法**沿"排序优化—超节点/多波前并行—通信规避—GPU 卸载—GPU 原生（cuDSS）"路线演进，NVIDIA cuDSS（2023 年末发布）首次使 GPU 原生稀疏直接求解实用化，在电网类矩阵上报告了最高三个数量级的数值分解加速；**迭代法**以 Krylov 子空间方法为核心，配合"一次分解、多次复用"的预条件策略与子空间回收技术，在超大规模与多场景潮流中已优于直接法，Ginkgo、hypre、PETSc 等现代栈实现了 GPU 可移植与混合精度；**新兴范式**中，混合精度迭代精化已进入基准测试与主流库，量子线性求解器被严格的端到端复杂度分析证明对潮流问题暂无实际优势，而机器学习代理（DeepOPF 系列、图神经网络潮流代理）在批量场景下可实现百至万倍加速但尚不能替代精确求解。在电力系统应用侧，最具标志性的成果是美国 ExaSGD 项目在世界首台百亿亿次超算 Frontier 上于 **20 分钟内完成 10 万余预想事故的安全约束最优潮流（SCOPF）全量求解**，以及中国"电网超算平台 + ADPSS + CloudPSS"体系实现的 **4.5 万节点机电暂态仿真、8000 母线级实时电磁暂态仿真与百万节点级批量电磁暂态云仿真**。报告最后给出"求解技术 × 应用场景"的选型矩阵与开放挑战分析。

**关键词**：稀疏线性求解器；直接法；Krylov 迭代法；GPU 计算；电力系统分析；潮流计算；状态估计；暂态稳定仿真；最优潮流；电磁暂态仿真

## 1 电力系统分析中的线性代数内核

### 1.1 为什么线性求解器决定电网计算的性能上限

电力系统分析的所有主干计算——牛顿—拉夫逊潮流、加权最小二乘状态估计、微分—代数方程（DAE）时域仿真、电磁暂态（EMT）仿真、内点法最优潮流——在外层形式上千差万别，但其内层都归结为**反复求解大型稀疏线性方程组** $Ax=b$。不同应用产生的矩阵在对称性、正定性、条件数、稀疏模式与"同一稀疏模式重复分解的次数"上差异极大，这正是求解器技术选型的根本依据。例如潮流雅可比矩阵非对称但结构对称、每个节点仅含少量非零元；状态估计的法方程增益矩阵对称正定，而 Hachtel 增广矩阵则对称不定；OPF 内点法的 KKT 矩阵不仅对称不定，且随内点迭代趋于收敛而**极度病态**；EMT 仿真则要求对固定拓扑的节点电导矩阵在数十万时间步内重复三角分解与回代。工业流程仿真领域的经验表明，大规模模型中线性求解可占总求解时间的 **90%**[^171^]，电力系统情形与之类似。

电网矩阵还具有一般稀疏矩阵少有的两个特征：其一，**极端稀疏且结构不规则**——每行平均非零元通常不足 10 个，非零元分布不服从带状或块对角等简单模式，使缓存复用与向量化困难、计算呈内存受限特征[^5^]；其二，**小世界图特性**——电网连接呈现小世界网络结构，少量高连通度节点（枢纽变电站）会在消去过程中诱发显著的填入（fill-in），使排序算法的质量对分解成本有数量级影响。这两大特征决定了电力系统求解器优化始终围绕"保稀疏性、控填入、挖掘粗粒度并行"展开，也解释了为何通用求解器库往往需要针对电网矩阵做专门调优。

**表 1  电力系统主要分析任务产生的线性系统特性对比**

| 分析任务 | 典型矩阵 | 对称性/定性 | 条件数 | 重复求解特征 | 主流解法 |
|---|---|---|---|---|---|
| 潮流（NR） | 雅可比 $J$ | 非对称、结构对称 | 中等，病态系统可很高 | 每次牛顿迭代重分解，拓扑不变时模式固定 | 稀疏 LU 直接法；Newton–Krylov |

| 状态估计 | 法方程 $H^\mathsf{T}WH$ 或 Hachtel 增广矩阵 | SPD 或对称不定 | 零注入等导致病态 | 每次迭代重分解 | LDLᵀ 多波前；增广矩阵法 |

| AC-OPF / SCOPF | 内点法 KKT 矩阵 | 对称不定 | **随收敛极度病态** | 每次内点迭代重分解 | LBLᵀ（MA57）；凝缩 KKT + Cholesky（GPU） |

### 1.2 历史脉络：电力系统是稀疏矩阵技术的发源地之一

稀疏矩阵计算并非数学界的纯理论产物，其最早的工程驱动力之一就来自电力系统。1963 年，Bonneville 电力管理局（BPA）的 Sato 与 Tinney 提出利用网络导纳矩阵稀疏性的存储与消去技术，目标是在仅有 32K 内存的计算机上求解 1000 节点级电网[^154^]。1967 年，Tinney 与 Walker 发表"最优排序三角分解"论文，Tinney 与 Hart 同年发表牛顿法潮流论文，两项工作共同确立了**"稀疏三角分解 + 最优排序 + 牛顿法"这一统治电力计算至今的技术范式**，并反过来激励了数学界对一般稀疏矩阵方法的研究[^148^][^150^]。1968 年 Dommel 与 Tinney 的最优潮流论文被评选为 20 世纪电力系统分析第五重要论文[^150^]；1974 年 Stott 与 Alsac 利用有功—相角、无功—电压的弱耦合提出快速解耦潮流（FDLF），以常系数矩阵换取"一次分解、永久复用"[^151^]。此后半个多世纪，PSS/E、PSASP、MATPOWER 等几乎所有电力分析软件的内核都建立在这一范式之上[^148^]。

进入 21 世纪第二个十年后，两条新的技术曲线开始叠加：一是硬件层面众核 GPU 与百亿亿次超算改变了浮点与内存带宽的性价比，二是可再生能源高比例接入使在线安全分析、海量场景评估对计算吞吐提出数量级增长的需求。图 1 概括了 1963—2025 年间求解器技术与电力系统计算协同演进的关键节点，可以看出**每一次电力计算能力的阶跃——从千节点潮流到超实时动态仿真再到百亿亿次级 SCOPF——都对应着求解器技术的一次范式更新**。

## 2 直接法求解器的进展

### 2.1 经典谱系与主流求解器库

稀疏直接法的核心技术在 1990—2010 年间趋于成熟，形成了多波前（multifrontal）与超节点（supernodal）两大算法家族。多波前方法以 UMFPACK、MUMPS、HSL MA27/MA57/MA97、WSMP 为代表，将消去树组织为一系列稠密"波前矩阵"上的 Level-3 BLAS 运算；超节点方法以 SuperLU、PaStiX、CHOLMOD 为代表，将结构相似的列聚合成超节点以复用稠密核[^9^][^136^]。面向电力与电路问题的一个特化分支是 **KLU**（Davis，2005）：它先对矩阵做块三角化（BTF）分解，再对各对角块分别进行左看式 LU 分解，特别契合电路与电网矩阵"近块对角 + 少量耦合"的结构，被广泛用于 SPICE 类电路仿真，并在潮流求解中表现出相对 MATPOWER 默认求解器约 10 倍的速度优势[^21^]。由中国学者研发的 **NICSLU**（清华大学陈晓明等，2013）针对共享内存多核 CPU 设计了自适应并行 LU 分解，在 85 个测试矩阵上对适合并行分解的矩阵取得相对 KLU **2.08×–8.57× 的几何平均加速**[^72^]；其后续工作 CKTSO（2024）进一步提升了数值稳定性与可扩展性，实现了分解与回代的全阶段并行[^63^]。

在分布式内存方向，MUMPS 长期作为通用标准被 Ipopt 等优化器默认采用[^162^]；SuperLU_DIST 则在近年完成了面向异构超算的重大重构：2021 年 7.0 版引入通信规避的 3D 稀疏 LU 算法，2022 年 8.0 版加入 AMD GPU/HIP 支持与单精度+双精度迭代精化的混合精度接口，2024 年 5 月发布的 9.0 版实现了 3D 通信规避 LU 与三角求解的全面 GPU 化，并首次提供 **GPU 批处理稀疏直接求解**与 Julia 接口[^139^]。STRUMPACK 另辟蹊径，将多波前分解与 HSS 秩结构近似结合，在大规模病态系统上以可控精度损失换取显著加速[^136^]。2026 年发表的分布式直接求解器综述将当前格局归纳为"结构稀疏（structure-sparse）"与"数据稀疏（data-sparse）"两条技术路线并存，前者以 SuperLU_DIST、PaStiX、MUMPS 为代表，后者以 STRUMPACK、ButterflyPACK 为代表[^9^]。

|---|---|---|---|---|

### 2.2 算法层面的四条演进线索

近十年直接法的算法进展可归纳为四条线索。**其一是排序与图算法的持续精化**：嵌套剖分（METIS/ParMETIS）与近似最小度（AMD）排序仍是控制填入的基石，电力矩阵因小世界特性对排序质量尤其敏感，实测表明同为 IBM 电网基准矩阵，不同求解器的因子非零元可相差数倍，直接造成分解时间差异[^11^]。**其二是通信规避与三维并行**：SuperLU_DIST 的 3D 算法在二维进程网格基础上增加冗余维度以摊薄通信，是稀疏 LU 适应百亿亿次架构的关键一步[^139^]。**其三是批处理与模式复用**：电力多场景分析（N-1 预想事故、蒙特卡洛潮流）天然产生"同一稀疏模式、数百至数千个不同数值矩阵"的批处理需求，SuperLU_DIST 9.0 与 cuDSS 均提供了 batched 接口，将符号分析成本一次性摊销[^139^]。**其四是混合精度分解**：以低精度完成 LU 分解、以 GMRES 迭代精化恢复 64 位精度的策略已进入 SuperLU_DIST 8.0 的正式接口，并以 HPL-MxP 基准的形式成为超算排名依据之一[^49^]。

这些进展共同改变了直接法的成本结构：符号分析（排序 + 符号分解）与数值分解、三角回代三者的时间占比被重新定义。在 GPU 原生实现中，数值分解与回代被加速到接近内存带宽极限后，**仍在 CPU 上执行的符号分析反而成为新的瓶颈**——cuDSS 在 335 万变量凝缩 KKT 矩阵上符号分析需 20.2 秒，而后续每次重分解仅需 0.43 秒、回代 0.17 秒[^123^]。这促使"符号分析一次化 + 数值分解高频化"成为电力在线应用的标准用法，也使符号阶段的并行化成为当前研究热点[^11^]。

### 2.3 GPU 原生稀疏直接法：cuDSS 的破局

稀疏直接法长期被认为不适合 GPU：主元选取的串行依赖、不规则内存访问与细粒度任务使其硬件利用率低下，2021 年针对电网优化 KKT 矩阵的五求解器基准测试（SuperLU、STRUMPACK、cuSolver、SPRAL/SSIDS、PaStiX）得出的结论还是"没有任何一款被测软件在 GPU 上取得显著加速"[^6^]。这一局面在 2023 年末被 NVIDIA **cuDSS** 打破：作为第一代 GPU 原生稀疏直接求解库，cuDSS 提供 LU、LDLᵀ 与 Cholesky 分解，支持混合主机—设备内存模式与多 GPU 多节点扩展，并迅速被 MadNLP、cuClarabel、QOCO 等优化求解器集成为默认 GPU 线性后端[^13^][^22^]。

性能证据已相当充分。在工业流程仿真矩阵（超百万非零元）上，cuDSS 相对 Honeywell 自研优化求解器取得 **2×–78× 冷启动加速与最高 200× 热启动加速**，且加速比随矩阵规模增大而上升[^171^]；在 IBM 电网 MNA 基准（节点数 1.4M–1.65M）上，cuDSS 将 CPU 上数十至数百秒的数值分解压缩到约 0.1 秒，**加速比达 6×–1500×**，且因子结构更紧凑[^11^]；在电力系统邻域，基于 cuDSS 的 GPU 内点法（见第 5.5 节）使大规模 AC-OPF 的求解速度首次全面超越成熟的 CPU 方案。需要指出的是，cuDSS 并非在所有情形占优：其符号分析仍在主机侧执行且多线程化后仍慢于成熟 CPU 基线，对中小规模问题收益有限；社区基准亦显示其性能优势主要集中在**大规模、可复用符号分解、多次重分解**的场景——这恰好是电力系统在线分析与优化迭代的标准形态[^11^][^168^]。

### 2.4 面向电力问题的直接法基准证据

针对电力系统的求解器评测给出了若干有实践指导价值的结论。对 OPF 内点法 KKT 矩阵（稀疏对称不定、随迭代极度病态）的系统性基准表明：**小规模（数千阶）时 cuSolver 最快，大规模（数百万阶）时 STRUMPACK 最快，而 CPU 上 MA57 仍是该类问题最高效可靠的选择之一**；所有被测 GPU 方案硬件利用率均低，计算为内存受限，主元选取导致的不规则数据搬移是 GPU 直接法的核心障碍[^6^]。对 Ipopt 十款线性求解器的独立评测进一步发现：OPF 算例的 KKT 矩阵其实并不"难分解"，串行的 MA27/MA57 即可在数百秒内解决绝大多数算例，并行求解器的开销反而拖累性能[^158^]。这些结果说明一个常被忽视的事实：**电力系统问题的求解器瓶颈往往不在分解本身，而在"病态 + 不定 + 高频重分解"的组合**，这正是 GPU 凝缩空间方法（将不定 KKT 转化为对称正定问题以避开数值主元）得以成功的逻辑起点[^20^]。

国内方面，针对电网仿真程序的对比研究验证了 KLU、SuperLU、NICSLU 等在典型电网矩阵上的适用性差异，SuperLU_MT 被成功植入状态估计程序，在多核计算机上显著缩短估计周期[^149^]。总体而言，CPU 直接法在电力系统单机应用中已高度成熟、逼近硬件极限，**增量性能正主要来自 GPU 原生实现与批处理/复用策略**，这也解释了第 5 章中各应用领域"求解器选型重心向 GPU 迁移"的普遍趋势。

## 3 迭代法与预条件技术的进展

### 3.1 Krylov 方法与 Newton–Krylov 潮流

以 GMRES、Bi-CGSTAB、CG 为代表的 Krylov 子空间迭代法将线性求解转化为矩阵—向量乘（SpMV）序列，天然适合 GPU 的粗粒度并行，但其在电力系统中的应用取决于预条件子的质量。电力潮流雅可比非对称、对角占优程度随工况变化，无预条件的 Krylov 方法收敛缓慢甚至失败。Semlyen 于 1996 年提出 Krylov 子空间潮流方法的基本框架，Flueck 与 Chiang 随后实现了牛顿—GMRES 潮流，陈颖等发展了无雅可比牛顿—GMRES（JFNK）方法并将其推广到分布式暂态稳定仿真[^119^]。代尔夫特理工大学的系统研究表明：**以初始雅可比 $J_0$（或 FDLF 矩阵）的一次 ILU(12) 乃至完整 LU 分解作为全程冻结的预条件子、配合 Eisenstat–Walker 强迫项控制内迭代精度，Newton–Krylov 潮流在大规模系统上可比直接法快数倍，且预条件子可在拓扑不变的大量场景间复用**[^114^][^117^]。

这一"一次分解、多次复用"思想在近年被进一步发展为**子空间回收（recycling）技术**：2024 年提出的 Recycling Newton–Krylov（ReNK）算法在牛顿迭代间乃至不同预想事故/负荷工况间回收 GCRO-DR 方法产生的 Krylov 子空间，在 **300–75,000 节点**系统上相对 GMRES、Bi-CGSTAB、QMR 与 LU 直接法均取得稳定加速，尤其在 N-1 分析中因基态与故障态雅可比的高度相似而收益显著[^120^]。迭代法在电力潮流中的定位因此逐渐清晰：在**超大规模系统与海量相似场景**两类情形下优于直接法，而在中小规模单次求解中直接法仍更简单鲁棒[^114^][^120^]。

### 3.2 预条件子技术：从 ILU 到 AMG 再到可学习预条件

预条件是迭代法性能的决定性因素，其谱系近年沿三个方向拓展。传统代数预条件（ILU 族、Jacobi/块 Jacobi、SSOR）在 GPU 上的并行化是首要难点——ILU 的三角结构同样存在串行依赖，ECP 项目期间 Ginkgo 团队实现了首个生产级并行阈值 ILU（ParILUT），被评价为"以算法进步抵偿五年硬件发展"[^84^]。代数多重网格（AMG）在 PDE 类椭圆问题上是渐近最优预条件，但**电网雅可比缺乏网格层级与光滑误差结构，AMG 在电力系统中的应用始终有限**，主要出现在机电—电磁混合仿真的接口解耦与少数分布式状态估计研究中；相反，多 GPU 聚合型 AMG（BootCMatchG）等库在通用科学计算领域持续演进，其求解阶段相对 NVIDIA AmgX 已取得最高 2 倍加速[^88^]。第三类是近似逆（SPAI）与多项式预条件，它们只含 SpMV 与向量运算，最契合 GPU，但预条件强度通常弱于 ILU，常作为折中方案[^84^]。

2024—2025 年间，**机器学习预条件子**成为数值线性代数与 ML 交叉的热点方向。IBM 研究院提出的图神经预条件子（GNP，ICLR 2025）用图神经网络直接学习矩阵的近似分解，在 800 余个 SuiteSparse 测试矩阵上展现出比 ILU/AMG 更可预测的构造时间与相对内外嵌套 GMRES 更快的执行时间，覆盖 PDE、经济、统计、图与优化等多类问题[^133^]。其他代表性工作包括：用 GNN 学习构造针对对流主导问题的 ILU 预条件子[^140^]、以傅里叶神经算子作无矩阵预条件使 CG 迭代数减半[^141^]、基于学习格林函数构造参数化 PDE 预条件子[^125^]。这类方法的意义在于将"一次性离线训练"的成本换取"在线每次迭代"的加速，与电力系统"拓扑固定、场景万千"的负载结构在逻辑上高度契合，但在电网矩阵上的系统性验证目前仍是空白，属于明确的机遇方向。

### 3.3 现代迭代求解软件栈

迭代法的工程能力主要由软件栈承载。**PETSc**（Argonne）提供从 Krylov 方法、预条件子到非线性 SNES、时间积分 TS 的完整层级，其抽象使电力应用可在运行时切换求解策略而不改写代码，2006 年起即被用于构建可扩展电网应用[^147^]，并成为 GridPACK 动态仿真与 ExaGO 优化平台的底层[^26^][^7^]。**hypre** 的 BoomerAMG 与 **Trilinos** 的 Belos/MueLu 分别代表分布式 AMG 与通信避免 Krylov 的最高水准，ECP 期间 Trilinos 发布了五款通信避免与流水线 Krylov 变体并在 ExaWind 风机仿真中验证[^84^]。**Ginkgo** 是新一代 GPU 中心稀疏线性代数库的代表：以现代 C++ 实现 NVIDIA/AMD/Intel GPU 的性能可移植，提供 CG/GMRES/BiCGSTAB/IDR 等 Krylov 方法与 ParILU/ParILUT/ISAI/多重网格预条件，1.9.0 版（2024 年 12 月）加入 FP16 半精度支持，并配有 Python 封装 pyGinkgo[^77^][^74^]。NVIDIA AmgX 则提供工业级 GPU AMG 与预条件迭代方法[^14^]。

值得注意的新趋势是**可微分求解栈**的兴起：torch-sla 等库将 cuDSS、STRUMPACK 与 Krylov 方法包装为可自动微分的 PyTorch 算子，单 GPU 上已实测 1.69 亿自由度的 CG 求解，打通了"物理求解器嵌入神经网络训练回路"的路径[^23^]；JAX 生态中，研究者将批量 AC 潮流完全重写于 jit/vmap 框架，在 2224 节点英国输电网与 2724 节点三相不平衡配电网算例上分别取得牛顿法 **14.3×** 与 Z-Bus 法 **12.9×** 的 GPU 加速[^121^]。这类框架虽然目前在稀疏支持上不如传统栈成熟，但为电力系统"仿真—学习"一体化提供了原生底座[^121^]。

### 3.4 小结：迭代法在电力系统中的适用边界

综合文献证据，迭代法在电力系统中的适用边界可以概括为：**（i）超大规模稳态问题**（数十万节点以上潮流、潮流雅可比-free 的 JFNK 动态仿真）中，Newton–Krylov 配合冻结 ILU/LU 预条件可稳定超越直接法[^114^][^120^]；**（ii）多场景批量问题**中，子空间回收与预条件复用使迭代法的边际成本趋近于 SpMV 成本，这是直接法难以企及的结构优势[^120^]；**（iii）强病态不定问题**（OPF KKT、Hachtel 增广矩阵）中，迭代法的收敛依赖条件数，预条件设计尚不如直接法成熟，目前主流仍是直接法或将问题变换为 SPD 后再迭代[^20^]；**（iv）电磁暂态等"固定矩阵、纯回代"问题**中，迭代法无优势，预分解直接法不可撼动。换言之，迭代法并非直接法的替代，而是在特定问题结构上的性能补集，两者在现代电力软件栈中长期共存、按场景路由。

## 4 新兴范式：混合精度、量子与机器学习

### 4.1 混合精度与迭代精化

AI 芯片的算力结构变迁（FP16/FP8 张量核心算力百倍于 FP64）推动混合精度从技巧上升为主流算法范式。其核心模式是：**以低精度完成计算密集的分解或预条件，以高精度残差驱动迭代精化恢复全精度解**。HPL-MxP 基准将"低精度 LU + GMRES 精化"确立为超算性能度量标准，要求达到与传统 HPL 相同的 64 位后向误差[^49^]。在稀疏领域，SuperLU_DIST 8.0 已内置单精度分解 + 双精度迭代精化接口[^139^]；Ginkgo 1.9.0 原生支持 FP16 作为矩阵/求解器/预条件子值类型[^77^]；神经网络类混合求解器普遍采用"FP32 预条件 + FP64 残差"的运行时配置[^137^]。对电力系统而言，混合精度的适用性需谨慎评估：潮流与状态估计的雅可比/增益矩阵条件数适中，单精度分解 + 精化通常足够；但 OPF KKT 在内点迭代末期条件数可达 $10^{16}$ 以上，低精度预条件的精化收敛可能恶化，目前 GPU 内点法实践仍以 FP64 为主[^20^]。混合精度在电力仿真中的系统性误差分析（特别是与 PMU 量测精度、模型参数不确定度的比较）是有价值但尚缺位的研究。

### 4.2 量子线性求解器：承诺与现实的落差

Harrow–Hassidim–Lloyd（HHL）算法理论上以 $O(\log N)$ 复杂度制备线性系统解的量子态，很快被引入电力系统：研究者将其嵌入牛顿—拉夫逊迭代求解 AC/DC 潮流，或在 IPM 框架内求解 KKT 系统[^44^][^45^]；2021 年 WSCC 9 节点系统上的首次真机 DC 潮流实验完成[^47^]；PNNL 基于 NWQSim 构建了电力—量子混合框架，通过门融合与 GPU 加速仿真使 IEEE 测试系统潮流研究取得相对 Qiskit Aer 最高 8 倍的效率提升[^31^]。然而，洛斯阿拉莫斯国家实验室对端到端复杂度的严格分析给出了降温结论：**计入态制备、条件数依赖与读出成本后，HHL 类量子潮流对 DCPF 与 FDLF 的运行时间复杂度高于经典算法**；实际量子优势仅可能存在于条件数与读出要求都落在极窄窗口的 DCPF 型问题中，且该结论可推广到任何有严格性能保证的量子线性求解器[^42^][^43^]。硬件现实同样严峻——迄今真机可精确求解的线性系统不超过 4×4[^31^]。

量子路线的当前研究重心已相应调整：一是变分量子线性求解（VQLS）与量子机器学习以降低线路深度，如用数据依赖变分量子电路学习 AC 潮流解[^30^]；二是将量子例程嵌入 ADMM/拉格朗日分解处理机组组合等组合子问题[^29^]；三是抗噪量子内点法，以非精确可行 IPM 容忍 HHL 的固有误差[^44^]。综合判断，量子线性求解器在电力系统分析中**短期内不具备工程价值，中长期价值取决于容错量子计算与 QRAM 的突破**，其意义更多在于为电网问题的复杂度结构研究提供新视角[^45^]。

### 4.3 机器学习代理与学习型求解

机器学习对电力计算的介入可分为三个层级。**最浅层是"代理模型"**：直接以神经网络逼近"负荷输入→潮流/OPF 解"的映射。香港城市大学陈名华团队的 DeepOPF 系列开创了这一方向——"预测—重构"框架先以 DNN 预测发电调度、再用潮流方程直接重构相角，DC-OPF 上取得 **<0.2% 最优性损失与最高 100× 加速**[^164^]，后续 AC-OPF 版本在 2000 节点系统上报告了 **15,000× 加速**[^165^]；DC3 框架确立了"预测—补全—校正"的约束学习范式[^174^]；图神经网络潮流代理（如 PI-GAT）在批量 64 场景推理下相对牛顿法取得 **398.65×（IEEE 30）与 257.24×（IEEE 118）加速**，单场景亦有 8–17×[^40^]。**中间层是"学习增强求解"**：用神经网络提供热启动初值或预条件（见 3.2 节），保留经典求解器的精度与收敛保证。**最深层是"可微分求解"**：将求解器本身嵌入学习回路（torch-sla、JAX 潮流），服务于反问题与参数辨识[^23^][^121^]。

对代理模型必须保持清醒认识：其加速比建立在"离线训练成本不计入 + 仅前向推理计时 + 拓扑固定"三个前提上[^40^]；AC-OPF 的可行性与多值映射问题需要同胚投影、增广学习等专门机制保障[^165^][^174^]；Google DeepMind 发布含拓扑扰动的大规模 OPF 数据集 OPFData，正反映了社区对"代理模型泛化到拓扑变化"这一关键短板的对齐努力[^163^]。因此，**ML 代理当前的合理定位是海量场景初筛与热启动提供者，而非精确求解器的替代**；其与直接法/迭代法的关系更接近"前端过滤器"，将值得精确求解的场景压缩到传统方法可承受的规模。图 2 汇总了各条技术路线报告的代表性加速比。

## 5 在电力系统分析中的应用进展

### 5.1 潮流计算：从 KLU 到 GPU 批量潮流

潮流计算是求解器技术在电力系统中应用最深、历史最长的领域。当代工业实践的基线是**牛顿—拉夫逊 + 稀疏 LU 直接法**：MATPOWER 等工具默认使用 LU 分解雅可比，KLU 因其对电网矩阵块三角结构的利用而成为常用的高性能替代，实测相对 MATPOWER 默认配置约快 10 倍，相对朴素实现快两个数量级以上[^21^]。快速解耦潮流（FDLF）以常矩阵 $B'$、$B''$ 实现"一次分解、永久复用"，至今仍是 EMS 在线应用的主力[^151^]。在超大规模与多场景方向，Newton–Krylov 与子空间回收（3.1 节）已被证明可稳定超越直接法，75,000 节点级系统的 N-1 分析中回收 Krylov 子空间使每个故障态的内迭代显著减少[^120^]。

GPU 化是近年潮流求解最活跃的方向，其技术路线分化明显。早期 cuSOLVER 的稀疏 QR 路径被证明慢于 CPU 基线而无法扩展[^11^]；MadNLP 团队早期方案在 GPU 上以 cuSOLVER 稀疏 QR 或 Krylov.jl 的 BiCGStab 求牛顿步[^80^]；cuDSS 的出现使 GPU 直接法潮流首次具备实用性能，其批处理接口与 JAX 生态结合后，批量 AC 潮流相对 CPU 取得 14.3×（2224 节点输电网）加速[^121^]。另一条路线是完全绕开牛顿迭代的 ML 代理（4.3 节），在批量场景下加速比可达数百倍[^40^]。综合来看，**潮流求解正形成"单次精确求解用 GPU 直接法、海量场景用 ML 代理初筛 + 精确法复核"的双层结构**，这一结构也正向状态估计与安全分析扩散。

### 5.2 状态估计：数值健壮性驱动的求解器选择

状态估计（WLS）每轮迭代需求解增益方程 $H^\mathsf{T}WH\,\Delta x = H^\mathsf{T}W\Delta z$。法方程的 SPD 结构允许使用高效 Cholesky/LDLᵀ 分解，但零注入节点、量测权重悬殊会导致严重病态，引发振荡甚至发散[^65^]。对此，工业界形成两条数值健壮化路线：其一是 **Hachtel 增广矩阵法**，将等式约束以拉格朗日乘子引入、求解对称不定的增广系统，数值健壮且保留稀疏性，代价是需调优参数且不定分解更慢[^60^][^70^]；其二是**正交分解（QR）与零空间法**，数值稳定性最好但速度较慢，近年针对配电网不平衡状态估计发展的稀疏零空间基方法在保留稀疏性的同时消除了调参需求[^70^]。这体现了状态估计求解器选型的核心矛盾：**SPD 法方程最快但病态下不可靠，增广/正交方法可靠但更贵**。

高性能化方面，PNNL 于 2015 年实现了真实数据验证的**亚秒级状态估计**，其关键在于稀疏三角分解优化、量测预处理与多核并行[^161^]；国内研究将 SuperLU_MT 并行稀疏直接求解库植入状态估计的迭代求解与坏数据辨识环节，在多核平台显著压缩估计周期[^149^]；大区互联电网则采用"分区估计 + 边界协调"的分布式计算架构[^159^]。总体看，状态估计的求解器进展不如潮流/OPF 活跃，其性能提升主要来自复用潮流领域的分解技术与平台级并行，而面向 PMU 混合量测的**动态状态估计**与 GPU 化增广矩阵求解仍是较为开放的问题[^159^]。

### 5.3 暂态稳定与动态仿真：超实时计算的实现

时域仿真的求解器负载取决于积分框架：**交替显式方案**（网络代数方程与机组微分方程交替求解）每步只需对小规模接口量迭代，配合快速 LU 分解与三角回代即可，但数值稳定性要求小步长；**联立隐式方案**（Simultaneous-Implicit）将全系统 DAE 联立、以牛顿法求解，步长大且稳定，但每步需求解大规模组合雅可比，对线性求解器带宽要求高[^26^]。PNNL 的 GridPACK 平台基于 PETSc 时间积分器（TS）实现了两种方案的并行对比：20 秒动态仿真中，联立隐式方案凭借变步长将时间步数大幅压缩，**16 进程时耗时 12.9 秒，比交替显式（18.1 秒）快约 30%，两种方案均实现超实时**[^26^]。无雅可比牛顿—GMRES（JFNK）方法通过矩阵—向量乘差分近似避免显式组装雅可比，已被用于分布式暂态稳定仿真[^119^]。

中国的工程实践代表了另一条极具特色的路线。国家电网 2015 年启动建设的新一代仿真平台包含世界首套基于超算的电力仿真专用系统，**支持国网主网全网架仿真，计算规模达 45,000 节点**[^97^]；中国电科院研发的全过程动态仿真程序解决了 EUROSTAG 等程序数值迭代收敛性差的问题，可模拟 **50,000 节点以上**系统从数秒到数小时的动态全过程[^97^]。这些系统的共性是将稀疏求解器、分网并行与专用硬件深度耦合，以工程化手段而非单一算法突破换取规模上限。美国方面，实时数字仿真（RTDS、HYPERSIM）与 GridPACK 的超实时离线仿真互补，共同支撑在线动态安全评估。综合而言，**机电暂态仿真的求解器问题已基本工程化解决，当前瓶颈已转移至电磁暂态尺度**。

### 5.4 电磁暂态仿真：分网并行与异构计算的国产突破

EMT 仿真以微秒级步长对节点电导矩阵做"一次分解、数十万步回代"，线性求解的绝对成本低但频率极高，其高性能化的核心在于**分网并行与多速率仿真**：利用输电线路分布参数模型的行波解耦或节点分裂法将大网分割为子网并行求解，ADPSS 即采用"节点分裂 + 边界点电压联立"的分网并行算法实现任意点分割[^107^]。中国电科院 ADPSS（周孝信院士团队）历经近十年攻关，2017 年攻克 50 微秒实时仿真步长（1 秒内对华东电网 6000 节点完成 2 万次计算），发展至 ADPSS 3.0 后实现**不低于 8000 母线、300 台风机的全电磁暂态实时仿真**、多时间尺度并行与跨计算节点仿真，建模时间由"月"级缩短至"十分钟"级，并已部署于百余家单位[^95^][^96^]。

清华大学陈颖、宋炎侃团队的 **CloudPSS** 则开创了云原生电磁暂态路线：以自动代码生成器将仿真任务编译为适配 CPU/GPU 异构设备的虚拟仿真引擎，实现细粒度 GPU 并行[^48^]；其百万节点级超算云仿真平台支持 **120 万以上计算节点**（含 20 万电气节点）、5000 台以上新能源详细模型，**百万节点系统 2000 场景 2 秒过程（50 μs 步长）采用 64,000 核并发仿真耗时 <15 分钟**，十万节点级 10 秒过程在 512 核上耗时 <18 秒，并完成对申威等国产处理器的适配[^73^]。2019 年该成果经鉴定被认为"国际首创、总体技术国际领先"[^68^]。对比国际同类（PSCAD、RTDS、HYPERSIM），中国在**全电磁暂态的大规模化与云化**上已形成差异化领先，其底层支撑正是稀疏节点方程求解与异构并行架构的深度协同[^58^]。

### 5.5 OPF 与 SCOPF：从 Ipopt+MA57 到百亿亿次级求解

OPF 是求解器技术竞争最激烈的电力应用。自 Dommel–Tinney 1968 年奠定问题形式后[^150^]，**原对偶内点法（IPM）+ 稀疏对称不定直接求解器**成为 2000 年代以来的黄金组合：Ipopt 默认配 MUMPS，工业实践首选 HSL MA27/MA57/MA97，大规模算例中 MA57 表现最优，PARDISO 与 HSL 相当[^158^][^162^]。这一格局的物理原因在于 OPF KKT 矩阵随内点迭代趋于极度病态，需要 LBLᵀ 分解配合精细数值主元策略保证精度——而这恰是 GPU 上最难并行的操作[^20^]。

GPU 时代的破局思路是**改变问题结构而非硬搬算法**，形成了两条已被验证的路线。**路线一：凝缩空间内点法**。将 KKT 系统通过 Schur 补/正则化凝缩为对称正定矩阵（HyKKT）或提升稀疏模式（LiftedKKT），从而可用 GPU 上高效的 Cholesky/LDLᵀ（cuDSS）求解，配合 MadNLP（滤波线搜索 IPM）与 ExaModels（SIMD 自动微分）构成全 GPU 驻留栈：在 PGLIB-OPF 基准上相对 Ipopt+MA27 取得**最高约 10× 加速**，ExaModels 的 GPU 自动微分相对 JuMP 达 300×，对 case30000 等三万节点级算例优势显著[^75^][^89^]；误差分析表明凝缩系统虽条件数增大，但 IPM 固有结构可补偿精度损失[^20^]。同一范式在锥优化中复现：QOCO-GPU 以 cuDSS 做 LDLᵀ 分解取得 50–70× 加速[^13^]。**路线二：两阶段分解 + 稠密化压缩**。ExaSGD 项目在确认"无可高效运行于 GPU 的病态不定稀疏直接求解器"后，彻底重构技术路线：以 HiOp 的两阶段分解将 SCOPF 拆为基态主问题与数千个预想事故子问题，子问题经定制稠密—稀疏线性代数压缩为小型稠密问题，转由 GPU 上成熟的稠密求解器（MAGMA）处理[^3^]。项目期间 HiOp 通过线性代数压缩技术将 GPU 求解速度提升约 100 倍，最终于 2023 年在 Frontier 超算 **9,000 节点上 20 分钟内完成 10 万+预想事故与天气场景的安全最优调度**——相较调度员惯常的 50–100 个手工选取预想事故，实现了穷举式安全分析[^4^][^7^]。

两条路线的分野具有普遍方法论意义：**当问题的病态不定线性系统在目标硬件上没有高效求解器时，可以在算法层把问题变换为有好求解器的形式（凝缩/分解/稠密化），而不是等待求解器进步**。此外，ARPA-E 电网优化（GO）竞赛推动了 OPF 求解器工程化水平的整体跃升[^163^]，ML 代理（4.3 节）则在 OPF 领域最先形成"代理初筛 + 精确复核"的实用模式[^164^][^174^]。对 SCOPF 这类超大规模结构优化问题，分解协调（ADMM、Benders、原问题分解）与底层求解器的协同设计已成为标准范式[^1^]。

### 6.3 开放挑战与未来趋势

**挑战一：GPU 符号分析与三角回代的短板。** cuDSS 等 GPU 原生求解器将数值分解加速至带宽极限后，主机侧符号分析与本质上串行的稀疏三角回代成为阿姆达尔瓶颈[^11^][^123^]。电力应用"符号一次、回代百万次"（EMT）与"符号一次、重分解千次"（IPM、N-1）的模式放大了这一问题，符号阶段并行化与 GPU 三角求解的任务图化是未来三年最确定的工程攻坚点。

**挑战二：病态不定系统求解的硬件适配。** OPF/SCOPF 的 KKT 矩阵暴露了"算法难度"与"硬件适配"的错位：LBLᵀ 数值主元在 CPU 上成熟而 GPU 上低效，凝缩/分解路线是绕道而非攻克[^20^][^3^]。能否设计原生支持 GPU 的鲁棒不定分解（如稀疏秩结构近似 + 迭代精化），决定了大规模随机/鲁棒 OPF 的求解上限。STRUMPACK 的秩结构多波前与 H 矩阵方法是有潜力的候选[^136^][^9^]。

**挑战三：精度、可信与标准化。** 混合精度在电力仿真中的误差传播缺乏系统研究；ML 代理的可行性、泛化（拓扑变化）与最坏情形保证仍是工业采纳的门槛[^174^][^163^]；电力矩阵基准方面，SuiteSparse 矩阵集虽已收录电力网络类矩阵[^127^]，但缺乏覆盖潮流/OPF/动态雅可比的开放标准基准集，导致各文献加速比基线不一、难以横向比较（图 2 的注记即为此而设）。CSEE 新型电力系统标准算例的发布是朝此方向的重要一步[^95^]。

**趋势判断。** 未来五年可预期的演进包括：（i）**求解器异构路由常态化**——电力软件将按问题规模、矩阵特性与求解频次在 CPU 直接法、GPU 直接法、Krylov、ML 代理间自动路由，类似 NICSLU 当年的"并行适用性预测"思想在更大尺度上的回归[^72^]；（ii）**"仿真—学习"一体化**——可微分求解栈使代理模型与精确求解器形成闭环（代理初筛、热启动、精确复核、残差回流训练）[^23^][^121^]；（iii）**国产求解器生态补齐**——在 NICSLU/CKTSO（电路级）、ADPSS/CloudPSS（系统级仿真）之外，面向 GPU 的自主稀疏直接求解库与优化内核是新型电力系统软件自主可控的下一个关键环节[^57^][^58^]；（iv）**百亿亿次级安全分析走向生产**——ExaSGD 证明穷举式 SCOPF 在算力上可行，其与调度运行 30 分钟决策窗口的兼容将推动在线安全分析范式从"筛选式"转向"穷举式"[^4^][^7^]。

## 结语

高性能线性代数求解器与电力系统分析的关系，是一部"需求牵引算法、算法解放需求"的协同演化史：Tinney 的稀疏三角分解源于电网又反哺了整个科学计算；今天 GPU 原生稀疏直接法（cuDSS）、凝缩空间内点法与分解协调框架，正在把电网分析从"万节点、单场景、离线"推进到"百万节点、十万场景、在线穷举"的新量级。对电力系统研究者而言，把握三条主线——**直接法的 GPU 原生化和批处理化、迭代法的预条件复用与子空间回收、以及 ML 代理与精确求解的分层协同**——比追逐任何单一"银弹"技术都更为重要；对求解器研究者而言，电力系统提供的极端稀疏、小世界结构、病态不定与高频重分解的组合特征，仍是检验新算法价值的最佳试金石之一。
