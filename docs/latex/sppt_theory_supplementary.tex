\section{Operator-Algebraic Restatement}\label{sup:operator}
%=======================================================================

For practitioners preferring an operator view to a categorical one, the
semantics-preserving projection is the tuple
$(\Projex,\Projeps,\Att,\role,\wp)$ where:
\begin{align*}
\Projex &= \Del\circ\Mrgex\circ\Exp\circ\Nrm
      &&\text{(exact rich-to-canonical projection)},\\
\Projeps &= \Del\circ\Mrgeps\circ\Exp\circ\Nrm
      &&\text{(threshold projection with error certificate)},\\
\Att  &= (\text{broadcast})\oplus(\text{origin attribution})\oplus {}\notag\\
     &\qquad (\text{participation split / audit map}),\\
\role &: \text{mode}\mapsto(u_{\mathrm{ctrl}},u_{\mathrm{free}},\pi_{\mathrm{ref}})
      &&\text{(control-role typing)},\\
\wp   &= \big[\forall j:\ n^{\angle}_j=1\big]\wedge
          \big[\forall k:\ n^{V_{\mathrm{dc}}}_k\ge 1\big]\\
      &\qquad \text{(reference well-posedness gate)}.
\end{align*}
The core identities and contracts are $\Nrm^2=\Nrm$,
$\Pi_\star\circ\iota\circ\Pi_\star\cong\Pi_\star$ for
$\Pi_\star\in\{\Projex,\Projeps\}$,
$\Att\circ A_{\mathrm{can}}\circ\Projex = A^{\mathrm{ref}}$ on
$\Obsstr$, the bounded-error statement of the threshold-error bound (main text)
on $\Obsapprox$ for $\Projeps$, conservation-only accounting on $\Obsaudit$, and
$\Pi_\star(\cdot\oplus_\Sigma\cdot)=\Pi_\star(\cdot)\bowtie_\Sigma\Pi_\star(\cdot)$
only under clean-interface assumptions.

\subsection{Commands and verification boundary}

Every artifact in the paper builds from the repository with the standard CMake
preset and is exercised by \code{ctest}; empirical tables and figures are
auto-generated.
\begin{itemize}[leftmargin=1.5em]
  \item \textbf{Build}: \code{cmake --preset macos-release} then
  \code{cmake --build --preset macos-release}.
  \item \textbf{Campaign}: run \code{sppt\_scale\_fault\_campaign} with an
  output path, 25 repetitions, and seed 20260818; then run the campaign plotting
  script on that output directory.
  \item \textbf{Determinism}: two complete campaign runs have identical 1575
  sample rows after excluding only \code{validation\_ms},
  \code{projection\_ms}, \code{guard\_ms}, and \code{solve\_ms}; summary and
  manifest CSV files are byte-identical.
  \item \textbf{Focused tests}: \code{test\_sppt\_fault\_campaign} passes 19
  assertions and \code{test\_validation} passes 178 assertions in the campaign
  Debug build.
  \item \textbf{Other proof-carrying tests} (Catch2):
  \nolinkurl{test_sppt_metamorphic} (MR1--MR7),
  \nolinkurl{test_sppt_dae_wellposedness} (MR8 $+$ transient MR3);\hfill\break
  \nolinkurl{test_sppt_certificate}, \nolinkurl{test_sppt_guard};\hfill\break
  \nolinkurl{test_sppt_ablation}, \nolinkurl{test_sppt_benchmark}, and
  \nolinkurl{test_sppt_agent}.
  \item \textbf{Other evidence}: certificate, ablation, external-engine,
  benchmark, cross-check, and agent-demo tools generate the supplementary scope
  checks and guarded trajectory.
  \item \textbf{Live services}: \nolinkurl{run_gui_server} exposes
  \nolinkurl{/api/session/sppt_guard} and \nolinkurl{/api/session/sppt_agent}.
  \item \textbf{Source}: the theory layer is \nolinkurl{include/hacdcpf/sppt} and
  \nolinkurl{src/sppt}; every object maps to code through the crosswalk of
  \Cref{sup:tab-crosswalk}.
\end{itemize}
Because the main-text figures are generated from CSV rather than manually
transcribed, rerunning the two commands refreshes the evidence chain. The
reported campaign used a Debug build because the local sibling dependency was
dirty and the repository refused a clean Release artifact. Correctness does not
depend on timing, but the four wall-clock columns are development diagnostics and
must not be cited as optimized performance measurements.
