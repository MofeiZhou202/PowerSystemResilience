# 配电参数补全标准对照表

## 契约

模型 IO（Model IO）参数补全工作流是来源感知的（provenance-aware）。它只会替换缺失的字段，或明确标记为导入器/手册估算值的字段。制造商铭牌、公用事业资产台账以及用户自行编写的参数不会被覆盖。

实现区分三种依据类型：

- `normative_parameter_table`：数值直接取自标准表格，例如 20 C 下的导体电阻；
- `normative_calculation_method`：输入值是项目特定的，但其换算遵循标准方法；
- `engineering_assumption`：源文件缺少所需的资产数据，使用可配置的筛查取值。

| `ACBus.base_kv` | SVG 导入选项或当前生效的参数档案 | 标准电压背景 | GB/T 156-2017 / IEC 60038 | 以图纸/项目标称电压为准。 |
| `ACBus.vmin_pu`、`vmax_pu` | 当前生效的参数档案 | 电能质量背景 | GB/T 12325-2008 | 研究用运行限值可能更严格，且保持可编辑。 |
| `ACSystem.freq_hz` | 当前生效的参数档案 | 频率背景 | GB/T 15945-2008 | 以互联系统声明为准。 |
| 估算的变压器终端负荷 | `Sn * load_factor * power_factor` | 工程假设 | 对通用馈线负荷因子，未援引任何国家标准。 | 用于规划决策前，应以 AMI/SCADA/规划需求数据替换。 |

## SVG 自动补全

`SvgDistributionImportOptions::auto_complete_parameters` 默认为 `true`。
导入器首先还原忠实于来源的标识与图纸几何信息，将所有虚构的电气字段标记为
`svg_geometry_estimate`，随后调用共享的设计手册补全工作流。将该选项设为 `false`
会保留初始的可配置 SVG 估算值。

补全报告返回每条建议、置信度、动作、标准来源、变更字段数以及参考文献列表。
严格导入（strict import）仍然会拒绝该格式，因为几何比例、电源强度与负荷需求
仍为推断值。
