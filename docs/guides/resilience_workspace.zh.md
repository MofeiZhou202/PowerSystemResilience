# 弹性 Web 工作区使用说明

## 第一次使用

1. 打开 `/xjtu/`，默认进入首页。点击“体验 33 节点演示”，加载
   `dist33_weather_mixed`，预选后端目录中可用的指标，并设置一个 TD 等级、
   一个代表簇。演示只准备输入，生成和求解均由用户点击启动。
2. 在场景页选择台风、暴雨内涝或雷暴雷击，设置参数，点击“生成弹性候选场景”，生成后选择一个代表场景。
3. 按“建议下一步”进入快速恢复，按需切换“考虑移动储能调度”后运行。故障与修复时间自动来自所选场景。
   轻度灾害可能没有设备故障；可提高台风强度、重新生成并选择场景，观察供电损失。
4. 到指标输出页计算结果。核心指标卡片在前，完整表格和导出在后。
   计算摘要位于结果末尾，默认折叠。

“新建分析”提供常规场景设置，同样预选可用指标；可以在指标选择页自定义。
指标选择页只选要计算的指标；t_sp 恢复目标、指标事件时刻和近似授权均采用后端默认值，暂不要求填写。
快速恢复只提供移动储能调度开关；可在“在电网中查看故障”展开项定位故障支路。其余恢复设置使用平台默认值，长篇计算依据收在结果下方。
工作流上方保留前一步和下一步提示。顶层导航支持键盘方向键和浏览器前进／后退。

## 暴雨内涝和雷击

暴雨可设置累计雨量、历时、排水能力；电缆附件受淹入口高度来自算例资产数据。雷击可设置地闪密度、
闪络阈值、永久损坏比例和修复时长。高级参数展开后可调整雨峰、电流分布等。
切换灾种保留已输入参数，“恢复本灾种默认参数”清除该灾种的修改。

结果页显示灾害过程和故障时间，恢复页自动采用给定停运窗口，包含等待退水或雷暴结束。
暂时跳闸按等效停运时间解除，不消耗永久损坏的修复时长。
默认指标灾害结束时刻仍为最后一次故障发生时刻。

这两个生成器按架空线、电缆附件、绝缘子和支路关联变压器区分影响，参数用于研究演示，
没有二维地形洪水或秒级雷电暂态。公式、字段和已验证边界见[实现契约](../modules/resilience/weather_scenarios.md)。

## 保存、继续和复制方案

- “保存版本”保存当前电网、场景和恢复设置、指标口径以及已有结果，新增版本而不覆盖旧版。
- 指标成功返回后自动保存一个版本；保存失败会明确提示，当前计算结果仍保留在页面。
- “我的分析”按名称搜索版本，可继续、复制为独立方案或导出 JSON 分析文件。
- 打开保存版本会将模型导入当前后端会话，并恢复场景与参数。历史运行 ID 不重新激活，
  当前分析需要重新运行；旧版本的指标计算覆盖值不会用于新计算，保存的指标和恢复曲线仍可在结果对比页查看。
- 新建分析前，若已有加载模型，先保存当前版本；保存失败时不清空当前工作。
- 文件导入创建独立副本，不自动加载模型或执行求解。导入文件和单个保存版本上限为 32 MiB。

**保存位置是当前浏览器、当前站点地址的 IndexedDB**，不是服务器项目数据库。
浏览器刷新或后端重启不会清除这些版本；更换浏览器、主机名或端口不会共享数据。
清理网站数据会删除记录。跨电脑迁移和备份应使用导出的分析文件。
此版本没有多人共享、账号权限或跨设备同步。

## 计算任务与结果对比

计算任务记录场景生成、快速恢复和指标计算的请求开始／结束时间、状态和错误。
运行中显示实际经过时间；同步求解接口没有提供内部阶段事件或百分比。
恢复计算的取消按钮调用既有任务管理器，请求取消不等于求解器已确认停止。
页面刷新后未收尾的本地任务标记为中断，不能推断后台结果。
历史任务可导航到当前计算步骤或保存的分析，不会自动重试。

结果对比支持选择 2～4 个保存版本，也可以单独查看一个版本的曲线和指标。
对比电网模型、场景及故障设置、时间轴、指标定义版本和计算口径；不一致时仅并列展示。
导入结果、过期结果或缺少完整运行依据的结果也不计算差值。
同一边界下只有 `computed`、非截尾且单位相同的有限数值计算相对第一个版本的差值；
比例指标差值使用“百分点”。没有自动综合排名或未经定义的综合评分。
导出对比 JSON 保留完整版本、参数、状态和不一致原因。

恢复设置中可展开“在电网中查看故障”，按 **AC/DC 域 + 稳定支路 index** 定位。
缺少唯一映射或大系统总览不支持定位时返回提示，不跨域查找同号设备。

## 实现与验证入口

| 项目 | 实现与口径 |
|---|---|
| 本地保存 | `web/js/core/resilience_workspace.js`，数据库 `hysim-resilience-workspace`，`versions` / `tasks` stores |
| 文件版本 | `resilience_workspace_v1`，`model` 为当前 Canvas rich-model 序列化，`state` 为显式白名单字段，`catalog` 为后端目录快照 |
| 后端操作 | 继续使用模型 JSON 导入、场景生成、快速恢复、指标 evaluator 与取消接口；未新增计算算法或 HTTP 路由 |
| 运行隔离 | 历史结果只读；重新打开不恢复后端 run handle；恢复参数编辑将旧结果标记过期 |
| 界面 | `resilience_portal.js` / `resilience_workspace.js` / `resilience_portal.css`，仅 Resilience 版启用 |
| 回归 | 已注册的 `tests/e2e/resilience_edition_gui_e2e.mjs`；实时验证记录见开发状态 |

数值公式及指标范围见[指标契约](../modules/resilience/metrics.md)，
