# 电力市场仿真操作教程

适用界面：`/xjtu/` 的“电力市场”。先选择“市场模型”，再按下列路线操作。
页面切换只改变查看位置，不代表计算完成，也不会把一个市场的结果自动传入另一个市场。
顶部“分步教程”和各页“本页帮助”提供可跳转的操作步骤；“操作手册”打开本文。

## 原因分析与等待时间

运行模拟的“恢复重算”默认在缺额、富余或线路越限出现时自动执行。
在边界设置中将“触发方式”改为“每一天”可检查没有异常的日子；选择“仅手动”
或关闭开关后，仍可在结果的当日原因区点击“补算当日原因”。
先选择日期和场景，再选补算范围：供需归因运行 SCUC/SCED；完整重算额外运行 LMP。
默认供需归因不计算恢复价格，主任务的价格正常计算。
“未执行恢复实验”不代表因素影响为零。补算固定历史日初水量、SOC、机组状态和次日
预测，不推进日期，也不覆盖原出清和后续状态。最近补算耗时单列显示。
求解计时表区分环境初始化、模型导入、优化、提取与释放；“优化”包含预处理和搜索，
不是仅整数搜索。计时在请求返回后显示，执行中仍看顶部活动状态及已等待时间。
价格一致性表显示“通过：精确一致”后才允许使用本次价格。百万列及以上 Gurobi 定价
固定为 8 线程障碍法，两份独立新实例同时求解；其他定价固定单线程对偶单纯形。
同一 LP 的全部行对偶必须精确一致；复算耗时单列，并发耗时不能相加。检查失败时价格为空，
不能结算，请查看失败状态，不能用零价替代。调度算法选项仅影响 SCUC/SCED。
这保证同一模型、同一后端版本和平台的可重复选取，不代表数学上的对偶只有一个解。
历史结果显示“未检查”；恢复实验改变边界后的价格不能视为同一定价 LP 的重复结果。

## 先选哪条路线

| 想做什么 | 市场模型与页面 | 数据和结果归属 |
|---|---|---|
| 第一次跑通一天 | 南方规则研究 → 边界与单日出清 | 独立南方边界，单日 SCUC / SCED / LMP |
| 观察一周或一月运行 | 南方规则研究 → 运行模拟 | 手工滚动任务；预测模式另存场景任务 |
| 比较停运、来水和报价影响 | 南方规则研究 → 对比试验 | 独立试验；安全与研究账本在“分析环节”中选择 |
| 研究调频预安排、调用和费用 | 南方规则研究 → 云南调频 | 本页能量与调频出清、本页月度账本 |
| 研究实时预测和状态滚动 | 南方规则研究 → 实时市场 | 独立实时任务及滚动批次 |
| 通用交直流报价博弈、N-1、双结算 | 通用 AC/DC 市场研究 | 工程画布电网、通用市场结果 |

南方五页是五个工作入口，不是必须按顺序执行的五个市场阶段。
首次使用推荐两节点演示；2000 节点案例需要较多时间和内存，不适合作为首次操作检查。
IEEE118 的水火风光储、报价和来水为合成研究边界，不是南方实际运行数据。

## 教程一：跑通单日演示

1. 进入“电力市场”，市场模型选择“南方规则研究 · 2025”，打开“边界与单日出清”。
2. 在“市场算例”选择“南方多资源两节点演示（风光水火储/可控负荷）”，点击“加载市场算例”。
   成功标志：摘要显示 2 节点及机组、储能、水库和可控负荷数量，状态显示边界修订号。
   **加载算例会替换南方市场边界并使原结果失效。**已有边界应先“导出边界”。
3. 保持“边界数据”选中。选择“边界类别”和“实体”，核对统调/母线负荷、机组申报、
   水库来水、储能初态及“执行解释 / 求解”。首次保留演示值，使用服务端列出的可用求解器。
4. 修改字段后点击“保存边界”，等待修订号更新。如果出现校验错误，按路径定位到对应类别和实体，
   修正数值、单位、时间点数或稳定 ID。保存成功前不要把本地草稿当成生效边界。
5. 点击“南方规则出清”。这是实际计算，会依次生成机组组合、经济调度和独立定价结果；
   每天 96 个 15 分钟点，另有次日峰谷 2 个前瞻点。97/98 点不能再计为当日实结电量。
6. 返回后在“出清结果”中选择计算阶段和时点。依次检查排程可行性、缺额/富余、线路越限、
   交流安全、价格有效性和模型限制。`schedule_only` 表示仅排程，不能当作交流安全通过。
7. 需要复现时分别“导出边界”和“导出结果”。“设为基准 / 恢复基准边界”操作的是南方边界，
   不会把通用工程电网变成同一份数据。

## 教程二：周 / 月运行模拟

本页仅显示当前滚动任务，故障/来水试验已移到独立页面。

1. **选择算例**：核对当前已保存边界；需要换案例时才点“加载算例”。点击“下一步：设置市场边界”。
2. **设置市场边界**：首次选择“手工周 / 月边界”，设定起始日期和一周，保持各倍率为 1，
   不增加停运。检查各日和最后一天之后的前瞻预测；周计划需要 8 日预测供 7 日出清。
   完整逐设备边界和报价仍由“编辑完整边界与报价”进入南方边界页维护。
3. 点击“确认边界并继续”，在第 3 步点击“开始仿真”。任务逐日出清并承接状态；
   “当日结束后暂停”会等待当前日窗结束，“继续仿真”续算剩余日窗。
4. 在“4 结果与原因”选择日期和时段，查看全设备运行计划、机组开停机热力图、功率、
   水库水位、储能 SOC 和可控负荷。筛选设备后可查看完整周曲线及导出 CSV。
5. 缺额/越限诊断和交流安全结论分别查看。诊断排程允许报告物理缺额，不等于安全可执行计划。
   返回第 3 步“导出报告 JSON”保留所有日窗、求解状态及限制。

**预测模式**：在第 2 步选择“预测场景”，配置概率分布或区间、场景数、种子、预测中心及相关矩阵。
先点击“生成一周市场边界”，再进入第 3 步“逐日出清全部场景”；第 4 步选择场景查看结果。
区间模式不声明发生概率，概率模式的统计仅对应所配置分布和实际完成的样本。
手工任务与预测任务分别保存，切换模式不会把它们合并。

### 每天的初始状态从哪里来

第一天使用建任务时的初态，后续天使用前一天 **SCED 第 96 个实际时段的日末状态**。
第 97、98 点只是次日峰谷参考，不用于推进状态；LMP 也不用于更新物理状态。

| 对象 | 下一天继承的状态 | 作用 |
|---|---|---|
| 机组 | 开停机状态、日末出力、连续开机或停机分钟数 | 最小开停机时间、启动类别及跨日爬坡 |
| 储能 | 日末能量 MWh，SOC 为能量除以额定容量 | 下一天的能量平衡初值 |
| 水库 | 日末水位、日末下泄流量、前一天 96 点下泄历史 | 水量平衡、下泄爬坡及梯级传播时滞 |
| 直流联络线 | 日末功率、调整方向 | 下一天初始运行状态 |

例如，机组在第一天 22:00 开机并持续到日末，第二天从“已开机 120 分钟”继续计算；
若全天状态不变，原有连续时长再加 1440 分钟。每日覆盖不能把这些状态重置。
当天结果无效时任务停止，不推进日期和状态；暂停后继续沿用已完成日末状态。
对比/预测的不同场景各自承接，恢复重算使用被检查日的原始日初状态。

**每日储能终值目标仍然有效。** 如果每天申报相同终值，次日初始 SOC 可能每天相同，
这是终值约束的结果。逐日滚动不等同于七天联合优化，不能据此声称全周最优蓄水或储能。
跨日启动/停机功率轨迹当前不支持，建立任务时拒绝非空轨迹。非市场核电作为外部功率
计划输入，不包含反应堆内部状态模型。

核对时先选相邻两天和同一设备，比较前一天最后时段与后一天初态。导出任务 JSON 后可
比较相邻 `days` 的 `state_end` 和 `state_start`；手工任务还保存当前 `carry`。
字段、公式、单位和源码对应见[跨日状态继承契约](../modules/market/southern_execution_contract.md)开头的“周月任务的跨日状态继承”。

### 2000 节点等待时间与适用范围

本机 Gurobi、8 调度线程、120 火电＋720 水电＋480 风光、180 水库、80 储能的固定
诊断边界：新版首次五次平均 58.25 秒、最大 58.52 秒；同会话重复五次平均 58.30 秒、
最大 58.57 秒。计时从点击到结果显示，包括单日 SCUC/SCED/LMP 和完整对偶核验。
这不是任意硬件、任意边界的一分钟保证，也不能乘以七当作已测完整七日耗时。
2000 节点完整七日及 544 火电版本尚未完成该性能验收；排程诊断不等于交流安全认证。
当前复用同一天 SCED 到 LMP 的共同矩阵，大模型跨运行缓存尚未启用。
详细样本、分解瓶颈和复现命令见[性能验收记录](../modules/market/performance.md)。

## 教程三：故障 / 来水对比

1. 在“边界与单日出清”准备基准，打开“对比试验”并“重载任务”。
2. 首次选择 1 天、来水倍数 `0.5,1,1.5`、报价倍数 `1`，选择停运线路/机组及故障时段。
   启用的故障类型与各倍率组合生成场景；场景越多，计算量越大。
3. 点击“生成对比场景”，确认当前场景和对照场景列表，再点击“2 逐日运行场景”。
   各场景使用相同初态，场景内部逐日承接；故障停止后按边界恢复设备状态。
4. 完成后选择同一日期的当前场景和对照场景。“分析环节”分别提供行为、边界、出清、
   安全、研究结算账本；这些是当前试验的不同观察角度，不再重复到其他页面。
5. 在“安全校核”看交流复核状态，在“研究结算账本”看账本条件、缺失资格及残差。
   交流复核失败的条件性研究账本不能作为正式结算。场景差异本身不能证明因果；
   “单因素恢复重算”才提供该配置下的额外恢复实验。
6. “查看该场景全设备运行计划”会转到运行模拟的结果步骤；查看完可回“对比试验”。
   “导出试验”保留全部场景、失败日窗和限制。

## 教程四：云南调频

1. 准备南方能量边界，打开“云南调频”，点击“载入边界与调频配置”。
2. 选择 AGC 单元和报价小时，检查申报价、需求、可用容量、水电允许区间及来源，
   点击“保存调频配置”。直接修改“完整申报数据”后须应用 JSON 并完成校验。
3. 点击“SCUC → 调频预安排 → SCED”。本操作自行运行 SCUC，**不自动消费其他页面已显示的日前解**。
4. 检查调频预安排、双向容量、耦合 SCED 和价格状态。若容量不足，不应继续解释为有效中标或收费依据。
5. 有有效日前组合后才可“日内出清（沿用日前组合）”。在“日内安全复核与调度记录”维护
   有来源的移出/补入/调增和 AUTOR 调用记录；资格满足时才计算费用。
6. 完整日结单可写入本页的仿真账本；“月度账本与退补”用于月度分摊和更正。
   账本是服务会话内数据，不是持久法律账本或真实支付。“黑启动”仅规则提取，没有交易执行。

## 教程五：实时市场

1. 进入“实时市场”，点击“载入当前边界”。核对起始时刻、滚动次数和求解器；首次用 1 轮。
2. 展开“完整6小时预测与实测初态”，检查有来源的预测、初态、申报和事故备用。
   它是独立实时配置，不会自动消费先前日前或调频页面的结果。
3. JSON 草稿先应用校验，再点击“校验边界并建立仿真”。只有成功建立任务后“计算下一轮”才可用。
4. 点击“计算下一轮”。每轮计算 24 个 5 分钟调度点、独立 8 个 15 分钟价格点，
   仅执行前 15 分钟并承接状态；2–4 小时参考展望不是已执行调度。
5. 在“实时出清结果”选择滚动批次、优化窗口、机组、价格节点和水库，检查约束诊断和曲线。
   失败轮次不推进状态；历史价格不完整时小时价格保持未知，不用零价填补。
6. 配置多轮时可“连续滚动”，在本轮结束后暂停；最后“导出仿真结果”。

## 通用 AC/DC 市场路线

1. 在“建模 → 模型IO”加载或编辑工程电网。选择“通用 AC/DC 市场研究”。
2. 在“主体与报价”配置机组归属、报价加成及容量扣留；“运行行为模拟”是可选重复博弈实验，
   不是普通出清的前置步骤，也不是南方逐机组报价编辑器。
3. 在“预测与时域”设置时段及负荷/新能源预测。没有导入时沿用当前会话/默认曲线，
   不读取南方市场页的独立预测边界。
4. 运行前在“安全校核”设置 AC / N-1，在“市场结算”设置偏差和奖惩参数。
5. “市场出清 → 运行市场出清”生成日前结果；如需实时双结算，再运行“实时/辅助市场”。
   此处辅助服务为通用备用模型，不是云南调频规则。
6. 查看“安全校核”中的基态和事故状态，再看“市场结算”并导出。
   “出清并校核”会重新计算；“查看结算结果”仅看现有结果。
   修改结算参数不会追溯更改旧账本，必须重新运行对应市场。

通用 AC/DC 模型有自己的设备覆盖与近似。南方梯级水量、AC 储能优化、调频账本不能因为切换页面而进入通用结果。
具体范围见[模块手册](../modules/market/README.md)及运行结果中的 `model_scope` / `model_limitations`。

## 如何判断结果

| 信息 | 正确读法 |
|---|---|
| `Optimal` / 达到最优性容差 | 该数学阶段在给定容差内的求解状态，不替代交流安全 |
| 限时可行 / `feasible_limit` | 已有可行整数解，最优性尚未证明，保留 GAP 和实际时限 |
| `schedule_only` | 线性计划已生成，交流安全未认证 |
| 缺额 / 富余 | 单位 MW，积分电量 MWh；不是数值平衡残差 |
| 线路越限 | 线性有功限额的 MW 或 MW·h，不是交流 MVA 负载率 |
| LMP | 元/MWh；只有定价有效时可用，不以排程目标值代替价格 |
| 条件性研究账本 | 仅用于研究核算，必须保留未满足的价格/安全/计量条件 |
| 尚未出清 / 已失效 / 不可用 | 未获得当前输入对应的结果，不能作为零缺额或零价格 |

## 常见问题

**IEEE118 运行很久，是否还在执行**：顶部“市场任务执行状态”持续显示本次请求耗时，
逐日任务同时显示场景、日期和已完成日窗。每隔约 3 秒读取服务状态：
“服务端有计算在执行”是会话占用状态，不是某个 SCUC/SCED 阶段的进度。
“等待服务端返回”表示结果尚未返回；“正在接收结果”显示实际下载量；
“响应已收到”只确认请求返回，求解成败仍看本页结果。
状态连接暂时中断时会明确提示并重试查询，不会自动重复提交出清。
切换页面后可用“返回任务”回到运行步骤。点击暂停仍需等待当前日窗及恢复重算结束。

**运行规模为何比预期大**：第 3 步显示“场景数 × 天数 = 日窗数”。例如 8 场景 × 7 日
实际要执行 56 个日窗，每日还包含 SCUC、SCED、定价和可选恢复实验。
单次求解时限不是整项任务时限。首次研究先用 1 个场景或单日任务，再逐步扩大；
恢复重算是额外实验，需要原因分析时再启用。结果的“原因”详情分别列出本日总耗时、
主出清耗时、恢复实验耗时；阶段表中的 SCUC/SCED 时间不是完整任务的等待时间。
例如一周开启六项恢复，会执行 7 次主出清和 42 次恢复，每次都包含多个求解阶段。
完整历史任务响应仍可能较大。

**54 台机组为何仍然慢**：IEEE118 混合案例的 54 台常规机组是 36 台水电加 18 台火电，
另外还包含 12 台风光机组、6 台储能、12 座梯级水库。计算按 98 个时点展开，节点数
并不是优化规模。优化后端对符合条件的零成本开停机和储能小时方向采用等价投影，
详情显示实际命中的台数；有最低出力、慢爬坡或启停约束的机组保留原模型。
实时与调频链不使用这两项投影。

**2000 节点单日如何设置**：在“边界与单日出清”载入 ACTIVSg2000 水电主导案例，
在执行参数中选 Gurobi、8 线程、`large_mip_strategy=auto`、`assembly_mode=cached`，
保存后点击“南方规则出清”。需要已安装且可用的 Gurobi。默认案例是 120 火电加
720 水电、480 风光，另含 180 水库、80 储能和 120 可控负荷，不能只按节点数估计耗时。
`verify` 会额外重建原模型作矩阵核对，属于验证模式，等待更久。
新路径先生成整数可行候选，并用原模型独立下界验证请求的 GAP；不满足则回退原 MILP。
“Optimality gap reached”表示达到最优间隙要求，不表示精确最优。`schedule_only` 和
诊断缺额/富余仍有原适用边界，不等于通过交流安全认证或可直接用于正式结算。
完整单日计时包括 SCUC、SCED、定价和价格复核；本机实测与适用配置见
[2000 节点性能记录](../modules/market/performance.md#2000-节点一分钟目标)。

**恢复实验如何使用线程**：符合规模及 CPU 预算的 Gurobi 任务使用两路独立恢复，
自动线程 0 在恢复阶段解析为每路 2 线程；主出清仍按原设置。显式线程超过并行预算、
其他求解器或大规模边界顺序执行。日与日之间的水量/SOC 仍顺序承接。
每次求解时限、GAP、场景数及恢复实验数量保持原设置，具体计时见
[市场性能验证](../modules/market/performance.md)。

**按钮灰色**：先检查前置状态。未载入配置、未保存草稿、未生成场景、正在计算或结果已失效都会禁用后续操作。
先查看本页状态行和分步教程，不需要反复切页。

**切换页面后看见另一类结果**：先核对“市场模型”和页标题。南方边界、滚动、试验、调频和实时各有独立结果上下文；
画布只显示当前南方页面的来源，通用页面使用工程画布。场景/日期/时点应与当前结果选择一致。

**边界已变化 / 409**：保存配置会更新共享南方修订号。先导出需要保留的输入，再重载边界、重新生成任务；
旧结果仍可作历史证据，不能视为当前边界结果。配置版本尚未拆分，切换页面本身不会更新修订号。

**当前服务版本未提供此市场接口 / 404**：网页静态文件已更新，但运行中的 `run_gui_server` 可能仍是旧二进制。
请使用具备相应接口的新服务；重启旧服务会丢失其会话内数据，应先导出。刷新网页不会升级 C++ 后端。

**价格空白或交流失败**：展开阶段状态、约束诊断和模型限制；无有效定价不能用零价补齐。
调频容量不足应调整有依据的申报/需求后重算，不能取消约束来宣称原边界通过。

**窄屏挤不下**：市场操作区优先显示，默认收起拓扑，使用“显示拓扑”展开。
数据表在各自区域横向滚动，页面导航会换行。桌面也可以收起拓扑以扩大表格和曲线。
