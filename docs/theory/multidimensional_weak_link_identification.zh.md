# 时空多维薄弱环节辨识

## 适用范围

`hacdcpf.multidimensional_weak_link.v1` 模块综合来自经济运行、碳流、可靠性与弹性分析的证据。它是一个筛查与决策路由层，并不声称某项归因的排放或停电贡献就等于某项投资的反事实收益。

GUI 暴露两种决策模式：

- `planning`：综合升级改造、加固/冗余、降损以及 Pareto 权衡审查；
- `operation`：协调调度、再调度/需求响应、紧急重构以及运行 Pareto 审查。

## 数学基础

该方法是一种非补偿型多准则脆弱性筛查。它结合了阈值归一化、Chebyshev 瓶颈聚合、max-min 共识、Pareto 偏序，以及一个独立的时间维度风险投影。它不是加权和效用模型：严重的可靠性问题不能被有利的经济得分抵消。

令 `i` 表示空间实体，`t` 表示时段，`k in {economic, carbon, reliability, resilience}` 表示维度。令 `x_ik` 为可用的原始压力证据，`tau_k > 0` 为其工程目标值。无量纲的阈值越限比为

`p_ik = max(x_ik, 0) / tau_k`。

`p_ik = 1` 表示达到目标，`p_ik > 1` 表示超出目标。定义 `K_i` 为实体 `i` 可用的维度集合。缺失的维度在 `K_i` 之外；它们不会被以零填补。

计算三个非补偿型统计量：

`severity_i = max(k in K_i) p_ik`，

`consensus_i = min(k in K_i) p_ik`，

`disagreement_i = severity_i - consensus_i`。

严重度（severity）是到全零压力原点的 Chebyshev（`L-infinity`）距离，用于识别最恶劣的瓶颈。共识度（consensus）是 max-min/模糊与（fuzzy-AND）聚合：只有当每个可用维度都很高时它才高。分歧度（disagreement）是极差半范数，用于暴露跨维度失衡。

这些定义提供三条有用的不变性：

1. 单调性：增大任何可用压力不会降低严重度；
2. 非补偿性：降低另一个维度不能掩盖最大压力；
3. 共弱保护：单个极端维度不能抬高共识度。

分类是一个确定性的决策划分。在当前默认值 `h=0.75`、`c=0.50`、`g=0.60` 下：

- compatible（共弱）：`|K_i| >= 3` 且 `consensus_i >= c`；
- conflict（冲突）：`|K_i| >= 2`、`severity_i >= h` 且 `disagreement_i >= g`；
- single-dimension（单维）：在通过前述判定后满足 `severity_i >= h`；
- watch（关注）：有证据可用，但不存在高压条件；
- insufficient（证据不足）：`|K_i|` 低于配置的证据要求。

### Pareto 弱前沿

仅当实体具有相同的可优化组件分组和相同的覆盖集合时，才对它们进行 Pareto 比较。当

`p_jk >= p_ik for every k in K_i`，

且至少在一个维度上严格不等时，实体 `j` 弱支配实体 `i`。Pareto 薄弱环节是指不被任何其他可比实体支配的实体。该前沿的含义是：该实体不能被当作 uniformly 更弱而排除；它并不意味着该实体或某项拟议投资是最优的。

最终排序为字典序：首先是 Pareto 成员资格，然后是严重度降序、共识度降序，最后是稳定的实体键。时间维度的行使用相同的维度归一化，并按时段严重度降序排列。当前实现暴露两个边际视图：实体×维度 与 时段×维度；尚不估计完整的 实体×时间×维度 张量。

### 保证与不保证的内容

对于固定的输入和阈值，结果是确定性的、单调的、可复现的。覆盖感知的 Pareto 比较可防止缺失维度的实体支配一个观测完整的实体。这些是算法层面的保证，而不是关于物理系统的统计保证。

结果有效性仍要求：来源分析收敛、故障与修复数据经过校准、灾害与时间序列具有代表性，以及工程阈值与决策相适应。当前 GUI 还对部分证据使用相对归一化，包括 LMP 偏差、支路碳排名和相对于峰值的时序成本/排放。这些数值支持同一算例内的筛查，但在没有共同绝对目标的情况下不应跨无关算例比较。

规划结果只有在通过以下审计后才应被接受：

1. 综合结论要求四维覆盖；
2. 拒绝或标记任何未收敛的来源分析，并保留每条证据细节；
3. 扰动每个阈值和关键模型参数，检查前沿/排名稳定性；
4. 在负荷、可再生、停运、检修和灾害场景下重复筛查；
5. 用下文独立的反事实收益计算确认拟议措施。

统计置信区间、概率化排名可接受性和场景频率鲁棒性尚未纳入 schema v1。在将筛查解读为概率保证性陈述之前，这些是必需的。

## 证据契约

每个空间实体和时段可以提供零到四条维度记录：

```json
{
  "pressure": 1.15,
  "detail": "EENS contribution 1.15 MWh/yr / target 1.00 MWh/yr"
}
```

压力是无量纲的，且始终遵循 `higher_is_weaker`（越高越弱）。取值 1.0 表示达到配置的工程阈值。缺失的证据是不可用，而不是零。GUI 目前从以下来源推导压力：

| 维度 | 空间证据 | 时间证据 |
| --- | --- | --- |
| 经济 | 支路负载率与节点 LMP 偏差 | 时间序列最优潮流成本 |
| 碳 | 节点碳强度与支路损耗排放 | 动态碳排放 |
| 可靠性 | 预想故障/组件级与节点级 EENS | 为时序可靠性轨迹保留 |
| 弹性 | 母线级加权失供能量 | 灾害步加权失供能量 |

可用证据还会归因到可优化的组件族：

- network（网络）：AC/DC 线路与双绕组/三绕组变压器；
- conversion（变换）：VSC、DC/DC 换流器与能量路由器；
- supply（电源）：同步、静止、可再生、光伏与外部电网电源；
- flexibility（灵活性）：AC/DC 储能、柔性负荷、VPP、微电网与移动储能；
- demand（需求）：AC/DC、不对称与充电需求；
- protection（保护）：开关与 AC/DC 断路器；
- node support（节点支撑）：AC/DC 母线与可投切并联补偿装置。

归因在相应字段可用时使用：求解得到的负载率或容量利用率、物理损耗比、LMP 乘需求暴露度、电源/负荷/储能/换流器碳结果、组件 FMEA 贡献、按负荷加权的灾害切负荷、故障修复时长，以及恢复开关依赖关系。缺失的来源字段保持不可用，而不会从邻近母线推断。

## 排名与关系

对于可用维度 `k`，后端计算

`normalized_pressure[k] = max(raw_pressure[k], 0) / target_pressure[k]`。

实体严重度是可用的最大压力。共识度是可用的最小压力，因此它不能被单个极端维度抬高。分歧度是可用维度上的 `max - min`。

关系标签为：

- `compatible`：至少三个维度可用，且全部超过共弱阈值；
- `conflict`：至少两个维度可用，其中一个为高，且跨维度差距超过冲突阈值；
- `single_dimension`：存在高压力但缺乏足够的共同压力；
- `watch`：有证据存在，但未满足任何高压条件；
- `insufficient_evidence`：少于配置的最小维度数。

Pareto 支配仅在具有相同维度覆盖掩码的实体之间评估。这可防止一个两维实体仅仅因为其缺失维度被当作零而支配一个四维实体。API 返回原始证据细节以保证可审计性。

## 直接可视化编码

GUI 将空间与时间结果呈现为原生的带注释压力矩阵，不依赖外部图表运行时。行是排名后的实体或关键时段，列是四个维度，每个可用单元格显示其精确的归一化压力。共享标尺锚定 `0.50`、`0.75` 与工程阈值 `1.00`；超过 `1.50` 的值在颜色上被截断，但保留其精确文本与悬停详情。缺失证据单独渲染，绝不赋予低风险颜色。Pareto 实体以菱形标记，关系标签保留在实体名称旁。

## 反事实规划

`hacdcpf.counterfactual_planning.v1` 评估将筛查结果转化为可审计的规划证据。它将每项选定的措施应用于同一基线系统的独立克隆体，并重新运行来源分析。它绝不通过对薄弱环节评分进行缩放来估计投资收益。

内置候选生成器暴露五种显式措施类型：

| 类型 | 反事实模型变更 |
| --- | --- |
| `line_capacity` | 提高选定 AC 支路的额定容量，并按相同倍数降低其并联等值阻抗 |
| `storage` | 增加具有显式功率、能量、SOC、调度与停运参数的构网型 AC 储能 |
| `tie_switch` | 在原本不相连的母线之间增加常开 AC 联络支路与远方开关 |
| `automation` | 新增或将馈线开关升级为远方自动操作 |
| `der` | 增加具有显式容量和运行点容量因子的可控、零运行碳分布式电源 |

API 还接受显式的 `measures` 数组，因此规划工作流可以针对薄弱环节筛查所识别的支路与母线索引，而不是使用自动候选位置。候选数与成对数受 `max_measures` 与 `max_pairs` 约束，因为每一行都是一次真实的系统评估。

对于越小越好的指标 `k`，带符号的单措施收益为

`B_k(a) = baseline_k - counterfactual_k(a)`。

正值表示改善，负值表示恶化。成对交互作用由单独的组合重算得到：

`S_k(a,b) = B_k(a+b) - B_k(a) - B_k(b)`。

正的 `S` 表示超出可加收益的协同效应。负的 `S` 表示冗余或冲突。JSON 响应保留绝对值、相对值、单位、求解器诊断、应用状态以及所用方程。GUI 在每个成对矩阵单元格中显示四个带符号的数值；它不会把经济上有利但可靠性不利的组合折叠成单一评分。

重算的维度为：

- 经济：年化 AC 最优潮流目标，附带年化货币化物理损耗回退；
- 碳：年化矩阵碳流或比例追踪结果；
- 可靠性：确定性配电 N-1 FMEA；
- 弹性：在基线与每个克隆体上、同一显式支路故障集下的启发式顺序恢复。

当前评估是规划比较，而不是多年容量扩展优化器。CAPEX 与运行成本分开报告；储能与 DER 使用配置的代表性运行点而非 8760 小时投资调度；自动候选生成目前每种启用类型至多提出一个候选。这些限制是显式声明的，以免收益与协同矩阵被误当作全生命周期 NPV 最优。
