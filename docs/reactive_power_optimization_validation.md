# 无功优化数学模型与全过程交叉验证

## 1. 模型定位

无功优化采用“离散调压设备搜索 + 连续 AC/DC OPF 补全”的双层结构。离散变量为：

\[
y=(t_1,\ldots,t_{N_t},s_1,\ldots,s_{N_s}),
\]

其中，两绕组有载调压变压器档位满足
\(t_k\in\{t_k^{\min},\ldots,t_k^{\max}\}\)，可投切并联补偿步数满足
\(s_j\in\{0,\ldots,n_j\}\)。给定离散配置后，连续变量
\(x=(V,\theta,V^{dc},P_g,Q_g,P^{vsc},Q^{vsc},\ldots)\)
由混合 AC/DC OPF 求解。所选电压偏差/网损目标直接进入连续 NLP 的目标函数，
而不是先求经济 OPF、再对其结果事后打分；RPO 模式同时关闭负荷削减，避免通过
少供电获得虚假的电压或网损改善。连续层加入 \(10^{-6}\) 权重的发电经济性
择优项，仅用于消除等价有功调度和改善 KKT 数值条件，不替代主 RPO 目标。

目标函数可选：

\[
\min f_V=\sum_i w_V(V_i-V^*)^2,
\]

\[
\min f_L=w_L P_{loss},
\]

或二者加权和。损耗采用全系统边界电源与物理需求的有功差额，不把
VSC、DC/DC 和能量路由器端口等内部传输重复计为电源。

连续层约束包括 AC/DC 节点功率平衡、母线电压、机组 P/Q、支路热稳、
VSC 容量圆、交直流电流、调制比以及 DC/DC 占空比约束。各约束族可在
GUI 中显式启停，并与独立 OPF 复算使用同一组选项。

## 2. 最优性口径

离散层使用灵敏度排序、整数坐标搜索和两变量邻域改进。非凸目标上的局部
线性灵敏度面不具备全局下界性质，因此不得用于安全剪枝。本实现返回经过
连续 OPF 补全的可行局部最优点，不报告虚假的 `gap=0`，也不声称获得全局
MINLP 最优性证明。

## 3. 元件利用审计

结果按照以下四类逐元件报告：

1. **直接离散优化**：两绕组 OLTC、可投切并联补偿；
2. **连续协同优化**：机组 P/Q、可控新能源/PV、储能 Q、柔性负荷、VSC、
   DC/DC 和能量路由器端口等由内层 OPF 处理的变量；
3. **固定建模**：负荷、固定电源、固定变压器/并联元件及当前开关拓扑；
4. **部分或未覆盖**：三绕组变压器分接头、独立调压控制器、单体三相不平衡
   RPO，以及当前尚未完整回写到 authored-space PF 的混合换流器调度。

“模型中出现”不等于“作为决策变量优化”。GUI 分别显示处理方式和是否完成
OPF/PF 交叉验证，避免用一个笼统的“支持”掩盖固定、投影或近似处理。

## 4. 全过程交叉验证

每次 RPO 后固定执行：

1. 保存 RPO 内层最优连续点与离散档位；
2. 将档位写入独立系统副本，重新运行独立 AC/DC OPF；
3. 比较两次 OPF 的最大 \(|\Delta V|\)、\(|\Delta P_g|\)、\(|\Delta Q_g|\)；
4. 将优化调度和档位写入 PF 回放副本，运行非线性潮流；
5. 报告 PF 收敛、残差、最大 \(|\Delta V|\) 与优化前后物理网损；
6. 对富混合 AC/DC 元件未能完整回写的情况明确标记为“部分映射”，不得判为
   全过程通过。

默认判据为：OPF 电压差不超过 \(10^{-5}\) pu，机组 P/Q 差不超过
\(10^{-4}\) MW/MVar；PF 电压差不超过 \(10^{-3}\) pu，且不存在部分调度映射。
