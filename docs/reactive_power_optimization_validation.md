# 无功优化数学模型与全过程交叉验证

## 1. 模型定位

无功优化采用“离散调压设备搜索 + 连续 AC/DC OPF 补全”的双层结构。离散变量为：

\[
y=(t_1,\ldots,t_{N_t},s_1,\ldots,s_{N_s}),
\]

其中，两绕组有载调压变压器档位满足
\(t_k\in\{t_k^{\min},\ldots,t_k^{\max}\}\)，可投切并联补偿步数满足
\(s_j\in\{0,\ldots,n_j\}\)。给定离散配置后，连续变量
\(x=(V,\theta,V^{dc},P_g,Q_g,P^{vsc},Q^{vsc},\ldots)\)
由混合 AC/DC OPF 求解。所选电压偏差/网损目标直接进入连续 NLP 的目标函数，
而不是先求经济 OPF、再对其结果事后打分；RPO 模式同时关闭负荷削减，避免通过
少供电获得虚假的电压或网损改善。连续层加入 \(10^{-6}\) 权重的发电经济性
择优项，仅用于消除等价有功调度和改善 KKT 数值条件，不替代主 RPO 目标。

目标函数可选：

\[
\min f_V=\sum_i w_V(V_i-V^*)^2,
\]

\[
\min f_L=w_L P_{loss},
\]

或二者加权和。损耗采用全系统边界电源与物理需求的有功差额，不把
VSC、DC/DC 和能量路由器端口等内部传输重复计为电源。

连续层约束包括 AC/DC 节点功率平衡、母线电压、机组 P/Q、支路热稳、
VSC 容量圆、交直流电流、调制比以及 DC/DC 占空比约束。各约束族可在
GUI 中显式启停，并与独立 OPF 复算使用同一组选项。

对 100 母线及以上的大型系统，连续 RPO 在进入非经济目标前先使用网络结构化
原生 IPM 求取高精度经济 OPF 种子；后续离散候选复用当前可行 RPO 点作为
Ipopt 热启动。可行性容差与 scaled KKT 平稳性容差分别配置，避免
`case300_acdc` 从平坦初值直接进入 `step computation failed`。

GUI 在求解前调用与求解器相同的离散控制清单接口。两绕组变压器只有同时满足
投运、`tap_max > tap_min`、`tap_step_percent > 0` 且当前档位位于铭牌范围内，
才会成为可选 OLTC。用户可逐台勾选是否参与优化，也可全选或清空；固定、停运
及参数无效的设备会显示明确排除原因。为避免大型系统直接暴露过大的离散邻域，
默认每台已选 OLTC 仅允许在当前档位上下各移动 2 档，即

\[
  t_k \in [t_k^{\min},t_k^{\max}]\cap
  [t_k^0-2,t_k^0+2].
\]

该窗口可在前端修改：`-1` 表示使用完整铭牌范围，`0` 表示保持所有 OLTC 当前
档位。输入审计同时显示铭牌范围、本次优化范围、可选位置数和全部离散组合规模；
局部坐标搜索仍受最大评估次数和时间上限约束，并不穷举组合空间。

MATPOWER 支路只提供当前连续变比，不提供 OLTC 可控标志、档位上下限或每档步长。
因此导入器保留支路上的精确变比，但不再将其伪造为 `0.01%` 步长、
`[-2000,2000]` 的 4001 档 OLTC。此类设备默认显示为固定变比；只有算例或用户在
GUI 属性中显式给出有效档位范围与步长后才进入 RPO。`case300_acdc` 作为内部
演示仅显式配置 3 台 `[-4,4]`、每档 `1.25%` 的 OLTC。对带
`source_branch_idx` 的设备，档位动作会按相对变比同步更新原始 AC 支路的 `tap`，
从而保证 RPO 内层、独立 OPF 和 PF 回放实际使用同一调压动作。

界面严格区分三种容易混淆的量：节点电压结果以实际 kV 为主，并在明细或悬停
信息中给出标幺值；“实际支路 tap”是 MATPOWER 支路的当前固定/有效电气变比；
“相对变比”则仅表示 OLTC 相对中性档的档位倍率。以 `case24_ieee_rts.m` 为例，
源数据中的 5 个固定支路 tap 为 `1.03, 1.03, 1.03, 1.02, 1.02`，对应 OLTC
档位范围和每档步长均为 0。潮流结果中出现的 `1.0301 pu` 是节点电压，不是
变压器档位或支路 tap；在 138 kV 基准节点上它对应约 142.15 kV。

## 2. 最优性口径

离散层使用灵敏度排序、整数坐标搜索和两变量邻域改进。非凸目标上的局部
线性灵敏度面不具备全局下界性质，因此不得用于安全剪枝。本实现返回经过
连续 OPF 补全的可行局部最优点，不报告虚假的 `gap=0`，也不声称获得全局
MINLP 最优性证明。

## 3. 元件利用审计

结果按照以下四类逐元件报告：

1. **直接离散优化**：两绕组 OLTC、可投切并联补偿；
2. **连续协同优化**：机组 P/Q、可控新能源/PV、储能 Q、柔性负荷、VSC、
   DC/DC 和能量路由器端口等由内层 OPF 处理的变量；
3. **固定建模**：负荷、固定电源、固定变压器/并联元件及当前开关拓扑；
4. **部分或未覆盖**：三绕组变压器分接头、独立调压控制器、单体三相不平衡
   RPO，以及当前尚未完整回写到 authored-space PF 的混合换流器调度。

“模型中出现”不等于“作为决策变量优化”。GUI 分别显示处理方式和是否完成
OPF/PF 交叉验证，避免用一个笼统的“支持”掩盖固定、投影或近似处理。

## 4. 全过程交叉验证

每次 RPO 后固定执行：

1. 保存 RPO 内层最优连续点与离散档位；
2. 将档位写入独立系统副本，重新运行独立 AC/DC OPF；
3. 比较两次 OPF 的目标值、最大 \(|\Delta V|\)、\(|\Delta P_g|\)、
   \(|\Delta Q_g|\)；
4. 将优化调度和档位写入 PF 回放副本，运行非线性潮流；
5. 报告 PF 收敛、残差、最大 \(|\Delta V|\) 与优化前后物理网损；
6. 对富混合 AC/DC 元件未能完整回写的情况明确标记为“部分覆盖”，与真正的
   数值不一致区分显示。

非凸 OPF 可能存在目标等价、但 P/Q 控制分配不同的局部点，因此独立 OPF
一致性以“双方收敛且审计可行、目标相对差不超过
\(\max(10^{-3},10\epsilon_d)\)、电压差不超过
\(\max(5\times10^{-4},10\epsilon_p)\) pu”为判据，其中
\(\epsilon_d\) 和 \(\epsilon_p\) 分别是平稳性和可行性容差。P/Q 最大差异仍
完整展示，但不再单独触发假失败。纯 AC 系统的 PF 电压差判据仍为
\(10^{-3}\) pu；富混合 AC/DC 在 authored-space 调度尚未完整回写时显示
“可用数值检查通过，PF 回放部分覆盖”，不宣称完整 PF 等价。
