# 碳流分析 Web 界面逻辑梳理

## 目标

碳流分析必须基于已经收敛的潮流结果，不能在没有电气运行状态的情况下独立计算。

本设计把碳流分析拆成两个明确流程：

- 静态碳流分析：基于最近一次单截面潮流计算结果。
- 动态碳流分析：基于最近一次时序潮流或时序 OPF 结果。

界面需要让用户清楚知道当前碳流结果来自哪个潮流结果、哪个时段范围、储能出力来源是什么，避免出现“动态结果里混入静态结果”“不知道对应哪个时间段”的歧义。

## 模块位置建议

当前顶部模块栏中，碳流分析位于潮流计算右侧，位置过早。建议调整到靠后位置。

推荐顺序：

1. 潮流计算
2. 短路计算
3. 拓扑重构
4. 时序潮流
5. 承载力分析
6. 可靠性分析
7. 场景生成
8. 弹性评估
9. 碳流分析

原因：

- 静态碳流依赖潮流计算。
- 动态碳流依赖时序潮流或时序 OPF。
- 碳流更像运行结果后的后处理分析，不应放在最前面的基础计算模块中。

## 统一计算原则

### 静态碳流

输入前置条件：

- 网络拓扑已同步到后端。
- 已成功运行一次潮流计算。
- 最近一次潮流结果收敛。
- 已设置或导入发电机、静态电源、外部电网碳排放因子。

计算流程：

1. 用户在“潮流计算”模块点击“运行潮流计算”。
2. 后端保存最近一次潮流结果和对应网络快照。
3. 用户进入“碳流分析”模块。
4. 点击“静态碳流分析”。
5. 后端使用最近一次潮流结果做矩阵法碳流追踪。
6. 前端展示单一潮流截面的碳流结果。

禁止行为：

- 未运行潮流时直接做静态碳流。
- 最近一次潮流未收敛时继续做静态碳流。
- 网络已修改但未重新跑潮流时沿用旧潮流结果。

### 动态碳流

输入前置条件：

- 已配置时序数据，例如负荷曲线、新能源曲线、外部电网分时碳因子。
- 已成功运行一次时序潮流或时序 OPF。
- 至少有一个收敛时段。
- 如要分析储能动态碳流，储能出力和 SOC 应来自时序 OPF、UC/SCUC 或明确的固定出力方案。

推荐计算流程：

1. 用户在“时序潮流”模块设置时段数、步长、时序数据和 OPF/UC 选项。
2. 点击“运行时序潮流”。
3. 后端保存最近一次时序潮流结果，包括每个时段的系统快照、潮流结果、储能出力和 SOC。
4. 用户进入“碳流分析”模块。
5. 点击“动态碳流分析”。
6. 后端默认复用最近一次时序潮流或时序 OPF 结果。
7. 对每个收敛时段做碳流追踪，并进行储能碳库存递推。
8. 前端展示时序汇总、趋势图、节点碳势曲线和储能碳流结果。

备选流程：

- 如果用户没有先运行时序潮流，可以提供“重新计算时序潮流后分析”的显式选项。
- 该选项必须显示 OPF/UC 开关，不能让用户误以为动态碳流一定使用 OPF。

## 储能动态碳流逻辑

动态碳流中的储能不能只看某一时段的静态碳势，还要递推储能内部碳库存。

基本逻辑：

- 储能充电时，按充电节点当时的碳势给储能库存增加碳。
- 储能放电时，按储能库存碳强度释放碳。
- 储能 SOC 影响库存能量，储能库存碳强度随充放电递推变化。
- 充放电效率和自放电损耗应纳入库存更新。

储能出力来源必须在界面中明确显示：

- OPF：每个时段由时序 OPF 优化得到储能出力。
- UC/SCUC：由机组组合或安全约束机组组合得到储能计划。
- 固定出力：使用画布或算例中的固定 `p_mw`。
- 简化策略：使用内部 fallback 策略，不作为严格优化结果。

推荐默认：

- 动态碳流优先使用最近一次时序 OPF 结果。
- 如果最近一次时序潮流没有启用 OPF，应在动态碳流结果顶部明确提示。

提示语：

```text
当前动态碳流使用最近一次时序潮流结果。储能调度来源：非 OPF 优化结果，请确认是否符合分析目的。
```

或：

```text
当前动态碳流使用最近一次时序 OPF 结果。储能出力和 SOC 来自 OPF 调度。
```

## 外部电网碳因子逻辑

外部电网必须支持固定碳因子和分时碳因子。

固定值：

```json
{
  "external_grids": [
    {
      "index": 1,
      "bus": 1,
      "emission_factor": 700
    }
  ],
  "unit": "kg/MWh"
}
```

分时值：

```json
{
  "external_grids": [
    {
      "index": 1,
      "bus": 1,
      "emission_factor_profile": [700, 680, 660, 720, 760]
    }
  ],
  "unit": "kg/MWh"
}
```

动态碳流中，外部电网第 `t` 个时段使用 `emission_factor_profile[t]`。如果时段数超过数组长度，沿用最后一个值，并在结果中提示。

提示语：

```text
外部电网 AC-1 使用分时碳因子：24/24 个时段已匹配。
```

或：

```text
外部电网 AC-1 分时碳因子长度不足，超出部分沿用最后一个值。
```

## 前端操作逻辑

### 静态碳流按钮

按钮名称：

```text
静态碳流分析
```

按钮说明：

```text
基于最近一次收敛的潮流结果进行静态矩阵法碳流追踪
```

点击前检查：

1. 是否有最近一次潮流结果。
2. 最近一次潮流是否收敛。
3. 网络是否在潮流后被修改。
4. 是否有碳因子配置。

失败提示：

```text
请先运行潮流计算，并确保潮流收敛后再进行静态碳流分析。
```

```text
当前网络已修改，最近一次潮流结果已失效。请重新运行潮流计算。
```

```text
缺少碳排放因子。请导入碳因子 JSON，或在右侧属性中设置发电机/外部电网碳因子。
```

### 动态碳流按钮

按钮名称：

```text
动态碳流分析
```

按钮说明：

```text
基于最近一次时序潮流或时序 OPF 结果进行动态碳流追踪
```

点击前检查：

1. 是否有最近一次时序潮流结果。
2. 时序潮流是否至少有一个收敛时段。
3. 时序结果的时段数和当前界面设置是否一致。
4. 是否有外部电网分时碳因子或固定碳因子。
5. 是否存在储能；如果存在，储能出力来源是否明确。

失败提示：

```text
请先在“时序潮流”模块运行时序潮流或时序 OPF，再进行动态碳流分析。
```

```text
最近一次时序潮流没有收敛时段，无法进行动态碳流分析。
```

```text
当前动态碳流时段数与最近一次时序潮流结果不一致，请重新运行时序潮流。
```

警告提示：

```text
最近一次时序潮流未启用 OPF，储能出力不是 OPF 优化结果。
```

```text
未检测到储能元件，本次动态碳流将退化为逐时段静态碳流汇总。
```

## 结果展示设计

### 静态碳流结果

静态结果只展示单一潮流截面。

建议展示内容：

- 概览卡片：
  - 数据来源：最近一次潮流计算。
  - 潮流算法。
  - 潮流收敛状态。
  - 矩阵法求解状态。
  - 源端碳排放，单位 `t`。
  - 负荷碳排放，单位 `t`。
  - 网损碳排放，单位 `t`。
  - 守恒误差，单位 `t` 和 `%`。
- 节点碳势图：
  - 单位 `kg/MWh`。
  - 低碳为绿色，高碳为红色。
  - 默认不显示零消纳或近零功率节点。
- 节点碳势表：
  - AC/DC 类型。
  - Bus 编号。
  - 节点角色：电源、负荷、储能、外部电网、普通节点。
  - 碳势 `kg/MWh`。
  - 有效能量吞吐量 `MWh`。
  - 是否有效。
- 负荷碳排放表：
  - Load 编号。
  - 所在 Bus。
  - 负荷功率 `MW`。
  - 负荷碳强度 `kg/MWh`。
  - 负荷碳排放 `t`。
- 支路损耗碳排放表：
  - Branch 编号。
  - From/To。
  - 损耗 `MW`。
  - 损耗碳强度 `kg/MWh`。
  - 损耗碳排放 `t`。

零消纳节点处理：

```text
部分节点没有有效能量消纳或功率吞吐，节点碳势不参与图表排序，仅在表格中标记为“无有效碳势”。
```

### 动态碳流结果

动态结果只展示时序结果，不复用静态碳流结果区域。

建议展示内容：

- 总览卡片：
  - 数据来源：最近一次时序潮流 / 最近一次时序 OPF。
  - 时段数。
  - 步长。
  - 总时长。
  - 收敛时段数。
  - OPF 收敛时段数。
  - UC/SCUC 状态。
  - 储能调度来源。
  - 外部电网碳因子来源：固定值 / 分时 profile。
- 逐时段表：
  - 时段。
  - 潮流是否收敛。
  - OPF 是否收敛。
  - 源端碳排放 `t`。
  - 负荷碳排放 `t`。
  - 储能充电吸收碳 `t`。
  - 储能放电释放碳 `t`。
  - 网损碳排放 `t`。
  - 守恒误差 `t`。
- 累计饼图：
  - 源端供给。
  - 负荷消纳。
  - 储能充电。
  - 储能放电。
  - 网络损耗。
- 趋势图：
  - 源端、负荷、储能充电、储能放电、网损随时段变化。
- 节点碳势时序图：
  - 下拉选择节点。
  - 节点标签包含编号和角色，例如 `AC-1 外部电网/电源`、`DC-2 负荷`。
  - 点击“添加节点”后进入同一张曲线图。
  - 默认只推荐有有效能量吞吐的节点。
- 储能碳库存表：
  - 储能编号。
  - 所在 Bus。
  - 每时段 `p_mw`。
  - 每时段 SOC。
  - 库存碳强度 `kg/MWh`。
  - 充电吸收碳 `t`。
  - 放电释放碳 `t`。

禁止展示：

- 不在网络图上叠加碳势彩色框或碳排标签。
- 动态碳流结果中不显示“静态碳流分析结果”标题。
- 动态平均碳势不能伪装成某个静态截面的碳势。

## 状态缓存设计

前端和后端需要维护以下状态。

静态潮流状态：

- `last_pf_result`
- `last_pf_converged`
- `last_pf_source_snapshot_id`
- `current_network_snapshot_id`
- `last_pf_method`

时序潮流状态：

- `last_tspf_result`
- `last_tspf_num_steps`
- `last_tspf_step_duration_hr`
- `last_tspf_num_converged`
- `last_tspf_run_opf`
- `last_tspf_skip_uc`
- `last_tspf_num_opf_converged`
- `last_tspf_storage_dispatch_source`
- `last_tspf_snapshot_id`

碳因子状态：

- `carbon_factors_loaded`
- `generator_factor_count`
- `static_generator_factor_count`
- `external_grid_factor_count`
- `external_grid_profile_count`
- `carbon_factor_unit`

运行检查逻辑：

- 当前网络修改后，`current_network_snapshot_id` 变化。
- 如果 `current_network_snapshot_id != last_pf_source_snapshot_id`，静态碳流按钮应提示需要重跑潮流。
- 如果 `current_network_snapshot_id != last_tspf_snapshot_id`，动态碳流按钮应提示需要重跑时序潮流。

## 单位规范

碳势和碳强度统一显示：

```text
kg/MWh
```

碳排放量统一显示：

```text
t
```

内部可以继续使用 `tCO2/MWh`，但前端展示必须转换为 `kg/MWh`：

```text
kg/MWh = tCO2/MWh * 1000
```

界面不再显示 `kgCO2/kWh` 或 `kgCO2/MWh`，避免和当前项目约定冲突。

## 异常和明显 Bug 防护

### 零消纳节点碳势异常

问题：

- 节点没有有效负荷或能量吞吐时，矩阵法可能得到极大碳势。
- 例如 `DC-1 = 46366 kg/MWh` 这类值不应默认进入柱状图。

处理：

- 后端返回 `valid=false` 或 `energy_mwh=0`。
- 前端图表过滤该节点。
- 表格中显示 `无有效碳势`。

提示语：

```text
部分零消纳节点未参与碳势图展示，可在表格中查看其状态。
```

### 负荷碳排放为负

问题：

- 负荷碳排放不应为负。

处理：

- 负荷侧统计使用实际正向消纳功率。
- 如果出现负负荷或反送功率，应归类为发电/注入，不进入负荷碳排放。

提示语：

```text
检测到反向功率负荷，已按注入功率处理，不计入负荷碳排放。
```

### 动态和静态结果混淆

问题：

- 动态碳流结果不能复用静态碳流表格标题。

处理：

- 静态和动态结果区域完全分离。
- 动态平均值必须标注为“时序平均”。
- 某一时段结果必须标注具体时段，例如“第 6 时段节点碳势”。

## 推荐实现步骤

1. 调整模块顺序，把“碳流分析”移动到模块栏最后。
2. 增加前端运行状态缓存，记录最近一次潮流和时序潮流结果是否有效。
3. 静态碳流按钮增加前置检查，未运行潮流时禁止计算。
4. 动态碳流按钮增加前置检查，未运行时序潮流时禁止计算。
5. 动态碳流默认复用最近一次时序潮流或时序 OPF 结果。
6. 提供“重新计算时序潮流后分析”作为显式高级选项。
7. 动态结果区域和静态结果区域拆开，不再复用静态表。
8. 后端返回储能调度来源、时段数、步长、OPF/UC 状态、外部电网 profile 应用情况。
9. 前端过滤零消纳节点碳势异常值，并在表格中解释。
10. 补充测试：
    - 未跑潮流时点击静态碳流，应提示并阻止。
    - 潮流不收敛时点击静态碳流，应提示并阻止。
    - 未跑时序潮流时点击动态碳流，应提示并阻止。
    - 时序 OPF 结果存在时，动态碳流应显示储能调度来源为 OPF。
    - 外部电网分时碳因子应逐时段生效。
    - 零消纳节点不应拉爆节点碳势图坐标。

## 最终用户操作路径

静态碳流：

1. 加载或绘制算例。
2. 设置发电机和外部电网碳因子，或导入碳因子 JSON。
3. 进入“潮流计算”。
4. 点击“运行潮流计算”。
5. 确认潮流收敛。
6. 进入“碳流分析”。
7. 点击“静态碳流分析”。
8. 查看静态节点碳势、负荷碳排放、支路损耗碳排放和守恒误差。

动态碳流：

1. 加载或绘制算例。
2. 设置固定或分时碳因子，外部电网可使用 vector。
3. 进入“时序潮流”。
4. 设置时段数、步长和时序数据。
5. 如需储能优化，勾选 OPF 或启用 UC/SCUC。
6. 点击“运行时序潮流”。
7. 确认时序潮流或 OPF 收敛。
8. 进入“碳流分析”。
9. 点击“动态碳流分析”。
10. 查看逐时段碳排、源荷储损耗饼图、趋势图、节点碳势曲线和储能碳库存。
