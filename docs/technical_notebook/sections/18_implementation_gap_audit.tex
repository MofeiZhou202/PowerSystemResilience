\section{Implementation Gap and Stub Audit}
\label{sec:implementation_gap_audit}
% ============================================================

This chapter records the current code-backed boundary between implemented
runtime behavior, transparent approximations, resolved gaps, and remaining
bounded model scope.  It is intentionally separate from the mathematical model
chapters: a formula in this notebook is not a claim that every richer physical
variant is solved end-to-end in production code.

\subsection{Audit Method}

The audit covered \texttt{src/}, \texttt{include/}, \texttt{tests/}, and the
technical-notebook \texttt{sections/} directory.  The review combined source
inspection with searches for high-signal markers such as \texttt{stub},
\texttt{unimplemented}, \texttt{placeholder}, \texttt{fallback},
\texttt{simplified}, \texttt{approximate}, \texttt{dummy}, and
\texttt{unsupported}.  Marker counts are not used as defect counts: many
occurrences are legitimate solver fallback paths, explicit input-domain checks,
or tests that verify a declared boundary.  The latest pass also searched for
the removed distribution power-flow API names and reran the full
\texttt{build\_rel} CTest suite.

Distribution power-flow public API &
The legacy distribution power-flow compatibility header and public single-phase
stub/BFS-style API are removed.  The public distribution feeder surface is now
the three-phase NR contract in
\texttt{include/hacdcpf/power\_flow/distribution\_power\_flow.hpp}:

\texttt{test\_three\_phase\_pf} covers three-phase projection, meshed systems,

\#293--\#316).  \texttt{test\_three\_phase\_nr} covers the native abc-domain NR
solver directly (CTest \#344--\#359). \\
Hybrid FMEA physical evaluation &
Hybrid FMEA no longer scores DC/VSC systems through an AC-only DCOPF boundary.
When DC or converter components exist, \texttt{run\_distribution\_fmea} uses a
linear hybrid AC/DC network LP that co-optimizes AC load shedding, DC load
shedding, AC/DC sources, DC branches, VSC active-power transfers, and DC/DC
converter transfers.  Reports set \texttt{model\_scope} to
\texttt{hybrid-acdc-network-lp} and mark DC-load curtailment plus VSC/DC power
flow as included. &
\texttt{FMEA: hybrid catalog optimizes DC load and VSC transfer} is registered
as CTest \#381 and asserts the hybrid scope string, validity flags, AC+DC nodal
curtailment vector, and VSC outage DC-load shedding. \\
AC OPF fallback for hybrid cases &
Hybrid AC/DC cases are detected before fallback selection.  If the nonlinear
hybrid path fails, \texttt{solve\_ac\_opf} suppresses the AC-only
economic-dispatch plus AC-PF fallback and attaches an explicit diagnostic that
the case contains DC/VSC components.  The fast AC-only route is still available
for AC-only cases. &
\texttt{AC OPF: hybrid cases suppress AC-only fallback} is registered as CTest
\#265 and asserts that a failing hybrid OPF does not report the AC-only fallback
status and does include the suppression hint. \\

\subsection{Remaining Bounded Model Scope}

\begin{enumerate}
  \item Hybrid FMEA is a linear restoration/curtailment LP.  It includes DC
        loads, DC network edges, VSC active transfers, DC/DC transfers, and
        source limits, but it does not certify nonlinear AC voltage/reactive
        feasibility for every restoration state.
  \item The resilience MIP entry point remains an AC-only LinDistFlow
        restoration MILP and reports that scope explicitly.
  \item DC OPF branch shadow-price arrays remain invalid unless
        \texttt{branch\_mu\_valid=true}; bounded-variable branch-dual extraction
        is still a deliberately exposed boundary.
\end{enumerate}

\subsection{Audit Conclusion}

The repository is not an empty shell: PF, OPF, graph, I/O, carbon, time-series,
resilience, FMEA, topology reconfiguration, and three-stage reliability paths
are implemented and covered by the current 422-entry CTest suite.  The three
previous high-risk audit items in this chapter are now closed in code and in
tests: the legacy distribution power-flow public API is removed, hybrid FMEA
optimizes DC networks and VSC transfers, and hybrid AC OPF can no longer accept
an AC-only fallback as a converged hybrid result.  The remaining risks are
bounded model-scope statements surfaced through result fields, validity flags,
and regression tests.
