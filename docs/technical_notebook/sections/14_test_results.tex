Test registration changes as modules evolve, so this notebook does not freeze
CTest ordinal ranges or a permanent test count.  The authoritative inventory is
generated from \texttt{tests/CMakeLists.txt} and the configured build tree:
\begin{verbatim}
ctest --test-dir build --show-only
ctest --test-dir build --output-on-failure
\end{verbatim}

\subsection{Claim Discipline}

A registered test proves only its asserted scope. Optional ETAP, OpenDSS,
GridLAB-D, commercial solver, and platform-specific results must state the
build/runtime prerequisites used.  A theory document or generated plot is not
verification evidence unless a reproducible test command and acceptance
tolerance accompany it.
