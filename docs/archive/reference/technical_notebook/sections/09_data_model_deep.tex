% ============================================================
\section{Complete Data Model: Enumerations, Defaults, and Error Types}
\label{sec:data-model-deep}
% ============================================================

This chapter provides the complete reference for the lower layers of the
\texttt{model/} subsystem: the enumeration hierarchy (nine sub-headers under
\texttt{include/hacdcpf/model/enums/}), the centralised \texttt{Defaults}
constant struct, the \texttt{Result<T>}/\texttt{Error}/\texttt{ErrorCode}
monadic result type, and the validation subsystem.

\subsubsection{\texttt{Result<T>} Monad}

\texttt{Result<T>} is a \texttt{std::variant<T,Error>}
wrapper that carries either a success value or an error:

\begin{center}
\begin{tabular}{ll}
\hline\hline
\textbf{Member} & \textbf{Description} \\
\hline
\texttt{has\_value()} $\to$ \texttt{bool} & True if successful \\
\texttt{operator bool()} & Alias for \texttt{has\_value()} \\
\texttt{value()} $\to$ \texttt{T\&} & Access success payload (UB on error) \\
\texttt{operator*(), operator->()} & Dereference to payload \\
\texttt{error()} $\to$ \texttt{Error\&} & Access error payload \\
\texttt{value\_or\_throw()} $\to$ \texttt{T\&} & Access value or throw \texttt{std::runtime\_error} \\
\hline\hline
\end{tabular}
\end{center}

Typical usage:
\begin{verbatim}
auto res = safe_solve_power_flow(sys, opt);
if (!res) { std::cerr << res.error().message; return; }
auto& r = res.value();
\end{verbatim}

\subsubsection{Validation Checks}

\texttt{validate(const HybridPowerSystem\&)} in
\texttt{validation/validate\_system.hpp} / \texttt{src/validation/validate\_system.cpp}
runs 15 static checks and returns a \texttt{ValidationReport}:

\begin{enumerate}
  \item \textbf{base\_mva $>$ 0} --- system base must be positive.
  \item \textbf{Duplicate AC bus IDs} --- no two AC buses share an index.
  \item \textbf{Duplicate DC bus IDs} --- no two DC buses share an index.
  \item \textbf{AC branch bus references} --- \texttt{from\_bus} and \texttt{to\_bus} exist.
  \item \textbf{DC branch bus references} --- same, in the DC network.
  \item \textbf{AC voltage limits} --- $V_{min} > 0$, $V_{min} < V_{max}$.
  \item \textbf{Generator P limits} --- $P_{min} \leq P_{max}$.
  \item \textbf{Generator Q limits} --- $Q_{min} \leq Q_{max}$.
  \item \textbf{Generator bus reference} --- generator bus exists in AC network.
  \item \textbf{Slack bus presence} --- at least one \texttt{BusType::SLACK} bus.
  \item \textbf{Transformer tap ratio} --- $0.5 < \texttt{tap} < 2.0$.
  \item \textbf{VSC converter bus references} --- AC and DC bus indices exist.
  \item \textbf{DC-DC converter bus references} --- both DC buses exist.
  \item \textbf{Non-negative AC branch resistance} --- $r_{pu} \geq 0$.
  \item \textbf{AC/DC base MVA consistency} --- subsystem base MVA matches system base.
\end{enumerate}

Any \texttt{Error}-severity result from \texttt{validate()} will prevent the
solver from proceeding.  The \texttt{Error::validation\_failed()} factory
method wraps a failed report into the structured error type for API return.
