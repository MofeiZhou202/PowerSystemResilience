# 研究资料

本分类管理论文、理论探索、复现实验与历史材料，不将其自动视为生产契约。

| 类型 | 位置 | 说明 |
|---|---|---|
| 长篇研究论文 | [论文工作区](../latex/paper/README.md) | 含 `main.tex`、参考文献、图表和复现资料 |
| 平台综述与专题长文 | [LaTeX 工作区](../latex/README.md) | 平台综述、SPPT、年度时序及生成证据 |
| 当前理论与模型 | [理论与模型](../theory/README.md) | 与源码直接对应的实现参考 |
| 历史理论与审计 | [归档索引](../archive/README.md) | 仅用于决策溯源 |

按篇幅与用途，LaTeX 资产分为“工业手册”“完整论文”“专题长文”“章节片段”“生成证据”五类；
具体归属见 [LaTeX 文档说明](../latex/README.md)。
