## 第 2.6 节 SCED 与 LMP 比较

SCED 原文为 2.6.4.1–2.6.4.18，LMP 原文为 2.6.5.1–2.6.5.16，
节点电价乘子公式单列于 2.6.6（正文第 62–63 页）。
完整条号映射见 LaTeX 规则章；完整公式、定义保留在主手册附录的官方原页。

| 规则要求 | 生产路径对照 |
|---|---|
| SCED 去掉启动与最小技术出力费用，保留跨省费及 M1–M4 等项 | PRICE 的平台报价目标与规则输入、松弛不一致 |
| SCED 继承 SCUC 组合；开停轨迹上下界均取轨迹定值，先处理调频预出清 | 固定组合存在，但没有全套轨迹与调频预出清边界 |
| LMP 单独以 M1′–M4′ 定价罚因子求解 | `extract_pricing` 直接提取平台固定组合 SCED 对偶，没有独立规则 LMP 模型 |
| 不可定价机组固定于 SCED 出力，可定价机组按 δ 限制在 SCED 附近 | PRICE 无相应资格与 δ 重建界机制 |
| 储能按 SCED 结果及 δ 重建设备界 | PRICE 无相同规则；原文自身另有 min/max 和符号歧义 |
| LMP = 平衡区乘子 − 线路拥塞项 − 断面拥塞项 | 平台返回 AC/DC 母线平衡对偶；缺少规则的断面、交易映射和独立重定价 |
| 2.6.5 未单列新能源/优先计划约束，也未完整重列 SOC 递推 | 已保留校核注，不能擅自声称自动继承全部 SCED 约束 |

## 原文歧义与不可擅自补齐的内容

LaTeX 中 A1–A7 为对应校核注，附录保留原貌。

| 校核注 | 原文位置 | 问题与处理 |
|---|---|---|
| A1 | 28–29、34、38 | 目标未写功率到电量的时长因子；T=98 与日内 T=96 混用；峰谷点时长、权重及状态连接未充分定义。不插入自定权重 |
| A2 | 30、31、34、41、42 | Na 文字定义、负荷备用 i/q、日能量重复 i、关口映射缺求和下限。保留并指出 |
| A3 | 32–34 | 出力分解求和外 Pmin 下标 m 未绑定；段界/增量宽度与停机状态连接不明确；稳定下限与启停轨迹需区分适用时段 |
| A4 | 29、36 | 冷/温/热态启动与单一启动费式之间缺状态选择细节；不据此取消三态要求 |
| A5 | 28、41 | 目标有 M4 SLk−，优先计划约束却未写松弛；不自行改变约束 |
| A6 | 40 | 水库式缺时长转换，上游 P 称谓与耗水率关系需澄清；流量 Qd 不等于电量 Q |
| A7 | 58–59、62 | LMP 储能放电 max/min 标签及负充电量附近界顺序有疑问；SOC、新能源和优先计划约束未完整重列 |

这些问题不阻碍下载、忠实引用与文档比较，但阻碍“唯一执行模型”和“生产结果完全等价”的
宣称。需要经确认的业务边界或发布机构澄清后，才能选择执行解释。
