生效。用户操作见[周月教程](../../guides/market_simulation_workflow.zh.md)。

[市场求解性能](performance.md)：IEEE118 水量、储能与机组组合的消融计时，
零成本开停机/储能小时方向投影、同日恢复实验有界并行及完整周任务的浏览器计时。
装配路径支持 `assembly_mode=cached|reference|verify`：默认复用符合条件的阶段存储/稀疏
结构，全部数值重新计算；verify 与原有序 map/Triplet 路径逐元素核对。模式不改变数学
formulation。另有严格准入的同一次出清SCED解/下界复用，需精确模型比较与原残差核验；
结构变化自动重建，缓存并发与容量边界见性能手册。
新增同日SCED到LMP有序行列选择复用，定价费用/冻结边界按原式计算；不满足准入走原装配，
verify独立核对矩阵和全部索引。原矩阵、水量/SOC七日承接、完整对偶与首次/重复五次
浏览器验收及分解填充诊断统一记录在[性能手册](performance.md)。大型跨运行缓存仍未启用。
运行模拟新增异常触发原因分析、历史日手动补算和恢复定价范围；默认供需归因仅运行
SCUC/SCED，主结果仍定价。Gurobi 内部 wall 拆分环境/导入/优化/提取，未测阶段为 null。
定价按版本固定算法：百万列Gurobi为8线程障碍法，其余为单线程对偶单纯形，均独立复算
全部行对偶；精确一致及最优性/残差检查通过才
输出有效价格。失败价格为空且不可结算，复算耗时单列，后端版本适用边界见执行契约。

2000节点优化使用原LP独立下界和整数可行性核验，维持请求的MIP gap；候选储能和
负荷轨迹不是与旧gap内解相同的承诺。默认水电版完整单日已由188 s无解改善到
同协议旧版最大61.29/61.41 s；SCED→LMP复用后首次/重复各五次最大58.52/58.57 s，
十次均低于一分钟，非任意模型的硬截止保证。74测试/29807断言、原矩阵及20份完整
输出对照、七日小模型承接、3247054行跨进程对偶核验通过；限于本机Gurobi/合成诊断边界，
最新8107入口和完整证据见性能记录。

`market_sced_cross_validation`；实时/博弈/混合出清的GUI回归见[开发状态](../../overview/development_status.md)。

## 平台实现材料

### GUI 运行入口

在仓库根目录运行 `./build/macos-release/run_gui_server`，默认端口为 **8088**。
打开 `http://127.0.0.1:8088/xjtu/#southern-market`，或在“电力市场”页面进入
“南方市场 · 算例与边界”。更新可执行文件后需重启旧进程并刷新浏览器。

“市场算例”选择器提供：
- **南方多资源两节点演示**：风光水火储及可控负荷，用于报价/边界编辑、保存、出清与结果查看。
- **单节点解析验证**：100 MW 负荷的手算基准。
- **ACTIVSg2000 水电扩展研究边界**：2000 节点、1744 机组（720 水电）、180 水库、80 储能。
  已验证加载/校验/编辑，未验证完整大规模出清。市场边界独立于 Canvas 工程系统。

报价在“边界数据”中选择“机组运行 / 检修 / 申报”的 segments，或储能交易单元的
充放电报价；结果中选择出清阶段、线路/节点类别和时点。

“电力市场 → 运行模拟”（`/xjtu/#market-operation`）提供周/自然月逐日滚动界面。
