# market 模块技术手册

本目录是 `src/market/` 的唯一模块文档目录。

南方单日、周月滚动和预测场景可显式选择HiGHS或本地Gurobi；时限、gap、线程及
实际后端随结果返回。Gurobi复用相同98点模型，许可证不可用时不静默替换后端。

日前规则模型以《南方区域电力市场现货电能量交易实施细则（2025 年 V1.0 版）》
第 2.6 节为基准。**规则模型与现有生产实现尚不完全一致**；手册先给规则模型，后给平台实现
及差异，不能将实现章节当成该细则的替代版本。

运行模拟已修正为逐日从下一日预测提取峰谷时序边界：周8日预测/7日出清，
月N+1日预测/N日出清；GUI可编辑末日预测并检查来源。求解质量区分最优容差与
限额可行，单值报价/参数及大规模求解边界见执行契约，不作完整规则等价承诺。

## 平台实现材料

### GUI 运行入口

在仓库根目录运行 `./build/macos-release/run_gui_server`，默认端口为 **8088**。
打开 `http://127.0.0.1:8088/xjtu/#southern-market`，或在“电力市场”页面进入
“南方市场 · 算例与边界”。更新可执行文件后需重启旧进程并刷新浏览器。

“市场算例”选择器提供：
- **南方多资源两节点演示**：风光水火储及可控负荷，用于报价/边界编辑、保存、出清与结果查看。
- **单节点解析验证**：100 MW 负荷的手算基准。
- **ACTIVSg2000 水电扩展研究边界**：2000 节点、1744 机组（720 水电）、180 水库、80 储能。
  已验证加载/校验/编辑，未验证完整大规模出清。市场边界独立于 Canvas 工程系统。

报价在“边界数据”中选择“机组运行 / 检修 / 申报”的 segments，或储能交易单元的
充放电报价；结果中选择出清阶段、线路/节点类别和时点。

“电力市场 → 运行模拟”（`/xjtu/#market-operation`）提供周/自然月逐日滚动界面。
“日前市场边界”按细则2.3–2.4列出15类边界的定义、条款、当前实体和覆盖限制。
选择字段“设置”，在每日底稿按稳定ID、时段设置实际值和调整依据，再“校验并预览”。
统调负荷与母线原始预测分别编辑，生效负荷按2.4.1.2比例校正；非市场计划、跨省保障
下限、检修、备用/安全、库水位/流量及水电日电量界均按目录接入已建模字段。
概率场景可采用此手工周底稿；报价单列为交易申报，倍数属于研究扰动。
尚未建模的水位库容曲线、振动区、完整D+1预测等明确列为缺口，不宣称完全规则等价。
主 Canvas 显示当前市场算例拓扑：直接选择场景、日期和时段，或播放时段；
“跟随计算”在每日出清返回后更新画面。点击节点/线路或结果表 ID，可查看
ΔP、ΔPᵢⱼ、价格、限额和条件恢复证据，并跳到所选设备的基准边界编辑器。
红色表示缺额/越限，青色表示富余，绿色表示有效解无异常，灰色表示结果不可用。
大算例按所选设备显示至多 80 节点邻域，设备菜单可定位全量稳定 ID。
市场 Canvas 使用独立市场身份；原工程拓扑保留，切出市场时恢复。
加载市场算例后，按日期及 15 分钟区间设置负荷、风光、来水、线路限额、停运设备，
以及全日报价倍数，点击“应用当日边界”，再开始仿真。曲线与表格显示节点缺额/富余、
数值残差和线路越限；选择结果日期/时段，可查看异常设备及单因素恢复重算的差值。
默认开启恢复重算；暂停在当日计算完成后生效，页面重载后可继续。
该入口是带罚变量的确定性研究诊断，不是全周/月联合最优或 AC 安全认证。
“运行模拟”默认进入“预测场景”：按七日预测中心和固定/均匀/三角/限幅正态分布，
或无概率的区间数生成一周边界；可设置因素相关矩阵及相邻日相关性。负荷、风光、
来水、发电/储能报价、可控负荷补偿、线路限额共同采样。生成后先检查七日边界表，
再逐日出清全部场景；统计表和曲线显示 ΔP、ΔPᵢⱼ 的异常比例、均值、分位数及
未知场景范围。选择场景/结果日期/时段可复核预测中心恢复后的差值。
概率估计仅针对所设置的概率模型；区间模式只报告采样统计。大规模周月和概率场景
出清性能尚未验证，真实预测/报价分布尚未拟合。

新增 `run_southern_day_ahead_market` 独立执行入口，以及 GUI 中的南方规则边界工作区。
其规则版本、A1–A7 执行解释、98 点输入、市场边界和三阶段出清结果均可追溯。
既有通用市场入口保持原契约。该研究执行模型已有解析/回归检查，但不把工程解释和
合成算例测试称为正式市场全模型等价认证，具体覆盖与限制见执行契约。
