# 南方实时电能量市场：规则与执行契约

规则源为[2025 V1.0正式原件](references/southern_region_spot_energy_rules_2025_v1_0.pdf)第3章，正文69–124页（PDF72–127页）。原件优先于本转写；通用`run_real_time_market`双结算模型不等于本规则。新入口使用独立实时边界与结果，不覆盖日前、辅助服务及周月结果。

## 理论与准入

RATIONALE：3.1、3.5.2–3.5.7明确15分钟滚动、2小时SCUC/SCED24×5min、LMP8×15min。共享稀疏建模器的时间维度由边界决定；日前仍98点。两阶段24点窗口分别形成0–2h执行前瞻与2–4h参考前瞻，第二窗口承接第一窗口末态；每次滚动只承接第3个5分钟点，不能把2小时末态当15分钟后的状态。输入72个5分钟点（6h），支持最多8次15分钟滚动。后续观测替换必须重新保存快照，不以过期预测冒充最新遥测。

目标（3.5.3/4）：`min Σ_t dt[Σ_g,m c_gm p_gmt + Σ_k fee_k f_kt + M1Σ_l,s(slack+ + slack-) + M2Σ_r deviation_rt + M3Σ_h spill_ht*3600/water_rate_h + M4Σ_k priority_slack_kt]`。原实时SCUC目标未写启动费/最小技术出力费，虽后文解释其符号，本执行不收取这两项；保留开停状态、最小开机义务（3.6.5）和爬坡；非空启停功率轨迹因缺少滚动初始阶段历史而拒绝。采用日前A1–A7增量报价/小时成本/SI水量解释并明确单位。

新增事故备用（3.5.3.17/3.5.4.14）：非固定及固定火电`r>=0,p+r<=u*pmax,r<=u*10*ramp_up`；水电`p+r<=available*pmax`，原式未乘开机状态，可包含备用水机容量。省内`Σr+Σr_pumped+slack>=requirement+reduction`。固定抽蓄净功率非负时备用为声明限开容量减出力，负时为净抽水功率取负。事故备用是独立事故产品，不自动与调频同时激活；实际预留上限可经边界扣减。SCUC目标未给负荷/事故松弛罚项、LMP目标有事故松弛而约束目录未列事故备用：必须显式选择有限罚值，承认执行解释；报告全部松弛，不能视作物理可行。

复杂度：主体/网络变量及主要约束O(T(G+L+R))；开停时窗最坏O(GT²)。24点单模型主体变量约为98点的24/98，2个窗口与8点LMP分别求解；不承诺固定速度比。手算100MW负荷、200元/MWh，2h能量200MWh、报价成本40000元、LMP200；爬坡1MW/min第一步增量不得超过5MW；只执行前三点累积25MWh。火电100MW上限、90MW出力、1MW/min，事故备用最多10MW；11MW需求应产生1MW短缺或严格不可行。容差1e-6 MW/MWh/CNY；测试共享日前回归、独立公式、滚动承接、定价维度、拓扑停运、GUI及IEEE118。

## 约束与定价

3.5.3共有20组约束：平衡、正备用、负备用、一次调频、特殊状态、分段出力、分段费用、功率上下限、机组群功率、机组群电量、水电全厂功率/电量、爬坡、线路、断面、储能、HVDC、事故备用、水位、新能源、跨省优先。3.5.4对应19组；3.5.6对应16组，固定离散状态并采用SCED邻域及非定价资源固定出力。

### 可核验公式映射

以下为执行形式；`dt=1/12 h`用于SCUC/SCED，定价为`1/4 h`，功率MW、能量MWh、价格元/MWh。`u`为开机状态，`a`为可用状态，`epsilon`为显式松弛；`s+、s-`为启停事件。代码行族前缀`2.6.*`表示共享日前建模器的实现身份，不能当作实时条款编号。

|---|---|
|3.5.3.1|逐节点净发电+固定注入+储能−负荷+削减+deficit−surplus=网络净送出。`balance`行及`diagnostic_imbalance`；默认严格平衡，诊断松弛需显式罚价|
|3.5.3.2|`Σ(alpha_up Pmax − P) >= R_up + R_network`，保留储能及负荷削减对区域平衡的影响。水电alpha为`available*reserve_up_eligible`，火电为`u*reserve_up_eligible`；`2.6.3.2`|
|3.5.3.3|`Σ(P − alpha_down Pmin) >= R_down − R_load`，水电/VPP资格与开机状态分别处理；`2.6.3.3`|
|3.5.3.4|`0<=r_primary<=u Pmax−P`及`r_primary<=u Pmax fraction`，省内/直调组总量≥需求。原式min转换为上界可分配容量；固定抽蓄计划若需一次调频应通过显式资源/组边界表达，不从净抽水功率推断；`2.6.3.4`|

|3.5.3.19|新能源`P<=forecast`、`P+deviation>=beta*forecast`，资格与偏差上限明确；`2.6.3.20`|

SCED固定SCUC离散状态，应用外部调频预留并重新优化连续出力。定价固定前序SCED离散选择和非定价出力；定价资源`(1−delta)P_sced<=P_lmp<=(1+delta)P_sced`与物理上下界取交集。储能定价是否保留能量约束、新能源/优先计划是否保留，由`execution.lmp_storage_policy/lmp_renewable_priority`明确选择；不得把一种解释写成官方勘误。定价程序可能因15分钟状态投影失败，返回`prices_valid=false`与`pricing_error`，仍保留有效5分钟排程。

网络`A f = injections`、`f=diag(baseMVA/x) A^T theta + phase_shift`，与每时刻拓扑对应的PTDF等价，逐岛参考角；保留线路/断面双向松弛。`DeltaP=deficit-surplus`，同时报告总松弛`deficit+surplus`；`DeltaPij`为线路正/反越限松弛，并独立重算物理越限。角度模型避免显式稠密PTDF矩阵。

水位`z_t=z_(t-1)+300/A*(inflow+upstream_delayed_release-release)`；`release=spill+Σp*water_m3_mwh/3600`。储能`E_t=E_(t-1)-dt*(pdis/eta+pch*eta)`且pch≤0；小时内互斥按真实小时分组（5分钟12点、15分钟4点），跨滚动保留已执行小时模式。窗口末SOC显式声明，不能每2h无说明地套日末目标。机组群/水库窗口MWh、负荷最大削减MWh及储能剩余循环容量必须标注时域。

实时LMP另建8×15min模型。执行解释：采用每组3个5分钟点的末点状态/功率/网络作为15分钟代表，独立LP取对偶除以0.25h；原规则没有明确5分钟到15分钟状态转换细节，输出必须披露该采样解释。跨3点的拓扑/开机变化不表示15分钟全过程均满足该LP。发电小时价为4个已实际滚动得到的15分钟价算术均值，缺点为null，不把未执行的预测点用于历史小时结算；实际发用电量、正式价格核验及省级用户侧政策不在本模拟中虚构。

3.7.7区分边界未准备、程序故障、错误边界等核验机制；真实历史缺价不得自动用零或未来价补齐。3.6供热转换、调用测试、应急增开/停、非市场新能源公平序位及3.8信息发布需要具名外部边界/事件，不宣称软件自行完成法定运营。

## API、GUI与索引

公共入口在`include/hacdcpf/market/southern_market.hpp`：`southern_realtime_defaults/catalog`、`make_southern_realtime`、`step_southern_realtime`。边界校验、采样和承接在`src/market/southern_real_time.hpp`；SCUC/SCED/LMP构建与运行在`src/market/southern_market.cpp`。HTTP为`tests/run_gui_server.cpp`的`GET/POST /api/session/southern_realtime`。
