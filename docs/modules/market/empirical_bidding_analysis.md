# 实际报价对照实验

后续[全模块可证伪验证](aemo_validation.md)增加官方调度/FCAS数据、两母线拥塞、
256组合UC穷举、共享梯级/SOC、七日/实时/调频与现金复算；保留AC及容量不足反例。
该扩展不改变本篇“跨市场报价形状迁移、尚未校准南方行为”的结论。

## 实验协议

本实验使用 AEMO 官方 NEMWEB 的 BIDMOVE_COMPLETE 文件，比较真实申报曲线与
`market_operation.cpp` 中共同正倍数报价扰动的表达能力，再调用本项目南方市场出清模块。
这是跨市场、固定边界的行为结构实验，不是南方市场报价校准，也不是澳大利亚市场规则复现。
文献证据及阅读深度见 [报价行为审查](bidding_behavior_review.md)。

**编码前理论依据及验收约定**：

- 模型：取每个交易日 PERIODID=96、ENERGY、GEN/LOAD 的最终报价快照，按 DUID、方向、
  交易日与产品连接日价格和时段容量。文件没有完整版本历史，不重建日前信息集。
  时间戳保留 AEMO 原文；96点的 INTERVAL_DATETIME 必须为当日12:00。
- 训练期2026-08-28至08-31，对照期09-01至09-03，按时间分割。固定基准为08-31。
  逐机组保持模型直接使用基准曲线；共同系数模型使用正系数乘全部基准段价。
  另计算利用当日实测报价最小二乘拟合的共同系数，作为**事后最佳拟合参照**，不能算预测。
  若连该参照也有明显误差，则调整随机系数分布不能消除该结构误差。
- 官方数据字典的主键是适用日SETTLEMENTDATE、DUID、BIDTYPE、DIRECTION；
  BIDSETTLEMENTDATE是原始申报日，跨日沿用时允许不同，单独计数，不作为连接相等条件。
- 公式：将申报数量截到 `min(MAXAVAIL, sum(BANDAVAIL))`，保留负价格。
  GEN保留低价优先可售部分，LOAD保留高价优先购电意愿部分；随后按价格升序作分布比较。
  以容量百分位十等分的档内均价表示每台机组的可售供给曲线
  `x[i,k] = 10/Q[i] * integral_(k*Q/10)^((k+1)*Q/10) p_i(q) dq`。
  该映射保持满容量报价积分，不保证任意部分出力时的费用或边际价完全保持；另报映射绝对误差。
  零可售容量从形状统计排除并计数；LOAD 分开统计，不能解释成可控负荷补偿。
- 共同系数事后最优值 `c*=max(0, sum(x*y)/sum(x*x))`，为固定曲线族平方误差最小值。
  预测共同系数取训练期逐日相对基准拟合系数的均值，不使用对照期价格。
  误差按 DUID×日×等容量档等权，另报正负价容量份额与分位数，不用市场出清价替代报价。
- 出清迁移：仅按训练期平均可售容量选20台 GEN，ID排序打破同容量并列。
  每台映射100MW、十档各10MW，价格数值除100作为人工货币单位。
  这不是AUD/CNY汇率换算；源价格统计仍为AUD/MWh。所有机组固定开机、Pmin=0、
  无启动费用、无水库/储能/网络跨期限制；三种固定负荷率35%、65%、90%，每天96+2点。
  三种报价输入均用相同物理边界；前96点统计费用，另外两点仅为模型延伸。
- 验证：在上述可分离、无网络拥塞条件下，SCUC/SCED应等价于报价从低到高填充负荷。
  独立排序oracle检查每个时段功率平衡绝对误差<=1e-5 MW，日费用相对误差<=1e-6，
  不以某一并列机组的特定分配作为唯一正确答案。LMP用oracle左右导数区间检查。
  因固定开机，该实验不验证整数搜索、水库机会价值、故障、调频或结算规则完整性。
- 成本模型：CSV流式解析O(R)，保存目标时段O(U)；供给曲线积分每机组最多10原始档，
  排序oracle每场景O(10U log(10U))；调用现有C++求解器，不修改求解算法。
  定量预期是上述等价误差容差；不预设实证模型优劣或宣称价格预测精度。

数据检查后的协议修正：20台训练期候选中，ERB01在三个对照日均为零申报容量，
LOYYB2、LYA2在第三日也为零。固定20台均可售的假设不成立；因此仅对当日非零申报
的19/19/17台做配对出清，三种报价方案共享同一可售集合，负荷仍为集合容量的35/65/90%。
保留零容量原始记录，不把零容量当作零报价、不用别的机组补齐20台，也不把该实验解释为容量预测。
该调整在出清前完成，数值验收容差不变。

下载地址、SHA256、实际筛选数、原始日/时段记录、机组映射、完整API结果均写入
`external_data/market_bids/` 与 `output/market-bids/`。没有南方实际申报、主体所有权、
合同持仓、燃料成本/水价值和申报时可见预测，就不能识别真实策略或声称本地概率已校准。

### 样本与行为误差

七天每天含475个GEN、98个LOAD的ENERGY日记录，全部产品共15827条日记录和4558176条时段记录。
仅抽取每日12:00的ENERGY曲线；排除零可售容量后，GEN为385个不同DUID、2536个DUID日，
LOAD为58个不同DUID、349个DUID日。DUID是注册调度单元，不等于独立公司或单台物理机组；
GEN也可能包含储能放电，LOAD可能包含储能充电，不能把两类分别全部解释为常规发电商和零售用户。

训练期持续可售GEN348个、LOAD43个。对照期分别有1009、119个配对DUID日，缺少正容量的记录
已分别计数。以下误差单位均为AUD/MWh，按配对DUID日及十等容量档等权，RMSE先合并平方误差
再开方；不是三天RMSE直接取平均。

|曲线模型|GEN MAE|GEN RMSE|LOAD MAE|LOAD RMSE|
|---|---:|---:|---:|---:|
|08-31逐DUID曲线保持不变|771.88|3629.71|321.34|555.56|
|训练期拟合共同系数|896.94|3598.60|753.97|2797.88|
|当日事后最佳共同系数|958.37|3592.02|327.44|553.74|

关键判断：即使允许使用当日实测数据挑选共同系数，GEN RMSE也只比保持模型降低约1.04%。
这里最小化的是平方误差，所以MAE可能反而上升，不能将两个指标混为一谈。
GEN对照期约30.4%至43.8%的可配对DUID曲线发生变化；价格档位、段容量和相对位置变化
无法完整落在共同倍数这一维曲线族内。训练期拟合系数GEN0.96298、LOAD0.25；
LOAD的0.25来自四天非负最小二乘系数0/0/0/1的均值，反映本小样本的符号/尾部变化及估计不稳定，
不能作为生产参数推荐。

这些基准给共同系数模型提供了真实的08-31逐机组曲线，已比当前IEEE118固定合成报价更有信息；
并非声称已经重放GUI默认0.9至1.1随机场景，也没有实现或比较Roth-Erev/SDDP策略的预测精度。
真实GEN可售曲线的负价容量占比为59.27%、高于1000 AUD/MWh占比为20.88%
（先算各DUID日份额再等权平均，非全市场容量加权占比）。不能拿这些比例直接配置中国市场价格上下限。
原报价所有正申报数量档的未加权价格中位数为7.72 AUD/MWh，95%分位为22963.36；
统计保留高价档，未把其当异常值删除。

十等分映射自身的平均绝对曲线误差为GEN62.19、LOAD10.32 AUD/MWh；满容量报价积分保持，
部分出力的费用/边际价仍有映射近似。这些误差不能误记为求解器误差。
报价图见 `output/market-bids/bid_errors.{png,pdf}` 与 `individual_bid_shapes.{png,pdf}`。
前者n为当日配对DUID数、曲线相对于08-31；后者展示TUMUT3/MURRAY归一化曲线，不能仅据曲线
把变化归因为来水或水价值，尚缺其当时物理边界、合同及预测信息。

### 本模块配对出清

通过生产API `/api/session/southern_market` 保存边界，再调用
`/api/session/run_southern_market`，启动独立临时服务器并在结束后退出，未修改用户GUI会话。
三个对照日、三种报价、三种负荷率，共27组；各组98点，由现有C++ SCUC→SCED→LMP执行。
HiGHS实际返回 `schedule_only`，不是交流安全认证。固定开机、小系统单母线条件下：

|指标|预先验收值|实测最大值|
|---|---:|---:|
|全部98点功率平衡残差|1e-5 MW|0 MW|
|96点日申报费用与独立排序oracle相对误差|1e-6|1.88e-13|
|LMP到oracle左右导数区间的距离|1e-5人工货币单位/MWh|0|

全部27组通过；单次API耗时0.389至0.585秒，包含建模和三阶段执行。
这不是大规模整数搜索性能证明，也不是2000节点算例耗时。
相对当日实际报价形状输入，九个配对边界的LMP MAE为：逐机组保持2.32990，
训练共同系数5.06216人工货币单位/MWh。该实验中后者更差，但三天样本不能支持所有时期的优劣结论。

例：09-01、65%负荷率，实际形状LMP5.88890，逐机组保持0.82840，共同系数0.79773。
09-03、90%负荷率，实际形状LMP224.34320与保持模型221.90700相近，
日申报费用却分别为1528820.89与839003.53人工货币单位。
因此**只拟合出清价格不能证明报价曲线或电量分配正确**。申报费用是报价目标项，
不是机组真实生产成本、利润或市场结算支付；本实验不报告缺少成本/合同数据的真实利润。

本组无线路，且固定负荷小于可售容量；节点平衡为零是预期结果，线路越限指标不适用。
不能据此推断故障/来水扰动下的Delta P、Delta P_ij概率，更不能将未建模线路越限填成已验证的零。
出清曲线见 `output/market-bids/clearing_prices.{png,pdf}`，颜色在各日保持一致，
全部价格为人工单位，非南方人民币或NEM实际出清价。

### 文献与改进判断

- AMES及Nicolaisen等文献支持主体异质报价、数量选择和有限信息反馈的研究方向；
  本次实证表明共同系数表达能力有限，但没有因此证明某种学习算法必然更准。
- Fleten等2024年Aneo实务研究将水库续值纳入策略评价；我们有共享水库/梯级物理约束，
  尚未从真实来水、水位、合同及季节水价值校准报价者的跨期机会成本。不能用本次单时点报价
  拟合来替代水电行为验证，更不能把高价报价唯一解释为市场力。
- LOAD应按购电效用或储能充电机会价值建模；AEMO LOAD报价不等于南方可控负荷削减补偿，
  当前400至500元/MWh固定补偿假设未因此被验证。储能GEN/LOAD方向还需按同一资产联结SOC。
- 建议先建立公司/电厂/水库/机组的经济与物理双重映射，再按主体拟合价格档与数量档的条件分布，
  加入可核验水价值和需求效用。使用南方实际申报及申报时可见边界做按时间留出的检验，
  同时评价报价、出清量、价格、末库容/SOC及成本收益；本报告没有把这些建议写成已实现功能。
