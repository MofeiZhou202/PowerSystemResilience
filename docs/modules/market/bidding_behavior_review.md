# 报价行为文献与实现审查

核对日期：2026-09-07。用户问题：市场参与者如何报价，当前模拟是否准确。
范围：发电商、储能、购电用户/售电商、可控负荷；这里将“用户”与“市场参与者”区分。
这是文献与源码审查，不修改出清算法，不将建议写成现有能力。

## 结论

当前适合合成报价条件下的机制实验、算法验证和边界敏感性分析；没有证据证明其能准确预测真实南方市场报价、价格分布或故障风险概率。
尤其需要分开：程序按公式正确执行、模型符合所选规则解释、行为符合经济机制、模型匹配真实市场四种有效性。
此前59项南方模型回归/27962断言与实时6项内存检查/81断言主要验证实现和物理约束，不能充当报价行为的实证校准。

## 方法与当前实现

| 方法 | 典型逻辑 | 本项目对应程度 |
|---|---|---|
|成本/机会成本基准|按增量生产成本或跨期资源价值构造供给曲线；价格接受者仍可能承担预测风险|通用成本报价已实现；水电/储能机会价值没有作为独立报价决策自动生成|
|固定加价/容量策略|成本曲线上加价，或调整申报容量，代表预设策略|通用模块已实现；适合受控市场力实验，不等于真实主体决策|
|随机报价场景|按经验条件分布或假定分布采样报价|南方运行模拟是共同倍数扰动；没有真实报价样本校准|
|利润最大化/双层报价|上层选择报价，底层市场出清；大主体考虑自身对价格的影响|通用模块是有限邻域局部最优响应，不能声称求得完整双层最优解或全策略Nash均衡|
|主体学习|根据各主体可见信息和结算反馈更新行为概率、价值函数或策略|通用模块没有Roth–Erev、Q-learning或深度RL更新；南方滚动模型也未接入通用博弈闭环|
|购电侧效用/组合优化|用户选择消费效用与购电成本，售电商考虑零售合同、现货/偏差风险|目前固定负荷及补偿削减；不是完整效用需求曲线或售电商采购行为模型|

### 源码事实

1. `src/market/participant_behavior.cpp:143`起，报价容量为
   `P_offer=Pmin+(Pmax−Pmin)(1−w)`；段价为`(1+m)[c1+max(0,c2)(P_left+P_right)]`。
   其中m为价格加成、w为容量保留比例。这是成本曲线割线近似与预设策略，c1/c2也是输入假设。
   主体可拥有多台发电机，但未指定所有权时自动将每台活动机组作为独立成本主体（同文件77行起）。
2. `src/market/market_simulation.cpp:5994`起，同时考察各主体加价和容量保留的正/负一步候选，固定其他主体，用出清利润选更好动作，随后同步更新。
   `converged`只表示受检主体在给定邻域没有获利改动，不代表全局最优、全部主体均衡、唯一均衡或市场真实性。
   `run_real_time=true`时策略评价使用传入的同一条实现时序（5897行附近），没有场景期望和风险偏好层；若解释为事前报价，必须处理这一信息可得性差异。
3. `src/market/southern_boundary.cpp:719`起，IEEE118水电基础段价为`35+3*(rank%6)`，热电为`180+3*rank`，再加固定分段价差；风/光5/8元/MWh，可控负荷400–500元/MWh。
   这些数值由代码构造并标为synthetic，不是从南方实际申报统计估计。IEEE118验证了电网/资源机制，没有因此验证报价数据。
4. `src/market/market_operation.cpp:64`起，全部发电机段价乘相同`bid_scale*generator_bid_scale`，储能充放电报价也乘同一因子；负荷补偿乘`bid_scale*load_bid_scale`。
   正共同倍数不改变发电报价段之间的相对排序。它可以改变与负荷补偿、未同步缩放罚项等的权衡，但不能表达各主体独立加价和竞争排序变化。
5. `src/market/market_forecast.cpp:65`起，默认8场景、均匀0.9–1.1、潜在Gaussian copula、日AR(1)相关0.5。相关矩阵与边缘分布为设定值，非数据拟合。
   七个因素是日级共同倍数；现有模型并非逐公司/逐流域/逐机组/逐15分钟的联合报价误差模型，Gaussian copula也不能自动覆盖极端事件尾部依赖。
6. `src/market/southern_market.cpp:505`起，可控负荷是在功率与累计电量界内最小化`compensation*reduction*dt`。
   这是有偿中断模型，没有用户消费效用、移峰后的回补、设备温度/生产任务或售电商合同持仓。
7. `src/market/southern_real_time.hpp:100`起严格封存报价，只更新允许的实时边界。这与本次采用的南方实时规则解释一致；不能为增加“智能报价”而擅自在每轮实时窗口重新报日前价格。

## 水电主导系统的主要缺口

水量平衡约束能限制短期发电可行性，但不会自动把未来一周、汛枯季节的蓄水机会价值变成发电商报价。
南方出清模型已经具有共享水库和梯级滞后约束；缺少的是报价者自己的跨期利润/风险决策以及独立校准的后续水价值。
同一水库多机应按统一库水资源协调，同一流域还应考虑下游价值、旅行时间及生态约束。物理流域和经济所有权是两种关系，不可默认一个流域必然是一个公司，也不可默认700台水机等于700个独立竞价主体。

以下是建议的研究模型，不是对R7或南方规则原式的逐字转写：

`max_policy E[现货及合同净收入 − 运行成本 − 偏差/违约成本 + V_terminal(S_H)] − rho*CVaR_alpha(L)`。

报价决策必须对当时不可见的场景实现满足非预见性；只有事后控制才能响应已经观测的信息。CVaR作用于明确定义的损失L；不能把利润和损失符号混用。
水价值`v_h = ∂V/∂S_h`的单位为元/m³。水电发出1MWh使用q m³时，简单单库报价基准可解释为`运行增量成本 + q*v_h`。
梯级还要计入下游未来获得水的价值、滞后与终期耦合；不能把上式不加修正地套到所有梯级水库。

对于凹的利润续值，可用`v_terminal <= a_k + b_k^T S_H`构成分段线性近似（取各仿射上界的最小值）；系数必须来自经验证的续值算法或有出处的假设，有限割近似还需误差验证。
SDDP成本最小化常用凸值函数的下界割，方向不同；这些“水价值割”也不同于SCUC整数规划的Gomory/MIR等强化cuts。

储能应考虑SOC机会价值、效率、退化及能量/辅助服务竞争；可控负荷应区分真正可中断、可转移和温控负荷。
若研究购电报价，建议从凹效用`U(d)=a*d−b*d²/2`的价格接受型模型入手：`max U(d)−price*d`，在允许负荷区间内得到递减需求；若规则只允许报量，则效用优化在参与者侧形成报量，不能擅自改变出清规则。

## 无真实报价时如何验证

首先明确：公开价格/发电量通常不能唯一反推出报价曲线。不同所有权、成本、合同、报价和边界都可能产生相近价格；给单一价格序列拟合成功不等于识别成功。

1. **结构验证**：日前封存、报价段宽/单调性、参与资格、价格范围及产品边界符合所选规则。相应软件断言属于实现证据。
2. **机制验证**：单库两时段留水/发电手算、丰水弃水与枯水稀缺对照、共享水库分机不重复计水、储能无利差不做亏损循环、需求效用/补偿阈值及可转移负荷电量守恒。方向性判断要在其他条件固定且没有约束切换时使用，不能声称水越少报价在任何条件下都必然更高。
3. **行为算法验证**：成本基准、固定加价、随机行为、学习行为使用相同场景比较；小系统用离散全动作枚举检查best-response regret，检验邻域之外是否仍可获利；改变公司所有权、初始策略、随机种子，记录不收敛和周期振荡。
4. **经验校准与样本外验证**：用公开分时价格、分类型出力、净负荷、来水/水位、断面能力与政策信息约束参数；按时间分训练/验证/测试，保留汛期/枯期及稀缺日。报告价格分位数/尾部、价量相关、发电结构、水位轨迹、收益与偏差，而非只比较均价。没有主体真实申报时，只能称结果分布/机制获得有限支持，不能称主体报价准确复现。

所有反事实策略比较都应包含期末SOC/水价值，避免以耗尽库存换取当期高收入造成虚假优势。
建议优先补水库机会价值，再补主体异质性和有限信息学习；不能期待仅改成深度强化学习就弥补缺失的物理模型、数据和奖励口径。

概率口径：目前输出的是`P_model(越限 | 假定输入分布、行为模型、边界与求解口径)`，不是已校准的真实系统越限概率。
8个默认场景适合流程检查。若真实模型事件率为1%，独立8次采样至少看到一次的概率仅`1−0.99^8≈7.73%`；要以95%概率看到至少一次约需299个独立场景。这只是事件发现能力，不是1%概率已被精确估计，更不修复输入分布误设。
应分别报告物理不确定性、报价行为不确定性、参数/结构不确定性及求解未决场景；相同输入/随机种子做配对对照，避免将输入间既有相关性解释为唯一因果。

## 本次验证边界

本篇审查读取并对照了源码和已有测试，本篇研究模型和验证清单不能写进GUI作为已实现功能。
随后按用户要求完成了[实际报价对照实验](empirical_bidding_analysis.md)：AEMO七天申报数据、
27组现有南方模块配对出清及独立oracle。该实验验证共同系数的局限和受控出清一致性，
未校准南方实际报价，也未实现上述学习或水价值报价研究模型。
