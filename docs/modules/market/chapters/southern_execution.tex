\subsection{边界组织与回溯}
\srcpath{src/market/southern\_boundary.cpp:southern\_market\_schema}
是 JSON 字段、单位、取值范围与 GUI 编辑控件的唯一来源。日前输入包括
统调/母线负荷、区外与非市场主体计划、机组逐时运行/检修边界、输变电检修、
线路/断面正反向限额、机组群、储能、直流中枢/端口、跨省交易以及水库运用边界。
字段全部校验后才保存，使用稳定 ID 引用；零备用、零启停次数和零循环数均有效。

第 2.4.1.2 的母线预测校正为
\begin{equation}
 D^{eff}_{b,t}=D^{raw}_{b,t}\frac{D_{a,t}}{\sum_{k\in a}D^{raw}_{k,t}},
 \qquad b\in a.
\end{equation}
当统调预测非零而母线总和为零时拒绝保存。原始/有效边界同时写入结果，
无功负荷保持独立输入。D$-2$ 保障电量修改保留调整前后值、原因及来源。

GUI 的边界工作区提供类别/实体选择、逐时序列与区间批量编辑、保存/重载、JSON
导入导出、基准设定和恢复。情景比较返回实际边界 JSON Patch、日电能费用、
机组电量/曲线和电价差值。比较是确定性输入差分，不是统计相关或因果结论。

\subsection{模型与量纲}
\srcpath{src/market/southern\_market.cpp:build\_model}
建立稀疏 SCUC、固定组合 SCED、独立 LMP；日内 96 点固定 15 分钟，D$+1$
峰谷代表点必须明确起点、时长及费用权重。代表点空隙不积分未观测的水量与电量。
日电量约束和报告只计运行日 96 点。

分段报价采用递增增量段宽，允许负价；三态启动费按已停分钟数和明确门槛决定，
三种启动曲线、停机曲线与稳定出力互斥。状态变量为二元，最小开停时间保留初始
状态已持续时间。储能使用负充电功率、同小时联合方向约束，独立初始/终止能量和
效率加权循环。水库采用 SI 单位：
\begin{align}
 Q^{release}_{h,t}&=P_{h,t}h_h/3600+Q^{spill}_{h,t},\\
 Z_{h,t}&=Z_{h,t-1}+\frac{3600\Delta t}{S_h}
 (I_{h,t}+Q^{up}_{h,t-s}-Q^{release}_{h,t}).
\end{align}
$h_h$ 为 m$^3$/MWh，流量为 m$^3$/s，库面面积为 m$^2$；上游迟滞历史显式给定。
生态/航运下泄下限、防洪上限、流量变幅与日电量边界同时进入约束。

网络逐时删去停运支路及其潮流方程，B$\theta$ 形式与同一无损拓扑 PTDF 形式对应。
线路与断面具有独立双向限额及 M1 松弛；直流功率包含恒定损耗、中枢守恒、
上/下调及相邻调节方向限制。商业交易与物理关口显式映射。
优先计划使用硬电量下限或显式选择带 M4 的缺额解释，两者不能混称同一原式。

\subsection{定价与安全}
SCUC 后应用具备来源的调频预出清容量：$P^{min}+R^{reg,down}$、
$P^{max}-R^{reg,up}$ 进入 SCED。调频市场本身的完整报价优化属于另一份规则，
本入口消费其容量结果，不宣称复现该独立市场。停机/轨迹机组获分配时明确失败。

LMP 使用独立罚因子与 SCED 出力邻域；不可定价机组固定，负充电附近界按有序区间
解释。是否保留 SOC/循环、未单列新能源/优先电量约束必须明确选择。
备用经平衡消元装配后，原始平衡乘子恢复为
\begin{equation}
 \lambda^{original}=\lambda^{transformed}+d^{up}-d^{down},
\end{equation}
其中 $d$ 为求解器上界行 shadow price，非拉格朗日非负乘子。
\srcpath{stage\_result} 在原单位代回每条约束和变量界，输出残差与约束族。

交流安全检查电压、线路有功/视在功率、断面和同母线机组聚合 P/Q 能力；网损和平衡
机有功调整单列。越限后以局部潮流灵敏度添加约束并重新求 SCUC/SCED，只有重新
执行的 AC 潮流通过才认证。局部切面不是非凸安全域的全局 oracle，迭代耗尽/潮流
失败会拒绝认证和定价。选择 \texttt{schedule\_only} 时可查看线性计划，但顶层
\texttt{feasible=false}，不能解释为通过交流认证。

\subsection{验证证据与限制}

输入拒绝、拥塞/检修、三态启动/轨迹、分省备用、调频改限、机组群、储能、水库、

非法输入原子拒绝、修订冲突、基准/情景差值及桌面/手机布局。
具体 Release/ASan/UBSan 结果及命令以开发状态为准。
该证据不覆盖真实省级历史出清回放、发布机构释义、调频市场独立优化或大规模在线时延。
