\subsection{边界组织与回溯}
\srcpath{src/market/southern\_boundary.cpp:southern\_market\_schema}
是 JSON 字段、单位、取值范围与 GUI 编辑控件的唯一来源。日前输入包括
统调/母线负荷、区外与非市场主体计划、机组逐时运行/检修边界、输变电检修、
线路/断面正反向限额、机组群、储能、直流中枢/端口、跨省交易以及水库运用边界。
字段全部校验后才保存，使用稳定 ID 引用；零备用、零启停次数和零循环数均有效。

第 2.4.1.2 的母线预测校正为
\begin{equation}
 D^{eff}_{b,t}=D^{raw}_{b,t}\frac{D_{a,t}}{\sum_{k\in a}D^{raw}_{k,t}},
 \qquad b\in a.
\end{equation}
当统调预测非零而母线总和为零时拒绝保存。原始/有效边界同时写入结果，
无功负荷保持独立输入。D$-2$ 保障电量修改保留调整前后值、原因及来源。

GUI 的边界工作区提供类别/实体选择、逐时序列与区间批量编辑、保存/重载、JSON
导入导出、基准设定和恢复。情景比较返回实际边界 JSON Patch、日电能费用、
机组电量/曲线和电价差值。比较是确定性输入差分，不是统计相关或因果结论。

\subsection{模型与量纲}
\srcpath{src/market/southern\_market.cpp:build\_model}
建立稀疏 SCUC、固定组合 SCED、独立 LMP；日内 96 点固定 15 分钟，D$+1$
峰谷代表点必须明确起点、时长及费用权重。代表点空隙不积分未观测的水量与电量。
日电量约束和报告只计运行日 96 点。

分段报价采用递增增量段宽，允许负价；三态启动费按已停分钟数和明确门槛决定，
三种启动曲线、停机曲线与稳定出力互斥。状态变量为二元，最小开停时间保留初始
状态已持续时间。储能使用负充电功率、同小时联合方向约束，独立初始/终止能量和
效率加权循环。水库采用 SI 单位：
\begin{align}
 Q^{release}_{h,t}&=P_{h,t}h_h/3600+Q^{spill}_{h,t},\\
 Z_{h,t}&=Z_{h,t-1}+\frac{3600\Delta t}{S_h}
 (I_{h,t}+Q^{up}_{h,t-s}-Q^{release}_{h,t}).
\end{align}
$h_h$ 为 m$^3$/MWh，流量为 m$^3$/s，库面面积为 m$^2$；上游迟滞历史显式给定。
生态/航运下泄下限、防洪上限、流量变幅与日电量边界同时进入约束。

网络逐时删去停运支路及其潮流方程，B$\theta$ 形式与同一无损拓扑 PTDF 形式对应。
线路与断面具有独立双向限额及 M1 松弛；直流功率包含恒定损耗、中枢守恒、
上/下调及相邻调节方向限制。商业交易与物理关口显式映射。
优先计划使用硬电量下限或显式选择带 M4 的缺额解释，两者不能混称同一原式。

\subsection{定价与安全}
SCUC 后应用具备来源的调频预出清容量：$P^{min}+R^{reg,down}$、
$P^{max}-R^{reg,up}$ 进入 SCED。调频市场本身的完整报价优化属于另一份规则，
本入口消费其容量结果，不宣称复现该独立市场。停机/轨迹机组获分配时明确失败。

LMP 使用独立罚因子与 SCED 出力邻域；不可定价机组固定，负充电附近界按有序区间
解释。是否保留 SOC/循环、未单列新能源/优先电量约束必须明确选择。
备用经平衡消元装配后，原始平衡乘子恢复为
\begin{equation}
 \lambda^{original}=\lambda^{transformed}+d^{up}-d^{down},
\end{equation}
其中 $d$ 为求解器上界行 shadow price，非拉格朗日非负乘子。
节点电价为恢复后的原单位平衡乘子除以该时段目标费用权重 $w_t$：
$LMP_{b,t}=\lambda^{original}_{b,t}/w_t$（\srcpath{src/market/southern\_market.cpp:stage\_result}）。
\srcpath{stage\_result} 在原单位代回每条约束和变量界，输出残差与约束族。

交流安全检查电压、线路有功/视在功率、断面和同母线机组聚合 P/Q 能力；网损和平衡
机有功调整单列。越限后以局部潮流灵敏度添加约束并重新求 SCUC/SCED，只有重新
执行的 AC 潮流通过才认证。局部切面不是非凸安全域的全局 oracle，迭代耗尽/潮流
失败会拒绝认证和定价。选择 \texttt{schedule\_only} 时可查看线性计划，但顶层
\texttt{feasible=false}，不能解释为通过交流认证。

\subsection{周月滚动与日末状态承接}
实现锚点为\srcpath{src/market/market\_operation.cpp:carry\_from}及
\srcpath{src/market/market\_operation.cpp:step\_market\_operation}。
每个场景顺序运行，首日使用建任务初态，后续日使用前日 SCED 第96个实际时段末态
（数组索引95）。次日峰谷参考点（索引96、97）及 LMP 定价解不推进物理状态。
实体按表内稳定 ID 匹配。设日末状态为 $u_{95}$，向前连续相同状态的时段数为 $k$，则
\begin{equation}
 \tau_{d+1}=15k+
 \begin{cases}
 \tau_d,&k=96\ \text{且日初状态等于 }u_{95},\\
 0,&\text{其他情况}.
 \end{cases}
\end{equation}
$\tau$ 单位为分钟，表示连续开机或停机时长。下一天机组还继承日末出力，开机时
裁至 $[0,P^{max}_{95}]$，停机置零，用于初始爬坡。储能继承日末能量（MWh），
裁至 $[0,E^{rated}]$，SOC 为能量除以额定容量。水库继承日末水位（m）、日末下泄
及前一日96点下泄历史（m$^3$/s）；下泄值取非负，供梯级时滞与下泄爬坡使用。
直流联络线继承日末非负功率和上调/下调/无调整方向。

\srcpath{src/market/market\_operation.cpp:apply}先应用每日覆盖，再写入承接初态；
每日储能终值目标仍按申报约束，不是由前日复制的状态字段。相同终值可能使每天的
SOC初值相同。只有当日结果有效才更新\fld{carry}与完成天数，失败日不推进。
结果\fld{state\_start}和\fld{state\_end}可用于相邻日核对；恢复实验从历史日初
重新计算，不改变主任务承接。当前为逐日98点滚动而非全周联合最优；跨日非空启动/
停机功率轨迹在建任务时拒绝，非市场核电只作为外部功率计划，不含反应堆动态状态。

\subsection{矩阵复用、价格一致性与性能验收}
\srcpath{src/market/southern\_market.cpp:derive\_lmp}在独立compact、无裁行、无安全割、
无交流安全迭代、无实时及云南辅助服务的准入条件下，将SCED按原定价分支作有序选择：
\begin{equation}
 A_{price}=R A_{sced} C,\qquad E_{price}=R_{eq}E_{sced}C.
\end{equation}
共同系数及行列顺序保持，RHS同序选择，定价费用、冻结状态及功率邻域按原式计算。
只省略原定价策略本来不装配的行列，水库方程保留，调度SOC不受影响。
\fld{assembly\_mode=reference}使用原装配；\fld{verify}独立原装配比较矩阵、目标、
边界、原表达式和索引；其他不满足条件的模型走原路径。大型跨运行缓存尚未启用。

\srcpath{src/market/southern\_market.cpp:solve}对百万列及以上Gurobi定价固定8线程
障碍法，两份新实例同时求解；其他定价固定单线程对偶单纯形。两份完整原单位行对偶
必须精确相同，且最优性、目标与残差通过，才允许输出有效价格。失败价格为空，不得
结算。这是同一有序LP/后端版本/平台的代表解一致性，不证明数学对偶唯一。
