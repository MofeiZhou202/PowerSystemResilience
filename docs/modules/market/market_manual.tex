\begin{abstract}
\noindent 本手册依据 HySim-XJTU-HRPES 平台电力市场仿真模块
（\srcpath{src/market/}、\srcpath{include/hacdcpf/market/market\_simulation.hpp}）整理，
覆盖日前市场全链路（报价$\to$SCUC$\to$固定组合 SCED/LMP$\to$LODF N-1 割$\to$AC 认证$\to$结算）、
实时两结算市场（再调度 + 偏差结算 + 辅助/不平衡）与同步局部最优响应的重复博弈。
全部结论以源码与既有契约 \srcpath{docs/market\_simulation\_runtime.md} 为准。
\textbf{诚实口径（AC-only）}：出清刻意只对 AC 网络子集定价
（\fld{model\_scope}=\texttt{"ac-dc-linear-v1"}，\fld{dc\_network\_modelled}=false），
公式无法表示的在役资产以 \texttt{UnsupportedMarketAsset} \textbf{显式退回而非静默简化}。
文档版式与《碳流追踪与碳排放核算技术手册》一致。
\end{abstract}

\section{阅读指南与约定}
\subsection{数据来源}
\begin{itemize}
  \item \srcpath{include/hacdcpf/market/market\_simulation.hpp} —— 日前/实时/重复博弈接口、
        \texttt{MarketOptions}/\texttt{MarketResult}/\texttt{MarketModelScope} 定义；
  \item \srcpath{src/market/market\_simulation.cpp} —— 出清流水线、SCED/LMP、N-1 割、AC 认证与结算实现；
  \item \srcpath{src/market/participant\_behavior.cpp} —— 参与者报价策略（加价/扣留）与所有权解析；
  \item \srcpath{tests/test\_market\_simulation.cpp} —— 验证依据（目标 \texttt{hacdcpf\_test\_market\_simulation}）。
\end{itemize}
入口族定义于 \srcpath{include/hacdcpf/market/market\_simulation.hpp}。

\subsection{单位制与索引空间}
价格 LMP 单位 元/MWh，功率 MW，时段为整数小时索引。\fld{lmp\_per\_mwh} 按 AC 母线顺序，
\fld{branch\_flow\_mw} 按 AC 支路顺序；\fld{dc\_lmp\_per\_mwh}、\fld{vsc\_ac\_injection\_mw}/
\fld{vsc\_dc\_injection\_mw} 为诊断性输出（直流网络未参与定价）。机组组合结果
\fld{commitment}（\texttt{UCSchedule}）与逐时段定价 \fld{pricing}（\texttt{PricingPeriod}）
共享时段索引空间。

\subsection{诚实口径}
\fld{model\_scope}（\texttt{MarketModelScope}）显式声明：\fld{ac\_network\_modelled}=true、
\fld{dc\_network\_modelled}=false、\fld{vsc\_bidirectional\_efficiency\_modelled}=false、
\fld{hybrid\_n1\_modelled}=false，且 \fld{energy\_prices\_valid} 在通过校核前为 false。
在役但公式无法表示的资产以 \fld{unsupported\_assets}（\texttt{UnsupportedMarketAsset}）退回。
\fld{scuc\_mip\_relative\_gap}=$10^{-2}$ 意味着 SCUC 为近似解，除非 \fld{scuc\_optimality\_proven}
置真；AC 应急校核为 opt-in，失败在 \texttt{SecurityResult} 中保持显式（不静默修复）。

\section{验证与边界局限}
\subsection{验证与校核}

覆盖日前流水线、定价对偶、结算与市场力度量。

\subsection{边界与局限（如实标注）}
\begin{itemize}
  \item 出清\textbf{面向 AC 网络子集}：混合 AC/DC 市场协同优化被\textbf{显式拒绝}而非静默简化；
        \fld{model\_scope}=\texttt{"ac-dc-linear-v1"}，\fld{dc\_network\_modelled}=false，
        换流器效率/损耗标志为 false，\fld{hybrid\_n1\_modelled}=false；
  \item 公式无法表示的在役资产以 \texttt{UnsupportedMarketAsset} 退回（不静默丢弃）；
  \item N-1 为 AC 支路上的预防式 LODF；AC 应急校核为 opt-in，失败在 \texttt{SecurityResult} 中保持显式；
  \item \fld{scuc\_mip\_relative\_gap}=$10^{-2}$：SCUC 为近似解，除非 \fld{scuc\_optimality\_proven}；
  \item \fld{energy\_prices\_valid} 在通过校核前为 false，直流 LMP 仅作诊断。
\end{itemize}
