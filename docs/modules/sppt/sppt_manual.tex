\begin{abstract}
本文档对应 \srcpath{src/sppt/} 与 \srcpath{include/hacdcpf/sppt/}，讨论如何把
rich-to-canonical 投影的语义主张转成持续可证伪的程序证据。手册完整覆盖公共 MR1--MR7 与 MR3d/MR3t、
MR8 注册 DAE 测试、证书语料、独立作者方程残差、三门守卫、固定种子故障注入、性能基准、
消融、脚本化 agent loop 以及结构--数值--不确定性--权限联合准入。

SPPT 是验证层而非物理求解器。\fld{passed} 只有在 \fld{observation=Observed} 时可解释；
\fld{supported=false} 表示证据不可得而不是残差为零；调用者容差不是跨系统通用认证阈值。
当前没有公开 \texttt{mr8\_*} API，MR8 仅由注册测试在一个声明工作点核验 DAE 代数子雅可比。
\end{abstract}
