\begin{abstract}
\noindent 本手册依据 HySim-XJTU-HRPES 平台语义保持投影理论（SPPT）验证层
（\srcpath{src/sppt/}、\srcpath{include/hacdcpf/sppt/}，总入口头 \srcpath{sppt.hpp}）整理，命名空间
\texttt{hacdcpf::sppt}。该层把 SPPT 定理转成可计算的通过/残差检查：蜕变关系 MR1–MR8、MR3 证书语料、
独立残差审计、三门准入守卫与受守卫约束的智能建模循环。全部结论以源码与
\srcpath{docs/theory/sppt\_runtime\_contract.md} 契约为准：SPPT 不替代物理求解器，也不在被测系统、可观测量、
容差与后端之外证明正确性。版式与《碳流追踪与碳排放核算技术手册》一致。
\end{abstract}

\subsection{单位制与索引空间}
SPPT 层度量为无量纲残差与布尔判定：\fld{residual}/\fld{tolerance}（$\ge 0$）、
\fld{passed}/\fld{accepted}/\fld{sound}（布尔）、\fld{attribution\_total}（$[0,1]$ 归因完整度）、
混淆计数 \fld{tp}/\fld{fp}/\fld{tn}/\fld{fn}。蜕变编号 \fld{id} 取 \texttt{MR1}…\texttt{MR8}；证书残差
分列潮流、独立、OPF 对偶与归因。索引空间沿用被投影系统的规范映射，不另定义。

\subsection{诚实口径}
\fld{passed}=true 仅在 \fld{observation}=Observed 时有意义；不收敛即失败；\fld{tolerance} 为调用方
输入，并非通用认证阈值。独立残差 \fld{supported}=false 或 \fld{converged}=false 表示“证据不可得”，
而非零残差。智能仿真门从不执行物理控制：即使控制请求证据完整，至多给出 \texttt{RequireHumanReview}。
SPPT 不替代物理求解器，也不在被测系统/可观测量/容差/后端之外证明正确性。

\subsection{关键数据结构}

\fld{reason}、\fld{attribution}（\texttt{ObservableAttribution}）。守卫指标 \texttt{GuardMetrics} 含
\fld{tp}/\fld{fp}/\fld{tn}/\fld{fn} 与 \fld{precision}/\fld{recall}/\fld{catch\_rate}。

\fld{opf\_dual\_residual}、\fld{attribution\_total}；语料支持 \fld{all\_pass}、\fld{to\_csv}、
\fld{to\_latex}。独立残差证书 \texttt{IndependentResidualCertificate} 含 \fld{ac\_residual}、
\fld{dc\_residual}、\fld{converter\_balance\_residual}、\fld{total\_residual}。代理轨迹
\texttt{AgentTrajectory} 含 \fld{steps}、\fld{metrics}、\fld{sound}。
