\begin{abstract}
本文档覆盖 \srcpath{include/hacdcpf/model/}、位于 \srcpath{src/model/} 的模型实现以及
公共投影头 \srcpath{include/hacdcpf/projection/}。它把 \texttt{HybridPowerSystem} 视为工程语义真源，
系统说明 AC、DC、换流器、三相、聚合体、动态档案和遥测容器，给出有效功率/容量、控制角色、
单位换算、标准参数库、rich 到 canonical 的等值链及结果恢复契约。

本模块不求解潮流、优化或动态状态。组件存在于 POD 容器并不表示每个下游工作流都以相同保真度消费；
所有能力判断应联合 \texttt{component\_runtime\_semantics()}、投影证书、归因恢复等级和具体求解结果。
稳定组件 \fld{index}、vector position 与 graph node/edge index 是三类不同空间；AC/DC 同整数母线号
只有在 domain-qualified 映射中才无歧义。
\end{abstract}
