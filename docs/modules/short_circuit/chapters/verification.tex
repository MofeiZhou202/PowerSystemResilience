\subsection{标准归属与入口选择}
\begin{itemize}
  \item \textbf{IEC 60909 准入入口}：\srcpath{run\_short\_circuit\_detailed} 建立独立三序网、
        矢量组和相/地电流，是 IEC 结论唯一入口；\srcpath{compute\_short\_circuit} 是正序全母线
        筛查器，不进入不平衡 IEC 合规门；
  \item \textbf{直流准稳态}：\srcpath{dc\_bus\_fault\_level} 为电阻性刚性源模型，\textbf{不}含
        换流器限流、电容放电、电感 $di/dt$ 与电弧，因此相对真实峰值不保证上/下界；
  \item \textbf{零序参数门}：两/三绕组接地矢量组缺少必需零序参数时显式
        \fld{invalid\_network}；不接地分量返回阻抗模型物理 0 A，不含电容接地电流；
  \item \textbf{非保护配合器}：无跳闸时限曲线、方向/距离/差动选择性、电弧模型与跳闸后拓扑更新；
  \item \textbf{换流器}：跟网/构网为稳态/准稳态故障水平，不含控制环动态、FRT 轨迹与限流器切换时序；
  \item \textbf{投影前置}：AC 短路在 canonical 空间求解；母线和支路均回投影到 authored
        身份，canonical branch ID 只保留为诊断；收缩理想设备以 N/A 行表达；
  \item \textbf{DC 理想边}：零电阻导体先收缩；DCCB 责任由补偿定理故障后电压恢复实际边电流；
  \item \textbf{外部证据}：OpenDSS 与 GridLAB-D 5.3.0 本轮均已重跑；注册矩阵强制要求
        GridLAB-D 至少 35 个数值案例且最大误差不高于 $10^{-6}$；pandapower 综合 1PH 上游
        测试未作为本模块合规 oracle；其正则化伪电流只作来源说明，不计入通过数。
\end{itemize}

\subsection{证据解释规则}
测试 ``pass'' 只证明测试中声明的模型与门槛。IEC 标准例是外部数值参考；解析小例是独立公式；
50 组矩阵是 OpenDSS 完整网络交叉验证，IEEE feeders 是外部 Thevenin 故障核比较，两者范围不同。
所有证据不得互相替代。完整原始数值、误差和复现提交见
第~\ref{sec:sc-numerical}~章；已关闭审计项和适用范围见第~\ref{sec:sc-audit}~章。IEC 推导与富模型
速查仍可参见 \srcpath{docs/theory/short\_circuit\_rich\_acdc\_derivation.md}，冲突时以公共头、源码和
注册测试为准。
