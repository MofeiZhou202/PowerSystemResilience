\subsection{工业使用准入门}

\begin{enumerate}
  \item \textbf{数据门}：完成 electrical/solver-ready 校验；确认 kV/MVA/pu 基准、零序参数、接地方式、
        变压器矢量组、机器次暂态参数和 VSC 限流参数来源。
  \item \textbf{模型门}：三相/不平衡研究选择正确入口；若问题依赖矢量组零序阻断、控制动态、
        电弧、电容放电或保护动作，必须换用更高保真模型。
  \item \textbf{身份门}：设备级结论只使用 authored ID；canonical ID 仅为诊断。收缩设备必须检查
        \fld{electrical\_value\_available}，N/A 不得解释为零。
  \item \textbf{结果门}：逐项检查 solved/异常、有限性、非负性、effective 选项、模型范围和限制；
        不把缺失/剥离行解释为零。
  \item \textbf{验证门}：目标电压等级和设备类型至少有一个解析例、一个标准/第三方基准及参数敏感性；
        标准例误差门槛在运行前冻结。
  \item \textbf{保护门}：准稳态 DCCB duty 已按实际电阻边分流；最终选型仍须使用 EMT 峰值、$di/dt$
        和开断暂态，不得把本模块替代 IEC 61660/厂商开断模型。
\end{enumerate}

\subsection{可信结论与禁止外推}

在已验证范围内，可以可信地使用详细 AC 路径评估 IEC 60909 准稳态故障量、源贡献和剩余电压，
使用概览路径快速排序全母线三相故障水平，使用 DC 路径对纯电阻、刚性源网络做稳态线路电阻
限制筛查与实际电阻边分流。不得外推为：EMT/DC 电容放电仿真、动态保护配合/选择性分析、
故障穿越控制仿真、线路电容主导的不接地接地故障，或缺少矢量组/中性点参数时的零序自动推断。
GridLAB-D 5.3.0 的 35 个可表达案例已在强制门下重跑；pandapower 综合 1PH 上游路径未作为
本模块合规 oracle，只能作为带已知正则化差异的来源说明，不计入通过数。
