\begin{abstract}
\noindent 本手册以当前可达代码路径为边界，系统说明
\srcpath{build\_power\_system\_graph} 的混合 AC/DC 无向图投影、
\srcpath{analyze\_topology} 的岛/径向性/桥/割点/基本圈报告、闭合开关与零阻抗线的并查集收缩、
候选分类和降阶计划、串联与悬垂化简、稠密和稀疏 Kron/Schur 补，以及求解后电压恢复。
手册同时覆盖 \srcpath{POST /api/session/topology} 与
\srcpath{POST /api/session/network\_reduction} 的生产 HTTP/GUI 组合路径、注册测试和系统审计。

\smallskip
\noindent\textbf{核心口径}：公共 C++ 层没有自动执行“收缩 $\to$ 串联 $\to$ 悬垂 $\to$ Kron
$\to$ 求解 $\to$ 恢复”的统一入口；调用方必须显式组合各阶段。HTTP 的网络化简路由只实际应用
收缩、串联和可选悬垂，Kron 仅统计候选。图边的稳定组件 \fld{comp\_index}、图位置和
\fld{edge\_id} 必须分开；AC/DC 同号母线必须使用 domain-qualified 映射。Kron 对线性无源内部
节点精确，悬垂折叠和恒功率内部节点均含工作点近似。

\smallskip
\noindent 第~\ref{sec:gr-th-foundations} 章为专著级通用理论；其后的章节只陈述当前实现。
超出实现的 Ward 多端口等值、最优消去排序、非线性误差界和自动多级恢复不构成运行时承诺。
\end{abstract}
