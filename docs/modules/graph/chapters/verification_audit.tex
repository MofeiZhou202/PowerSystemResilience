\subsection{审计范围}

CMake 注册、三个直接测试目标，以及 validation、PF/OPF、可靠性/弹性、时序和生产 HTTP/GUI 的主要

本轮没有修改运行时代码。三个直接 graph 目标已由当前源码重新构建后运行；这仍不能替代完整
CTest、sanitizer 或外部求解器交叉验证。逐项原始数值与依赖提交见
第~\ref{sec:gr-numerical-crossval} 节。

非连续 branch component index 的 pendant 电压恢复；含内部常电流注入的稠密 Kron 完整电压恢复；

各类 400/409 结果契约。E2E 的 reduced-system reload 是完整性 smoke test，不是上述语义回归。

\subsection{算法级验收判据}

用于科研/工程结果前，至少应分别验收：
\begin{enumerate}
  \item \textbf{拓扑身份}：所有对外母线引用带 AC/DC domain，所有边引用声明 component ID、edge
        position 或 vector position；同号 AC/DC 测试必须通过。
  \item \textbf{物理保真}：收缩仅用于可接受阈值的同电压基 ideal ties；series 证明零注入且说明
        shunt/thermal-limit 处理；pendant 给出原网回放误差；Kron 证明 eliminated injection 假设。
  \item \textbf{映射闭环}：每个 authored bus/component 恰好能归因到 retained 或 explicit dropped
        状态，逆序恢复后在原网络重新计算残差和支路潮流。
  \item \textbf{数值质量}：Kron 报 pivot/front/fill/drop 信息，拒绝候选不能静默冒充已消去；大模型
        记录规模、nnz、内存和耗时。
  \item \textbf{结果诚实性}：HTTP/GUI 保留 exact/approximate/identify-only、失败与未验证状态，不用
        before-after 数量替代方程一致性证书。
\end{enumerate}

\subsection{工业使用边界}

在 AUD-024、AUD-027 与 AUD-031 关闭前，不应把当前 graph reduction 作为任意富模型的无条件生产
预处理器。较安全的可用范围是：ID 受控、组件覆盖明确的单域或无同号冲突网络；被动普通线路的
series；带显式误差回放的 pendant；以及三相混合 OPF 已注册路径中的 sparse Kron。任何导出的
reduced system 都应与原系统并存，保留完整 option、diagnostic、mapping 和原网后验 PF/OPF 证据。
