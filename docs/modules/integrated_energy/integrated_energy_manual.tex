\begin{abstract}
\noindent 本手册依据 HySim-XJTU-HRPES 平台综合能源模块
（\srcpath{src/integrated\_energy/}、\srcpath{include/hacdcpf/integrated\_energy/}）整理，
覆盖孤立园区多能载荷（电/热/氢/燃料/交通/储能）的混合整数线性规划（MILP），
命名空间 \texttt{hacdcpf::integrated\_energy}。诚实口径为本手册核心：本模块\textbf{不是交流网络模型}，
\fld{model\_scope}=\texttt{isolated-campus-multi-carrier-milp}，\fld{electrical\_network\_coupled}=false，
不含无功、电压、支路潮流或安全约束；并网点（PCC）交换为单一聚合进/出功率对，
\fld{fixed\_power\_factor} 必须恰为 $1.0$（其余取值被拒绝）。全部结论以源码与契约
\srcpath{docs/integrated\_energy\_contract.md} 为准。文档版式与《碳流追踪与碳排放核算技术手册》一致。
\end{abstract}

\section{阅读指南与约定}
\subsection{数据来源}
\begin{itemize}
  \item \srcpath{include/hacdcpf/integrated\_energy/integrated\_energy\_optimizer.hpp} —— 唯一公共入口；
  \item \srcpath{integrated\_energy\_options.hpp}、\srcpath{integrated\_energy\_result.hpp}、
        \srcpath{integrated\_energy\_system.hpp} —— 选项、结果与数据集结构；
  \item \srcpath{src/integrated\_energy/integrated\_energy\_optimizer.cpp} —— MILP 组装与求解实现；
  \item \srcpath{docs/integrated\_energy\_contract.md} —— 建模范围/有效性/局限契约；
  \item \srcpath{tests/test\_integrated\_energy\_campus.cpp} —— 验证依据。
\end{itemize}
命名空间为 \texttt{hacdcpf::integrated\_energy}。

\subsection{单位制与索引空间}
时域为 \fld{num\_steps} 步、单步 \fld{step\_duration\_hr} 小时；功率 MW、能量 MWh、
氢/燃料以等效 MW/MWh 计、距离 km、碳量 tCO\textsubscript{2}、电价 \$/MWh。所有平衡按
时间步索引，各能量载体（电/热/氢/燃料/交通/储能）分别守恒；\fld{pcc\_ac\_bus} 仅为
归因标签，\textbf{不}进入任何交流网络求解，并网点仅有单一聚合进出功率
$p^{pcc}_t=p^{imp}_t-p^{exp}_t$。

\subsection{诚实口径}
求解结果的 \fld{model\_scope} 固定为 \texttt{isolated-campus-multi-carrier-milp}，
有效性结构 \texttt{CampusIESValidity} 明示：\fld{multi\_carrier\_balances\_modelled}=true、
\fld{aggregate\_pcc\_active\_power\_modelled}=true，而
\fld{electrical\_network\_coupled}=false、\fld{reactive\_power\_modelled}=false、
\fld{voltage\_and\_branch\_limits\_enforced}=false。\fld{fixed\_power\_factor} 必须恰为
$1.0$，否则拒绝。被动效率须为 $(0,1]$ 内有限值，热泵 COP 可大于 1。历史输入的默默归一化
（如负容量截断、COP 缺省回填为 3.2）不构成输入校验；Sankey 流为可视化产物，非额外平衡约束。

\section{验证与边界局限}
\subsection{验证与校核}
注册测试：\srcpath{test\_integrated\_energy\_campus}
（\srcpath{tests/test\_integrated\_energy\_campus.cpp}），覆盖多能流平衡、分层储氢、
目标切换与有效性字段一致性。

\subsection{边界与局限（如实标注）}
\begin{itemize}
  \item \textbf{非交流网络模型}：求解不含 \texttt{HybridPowerSystem}、无功、电压、支路潮流、
        短路或安全约束；\fld{pcc\_ac\_bus} 仅为归因标签；
  \item \fld{fixed\_power\_factor} 必须恰为 $1.0$，其余取值被拒绝；建模范围在
        \fld{model\_scope}/\fld{validity}/\fld{model\_limitations} 中重申；
  \item 被动效率须为 $(0,1]$ 内有限值，热泵 COP 可$>$1；
  \item 历史输入的默默归一化（负容量截断、COP 回填为 3.2）不构成输入校验；
  \item Sankey 流（\texttt{CampusIESSankeyFlow}）为可视化产物，非新增平衡约束。
\end{itemize}
