\begin{abstract}
\noindent 本手册依据 HySim-XJTU-HRPES 平台求解器无关建模层
（\srcpath{src/power\_models/}、\srcpath{include/hacdcpf/power\_models/}）整理，命名空间
\texttt{hacdcpf::power\_models}，经 AML 桥 \texttt{hacdcpf::aml} 转发到 \texttt{mipsolvers::aml}。
该层把工程系统翻译为 \texttt{aml::Model} 的集合/参数/变量/目标/约束对象，按问题类（LP/QP/MILP/NLP）
派发到原生核或可选 HiGHS/Ipopt/SCIP/Gurobi，覆盖极坐标 ACOPF、交直流混合 OPF、DCOPF、LinDistFlow
与 SCUC。全部结论以本模块源码及逐式核验章为准：AML 通道为
实验性建模通道，不被生产运行时使用；\fld{model\_scope} 按结果类型区分：
\texttt{AMLBuildResult} 固定为 experimental-aml-builder:not-production-runtime，
混合 OPF 结果为 experimental-aml-hybrid-acdc-opf，SCUC 结果为
experimental-aml-scuc:system-balance-no-network，DCOPF/LinDistFlow 结果无该字段。
版式与《碳流追踪与碳排放核算技术手册》一致。
\end{abstract}

\end{itemize}
命名空间为 \texttt{hacdcpf::power\_models}。

\subsection{单位制与索引空间}
功率基准 \fld{base\_mva}（MVA），电压/电抗以标幺 pu，费用系数为发电费用多项式系数，价格以 \$/MWh。
输入以规范数据结构给出（\texttt{ACOPFData}/\texttt{ACDCOPFData}/\texttt{DCOPFData}/\texttt{SCUCData}/
\texttt{LinDistFlowData}），结果索引与其内部母线/机组/支路编号一致，映射字段如 \fld{vm\_pu}/\fld{pg\_mw}
以名称键给出。

\subsection{诚实口径}
AML 路径为实验性建模通道：\fld{model\_scope} 按结果类型区分——\texttt{AMLBuildResult} 固定为
experimental-aml-builder:not-production-runtime（\srcpath{include/hacdcpf/power\_models/aml\_build\_result.hpp:AMLBuildResult}），
明确“不被生产 \srcpath{solve\_ac\_opf}/
\srcpath{solve\_dc\_opf} 使用”；混合 OPF 结果 \texttt{ACDCOPFBuilderResult} 为
experimental-aml-hybrid-acdc-opf（\srcpath{include/hacdcpf/power\_models/hybrid\_opf\_model\_builder.hpp:ACDCOPFBuilderResult}），
生产混合 OPF 采用对等（parity）表述。SCUC 仅系统级平衡、无网络，其
MILP 平衡对偶非认证市场出清价（\fld{price\_valid}=false）。混合 OPF 的 DC/DC 采用光滑前向传输效率
/$I^2r$ 模型，不表示双向符号切换。

\section{验证与边界局限}
\subsection{验证与校核}
专用注册目标 \srcpath{power\_models\_cross\_validation} 已覆盖 AML DCOPF、LinDistFlow 与
SCUC 的公开入口，并以独立 Python 方程 oracle 重算解析解；详见
第\ref{sec:power-models-numerical}节。非线性 AML 建模器仍经由其它测试间接覆盖：
\srcpath{to\_acopf\_data}/\srcpath{to\_acdcopf\_data}/\srcpath{solve\_acdcopf} 见
\srcpath{tests/test\_converter\_coordination.cpp}，\srcpath{to\_acdcopf\_data} 见
\srcpath{tests/test\_hacdcpf.cpp}。旧交叉校核目标 \srcpath{test\_acopf\_dcopf\_crossval} 检验的是生产
\srcpath{opf::solve\_dc\_opf}，不能替代本轮 AML 专项 oracle。AML 非线性
\srcpath{solve\_acopf}/\srcpath{solve\_acdcopf} 尚无本模块专属独立数值 oracle。

\subsection{边界与局限（如实标注）}
\begin{itemize}
  \item AML 通道为实验性建模通道：\texttt{AMLBuildResult} 的 \fld{model\_scope} 固定为
        experimental-aml-builder:not-production-runtime（\srcpath{include/hacdcpf/power\_models/aml\_build\_result.hpp:AMLBuildResult}），
        明确“不被生产 \srcpath{solve\_ac\_opf}/
        \srcpath{solve\_dc\_opf} 使用”；混合 OPF 结果为
        experimental-aml-hybrid-acdc-opf（\srcpath{include/hacdcpf/power\_models/hybrid\_opf\_model\_builder.hpp:ACDCOPFBuilderResult}），
        生产混合 OPF 采用对等（parity）表述；\texttt{DCOPFResult}/\texttt{LinDistFlowResult}
        无 \fld{model\_scope} 字段；
  \item 混合 OPF：DC/DC 采用光滑前向传输效率/$I^2r$ 模型，不表示双向符号切换；
  \item SCUC 范围 \texttt{experimental-aml-scuc:system-balance-no-network}：仅系统级功率平衡、
        无输/配电网络；MILP 平衡对偶非认证市场出清价（\fld{price\_valid}=false）；
  \item LinDistFlow：仅固定负荷（无 DG/可控源/切负荷变量），忽略 $I^2r$ 损耗，热限近似；
  \item 本手册的 \srcpath{chapters/source\_equivalent\_builders.tex} 是本模块唯一数学规范；
        OPF 手册只记录跨模块接口，不复制本模块公式。
\end{itemize}
