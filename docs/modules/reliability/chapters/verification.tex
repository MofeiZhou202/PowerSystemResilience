\subsection{边界与局限（如实标注）}
\begin{itemize}
  \item \textbf{AC-only DC-OPF 口径}：MC/FMEA 在纯交流上 \fld{model\_scope}=\texttt{"ac-only-dcopf"}，
        \fld{validity.dc\_load\_curtailment\_included}=false、\fld{vsc\_dc\_power\_flow\_modelled}=false、
        \fld{ac\_voltage\_reactive\_feasibility\_certified}=false——EENS/LOLE \textbf{不含} DC 负荷中断，
        对含直流分量系统低估切负荷；
  \item \textbf{重要度语义}：\fld{critical\_components.importance} 是共现/归因秩（多故障态整体切负荷
        归给每个停运元件，可相加超 100\%），\textbf{非} Birnbaum 边际重要度 $\partial\mathrm{EENS}/\partial U_c$；
  \item \textbf{收敛判据}：CoV 仅对 $\bar S>0$ 有定义，零损失运行跑满迭代且记录零 CoV 不代表收敛；
  \item \textbf{尾部风险}：非序贯 VaR/CVaR 为 iid 小时近似，低估天气/修复/储能持续性引致的离散度；
  \item \textbf{信息物理 L1}：标量接口矩阵，无通信拓扑、无保护 FRT 轨迹、无类间联合依赖，
        保护误动占位项恒为 0；
  \item \textbf{三阶段范围}：耦合 LinDistFlow（线性化损耗），LCC 与多端口能量路由器被拒
        （清 \fld{ok}）；VSC/DC-DC 恒效率（无固定/二次损耗）；发电机/变压器/换流器/开关故障为选入项；
  \item \textbf{保护事件树}：静态事件树，非时限-电流/选择性/FRT 仿真；瞬时重合不计入 SAIFI/SAIDI/EENS。
\end{itemize}
