\subsection{往返与拒绝证据}
内置 IEEE-14 AC/DC rich JSON 案例逐字段往返通过；人为把首条 AC 支路 $x_{pu}$ 加 1 后，
比较器报告至少一项 mismatch，证明门控不仅检查“能否重新解析”。动态 RL 选择器、遥测绑定和
schema major 版本也在往返/拒绝矩阵中；不兼容 major 在 Strict 拒绝、Permissive 仅按当前
best-effort 契约处理。

CIM 目标覆盖 EQ+SSH 有界往返、越界类的 structural-loss 记录以及 DOCTYPE/ENTITY 拒绝。
这些结果证明实现遵守声明子集和安全边界，不证明完整 CGMES 互操作一致性。

\subsection{BPA--DSP 外部交叉验证}
DSP 参考通道覆盖 39-bus、IEEE90、2DC LCC、CIGRE LCC 和 vsc2 VSC-HVDC。LCC 参考工况为
整流侧 $P_{ac}=-1500$ MW、逆变侧 $+1410$ MW、$I_d=3.0$ kA、直流电压 500/470 kV，
直流线路损耗 90 MW；测试门槛分别为功率/电压 1 MW 或 1 kV、电流 0.01 kA。
VSC 工况对拍 $P/Q/P_{dc}$、站损和约 300 kV 直流电压。5 cases/251 assertions 全部通过。

新增内部矩阵覆盖 L/T 小电抗的 \fld{DspCompatible}/\fld{PreserveSource} 分歧、BQ
来源字段、BA/BA1/BA2/BB/BM/LM/LY 卡结构、L/C 工程量保留及 BridgeIn 电流限值。
三端 BM/LM 外部 DSP 数值用例依赖未随仓库提供的 \texttt{data/dsp/mtdc\_bm.dat}，
本轮明确 skip；因此 1680 条已执行断言只证明解析/结构/内部方程契约，\textbf{不构成}
BM/LM 外部数值对拍通过。

该 oracle 来自 DSP 文件和报告，独立于 HySim 求解器，但只覆盖对应 BPA 卡片和稳态 AC/DC
公共物理。它不能认证 JSON、CIM、ETAP、保护、动态或市场语义。

\subsection{可选外部引擎和未闭环范围}
GridLAB-D、OpenDSS 与 ETAP 测试受本机构建能力和数据存在性门控；本轮未把它们重新执行结果
混入上述无条件表。当前没有完整 CGMES 3.0 一致性套件、ETAP 商业程序双向 oracle 或所有格式
的字段级 schema 覆盖率。因此“导入通过”仍必须与 \texttt{ImportReport}、validation 和实际
PF/OPF 状态共同解释。
