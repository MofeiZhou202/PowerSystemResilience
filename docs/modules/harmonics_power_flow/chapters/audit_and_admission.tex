\subsection{测试覆盖}
\texttt{test\_harmonics\_power\_flow} 当前 63 cases / 412 assertions，覆盖 AC/DC/HSS 解析解、叠加性、
集肤、DC LC、NIC、三相不平衡、序分量、变压器接线组、所有 Newton 家族、频扫、标准门限、指标、
投影恢复、基础潮流回退和输入拒绝。外部测试分别承担独立方程、异构引擎和真实馈线证据；单元测试不能
替代外部验证，外部一致也不能替代失败语义测试。

\subsection{工业研究输入检查表}
\begin{enumerate}
  \item 确认基频潮流收敛；若使用存储工作点，报告 \fld{model\_limitations}；
  \item 谱幅值、相角、参考电流和注入符号必须有测量或设备资料来源；
  \item 线路 $R(h)$、大地回路、并联电容和负荷等值应覆盖研究频带；
  \item 三相变压器必须给出接线组、接地语义和可获得的 $Z_0$；
  \item 频扫步长需通过加密检验，共振点附近不能只取整数次数；
  \item 同时检查 order solved、ok、converged、最终残差和结果向量完整性；
  \item IEEE/国标结论须注明 PCC、电压等级、基准电流和采用的标准版本；
  \item 重要项目应以现场频扫/谐波测量校准，不以跨软件一致性替代实测。
\end{enumerate}

\subsection{当前声明范围内的闭环结论}
对“周期稳态、整数次数、逐阶线性频域网络；显式给定的跨阶二次项；当前三相接线组与 AC/DC
代数 NIC”这一声明范围，理论方程、源码、状态契约、单元测试、独立节点解、OpenDSS、GridLAB-D
和 IEEE13 证据已闭合。EMT、PWM 开关波形、间谐波、自动设备参数辨识和现场认证是不同模型族，
不作为本模块未完成边界，也不由本模块结果暗示。
