\section{源码等价的单相 AC/DC 线性模型}
本章只转写当前代码实际执行的运算，符号锚点不依赖易漂移的行号。

\subsection{选项拒绝条件}
\implfull{harmonics\_power\_flow.cpp:validate\_hpf\_options} 在任何矩阵组装前拒绝：非正或非有限的
\fld{default\_source\_xpp\_pu}、\fld{dc\_source\_impedance\_pu}、\fld{min\_shunt\_pu}；负或
非有限集肤系数；非正 Newton 迭代数/容差；AC 次数 $h\le1$、DC 次数 $r\le0$；以及任一列表中的
重复次数。拒绝结果保持 \fld{ok=false} 并在 \fld{message} 给出原因。

\subsection{交流四元印章}
\implfull{harmonics\_power\_flow.cpp:skin\_r/ac\_branch\_stamp} 定义
\begin{equation}
R(h)=\begin{cases}R_1,&model=None,\\R_1\sqrt h,&model=SqrtOrder,\\
R_1(1+k_s\sqrt h),&model=ProportionalSqrt,
\end{cases}
\end{equation}
并令 $z_h=R(h)+jhX_1$、$y_s=1/z_h$、$y_c=jhB_1$、$t=\tau e^{j\phi}$，得到
\begin{equation}
\begin{bmatrix}I_f\\I_t\end{bmatrix}=
\begin{bmatrix}(y_s+y_c/2)/\tau^2&-y_s/t^*\\-y_s/t&y_s+y_c/2\end{bmatrix}
\begin{bmatrix}V_f\\V_t\end{bmatrix}.
\end{equation}
同一个印章用于 Ybus 和 \texttt{HarmonicBranchFlow}。结果中的 \fld{i\_by\_order} 是 $|I_f|$，
\fld{i\_to\_by\_order} 是 $|I_t|$；铜耗采用理想变比低压侧的串联电流
$|y_s(V_f/t-V_t)|$，不把充电电流误计入 $I^2R$。

\subsection{canonical 投影与变压器唯一盖章}
\implfull{model/network\_utils.cpp:project\_to\_canonical\_models} 已把两绕组/三绕组变压器和开关展开为
canonical \texttt{ACBranch}，并创建 \texttt{BranchExpandMap}。因此
\implfull{harmonics\_power\_flow.cpp:build\_ac\_ybus} 只遍历 canonical 支路；不再二次遍历
\fld{transformers\_2w}。这保证每个物理泄漏阻抗只盖章一次，且支路结果包含变压器等值支路。

\subsection{并联元件、负荷与电源}
母线和 shunt 的基频参数按 $g+jhb$ 缩放。启用 \fld{include\_load\_impedance} 时，负荷采用
\begin{equation}
Y_L(h)=\frac{P_Ls_L/S_B}{|V_1|^2}-j\frac{Q_Ls_L/S_B}{h|V_1|^2}.
\end{equation}
电阻部分不随集肤模型变化。发电机、外部电网与松弛节点通过 $1/(R+jhX'')$ 接地；未知 $X''$ 使用
\fld{default\_source\_xpp\_pu}。每个活动节点加入 \fld{min\_shunt\_pu} 数值接地，停运节点使用大导纳
锁定。该正则化防止孤立节点令矩阵结构奇异，但不会把没有物理回路的零序电压解释为可信有限值。

\subsection{直流纹波网络}
\implfull{harmonics\_power\_flow.cpp:build\_dc\_ybus} 对 DC 支路采用
\begin{equation}
Z_r=R+jrX_{override},\qquad Y_{cap,r}=jrB_{override}.
\end{equation}
\texttt{DC\_V} 母线和 grid-forming NIC 端口由
$1/\max(Z_{dc,src},10^{-9})$ 接地。没有 override 时 DCBranch 为纯电阻；这是输入模型语义，而不是
把实际换流站电感默认设为零的物理结论。

\subsection{工作点与 NIC}
\implfull{harmonics\_power\_flow.cpp:extract\_operating\_point} 只有在基础潮流收敛时使用其电压和 VSC
传输结果，否则使用存储值并设置 \fld{used\_stored\_operating\_point=true}。NIC 基准电流为
\begin{equation}
I_{ac,1}=\overline{S_{ac}}/\overline{V_{ac,1}},\qquad I_{dc,0}=P_{dc}/V_{dc,0}.
\end{equation}
若用户未提供 $P_{dc}$ 且无法取得基础潮流 VSC 结果，代码采用 $P_{dc}=-P_{ac}$，并把无损假设写入
\fld{message}。自动 NIC 只对活动 VSC 且没有显式覆盖的设备生成。

\subsection{成功语义}
每个请求次数分别记录在 \fld{ac\_order\_solved}/\fld{dc\_order\_solved}。只有全部实际请求的矩阵
分解和回代都成功，线性结果 \fld{ok} 才为真。失败次数不进入 \fld{ac\_orders}/\fld{dc\_orders}，
也不伪造零电压。基础潮流回退是有标志的模型限制，但不自动否定谐波矩阵本身的数值成功。
