\subsection{输入资源}
\texttt{HarmonicCurrentSource} 以稳定 bus ID、AC/DC 域标志、参考电流、参考相角和
\texttt{HarmonicSpectrum} 描述。\texttt{HarmonicNIC} 另含 AC/DC 母线、VSC 稳定 ID、端口行为、
输出导纳和工作点功率。三相资源声明 phase mask、平衡/不平衡和分相参考电流。跨次资源必须显式列出
输入次数、输出次数、相别和复系数。

HSS 使用 \texttt{HSSCurrentInjection} 和 \texttt{HSSAdmittanceEntry}；两者的 bus 均是 authored 稳定
ID，并用 \fld{is\_dc} 限定域。\texttt{HSSOptions} 的主要准入项为唯一正整数 \fld{orders}、
\fld{include\_converter\_models}、\fld{compute\_device\_currents} 与有限正数
\fld{max\_backward\_error}（默认 $10^{-10}$）。完整方程和设备参数见第~\ref{sec:hss} 节。

\subsection{结果索引和单位}
\texttt{HarmonicBusResult::bus} 是 authored 稳定母线 ID，\fld{v\_by\_order} 为 order 到 pu 复相量；
AC 含 order 1，DC 含 order 0。THD 单位为百分数。\texttt{HarmonicBranchFlow::branch\_index} 是
canonical 支路稳定 ID，电流均为 pu 幅值；\fld{i\_by\_order}、\fld{i\_to\_by\_order}、
\fld{i\_series\_by\_order} 分别为 from 端、to 端和串联元件电流。HTTP 响应同时返回
\fld{branch\_index}、\fld{i\_pu}、\fld{i\_to\_pu} 和 \fld{i\_series\_pu}。
