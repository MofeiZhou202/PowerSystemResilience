\begin{abstract}
\noindent 本手册依据 HySim-XJTU-HRPES 平台可靠性评估模块
（\srcpath{src/reliability/} 与 \srcpath{include/hacdcpf/reliability/}，
以及位于 \srcpath{include/hacdcpf/analysis/three\_stage\_reliability.hpp} 的三阶段
恢复评估器）整理，覆盖统一可靠性参数解析器、非序贯/序贯蒙特卡洛、元件级 FMEA 与
故障模式级 FMEA（含信息物理 L1 扩展）、三阶段故障恢复 MILP、频率-持续时间解析法，
以及尾部风险与配电可靠性指标。每个方法给出功能定位、完整数学模型（公式对照
源码与
\srcpath{docs/reliability\_mathematical\_models\_and\_intelligent\_cyber\_physical\_assessment.md}）、
全部选项与结果字段的单位制和默认值、验证依据及已知局限。文档风格与《潮流计算技术
手册》《最优潮流技术手册》一致，全部公式逐条注明源码出处（文件:行号）。

\smallskip
\noindent\textbf{核心口径}：蒙特卡洛与 FMEA 的最小切负荷评估在纯交流系统上为
\emph{AC-only DC-OPF}（\fld{model\_scope}=\texttt{"ac-only-dcopf"}），\textbf{不计} DC
负荷中断，故对含直流分量的混合系统会低估切负荷；三阶段模型为耦合交直流
LinDistFlow 恢复 MILP。全部近似、回退与模型覆盖不足均写入结果的 \fld{model\_scope}、
\fld{model\_limitations} 与 \fld{ValidityFlags}。
\end{abstract}
